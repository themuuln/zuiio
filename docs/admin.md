# Админ самбар

Админ самбар (Admin Dashboard) нь **супер админ** эрхтэй хэрэглэгчдэд зориулсан тусгай самбар юм. Энэ хэсэгт бүртгэлтэй бүх байгууллагын захиалга (subscription) болон төлөвлөгөөг (plan) удирдах боломжтой.

## Хандалт

Админ самбарт зөвхөн **супер админ** эрхтэй хэрэглэгчид нэвтрэх боломжтой.

- `/dashboard/admin` хаягаар орно
- Супер админ эрхгүй бол **ShieldAlert** дүрс ба **"Access Denied"** мэдэгдэл харуулна
- Эрхийг `/api/admin/me` эндпойнтоор шалгана

## Header

Дээд хэсэгт:

- **Shield** дүрс + гарчиг
- Байгууллагын нийт тоо (**"X org(s)"** badge)

## Байгууллагын жагсаалт

Бүртгэлтэй бүх байгууллагын жагсаалт хүснэгт хэлбэрээр харагдана:

| Багана | Тайлбар |
| --- | --- |
| **Organization** | Байгууллагын нэр, slug |
| **Plan** | Төлөвлөгөөний төрөл (badge) |
| **Status** | Захиалгын төлөв (badge) |
| **Actions** | Төлөвлөгөө өөрчлөх товчнууд, Trial сунгах товч |

## Төлөвлөгөөний төрлүүд

Систем дараах 4 төлөвлөгөөг дэмждэг:

| Төлөвлөгөө | Өнгийн badge | Тайлбар |
| --- | --- | --- |
| **Starter** | Slate (саарал) | Эхлэгч төлөвлөгөө |
| **Pro** | Blue (цэнхэр) | Мэргэжлийн төлөвлөгөө |
| **Business** | Purple (ягаан) | Бизнес төлөвлөгөө |
| **Enterprise** | Amber (улбар шар) | Аж ахуйн нэгжийн төлөвлөгөө |

## Захиалгын төлөвүүд

| Төлөв | Өнгийн badge | Тайлбар |
| --- | --- | --- |
| **Active** | Emerald (ногоон) | Идэвхтэй, төлбөр төлсөн |
| **Trial** | Cyan (цайвар цэнхэр) | Туршилтын хугацаа |
| **Cancelled** | Red (улаан) | Цуцлагдсан |
| **Expired** | Rose (ягаан) | Хугацаа дууссан |

## Төлөвлөгөө өөрчлөх

Байгууллагын төлөвлөгөөг өөрчлөх:

1. Жагсаалтаас хүссэн байгууллагаа олно
2. **Actions** хэсэгт хүссэн төлөвлөгөөний товч дээр дарна (Starter / Pro / Business / Enterprise)
3. Одоогийн төлөвлөгөөний товч дээр **Check** (✅) тэмдэгтэй байна
4. Систем төлөвлөгөөг шууд шинэчилнэ (загварын spinner гарч ирнэ)
5. Амжилттай бол toast мэдэгдэл гарна

## Trial сунгах

Туршилтын хугацааг шинэчлэх:

1. **Actions** хэсэгт байрлах **Trial** (**RefreshCw** 🔄) товч дээр дарна
2. Систем тухайн байгууллагын туршилтын хугацааг дахин 14 хоногоор сунгана
3. Өөрчлөлт шууд хэрэгжинэ

::: info Анхаар
Төлөвлөгөөний хязгаарлалтууд одоогоор идэвхжээгүй байна. Энэ нь зөвхөн өгөгдлийн сан дахь төлөвлөгөөний төрлийг шинэчилнэ.
:::

## Түүхийн мэдээлэл

Хуудасны доод хэсэгт:

> Changes take effect immediately. The subscription plan limits are not enforced yet; this only updates the plan type in the database.

## API endpoints

Админ самбар дараах API эндпойнтуудыг ашигладаг:

| Эндпойнт | Үйлдэл |
| --- | --- |
| `GET /api/admin/me` | Супер админ эсэхийг шалгах |
| `GET /api/admin/organizations` | Бүх байгууллагын жагсаалт |
| `PATCH /api/admin/organizations/{id}/subscription` | Төлөвлөгөө шинэчлэх эсвэл Trial сунгах |

## Зөвлөмж

::: tip Төлөвлөгөө сонгох
Туршилтын хугацаагаа ашиглаад үзэхийг зөвлөж байна. Бүх төлөвлөгөөг туршиж үзээд тохирохыг нь сонгоорой.
:::

::: warning Зөвхөн супер админ
Энэ хуудас нь зөвхөн супер админ эрхтэй хэрэглэгчдэд зориулагдсан. Бусад хэрэглэгчид энэ хуудсыг нээхэд "Access Denied" мэдэгдэл гарна.
:::
