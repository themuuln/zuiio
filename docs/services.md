# Үйлчилгээний каталог

Үйлчилгээний каталог нь таны авто засварын газарт үзүүлдэг бүх үйлчилгээний жагсаалт, үнийг нэг дороос удирдах хэсэг юм.

## Үйлчилгээний жагсаалт

Үйлчилгээний каталогт дараах мэдээлэл харагдана:

| Талбар | Тайлбар |
|--------|---------|
| **Үйлчилгээний нэр** | Үзүүлэх үйлчилгээний нэр (жишээ нь: "Тос солих", "Тормосны дэвсгэр солих") |
| **Ангилал** | Үйлчилгээний төрөл (жишээ нь: "Тос, шүүрүүр", "Тормос", "Оношилгоо") |
| **Үндсэн үнэ** | Үйлчилгээний стандарт үнэ |
| **Сүүлд ашигласан үнэ** | Ажлын захиалгад хамгийн сүүлд ашигласан бодит үнэ |
| **Тодорхойлолт** | Үйлчилгээний дэлгэрэнгүй тайлбар |

## Шинэ үйлчилгээ нэмэх

1. **"Үйлчилгээний каталог"** хэсэгт орж **"Add Service"** товч дарна уу.
2. **Үйлчилгээний нэр** — заавал бөглөх талбар. Үйлчилгээний тодорхой нэрийг оруулна уу.
3. **Ангилал** — үйлчилгээний төрлийг сонгоно уу (жишээ: Oil, Brakes, Diagnostics).
4. **Үндсэн үнэ** — үйлчилгээний стандарт үнийг оруулна уу.
5. **Тодорхойлолт** — нэмэлт тайлбар оруулах боломжтой.
6. **"Save"** товч дарж хадгална уу.

::: tip Ангилалаар бүлэглэх
Үйлчилгээг ангилалаар нь бүлэглэн харуулах боломжтой. Хайлтын талбараар нэр эсвэл ангилалаар хурдан хайх боломжтой.
:::

## Үйлчилгээ засах, устгах

- **Устгах**: Үйлчилгээний мөрөн дээрх **X** товч дээр дарж устгана уу.
- **Засах**: Одоогоор үйлчилгээний мэдээллийг шууд засахын тулд устгаад шинээр үүсгэх шаардлагатай.

## Excel экспорт

Үйлчилгээний жагсаалтыг Excel-д экспортлох боломжтой. Экспортод үйлчилгээний нэр, ангилал, үнэ багтана.

## Ажлын захиалгад үйлчилгээ нэмэх

Үйлчилгээний каталогийн үйлчилгээнүүдийг ажлын захиалга үүсгэх үед шууд сонгож нэмэх боломжтой. Каталогид бүртгэгдсэн үндсэн үнэ эхний санал болно; тухайн машины өмнөх үнийн түүх байвал сүүлийн үнэ автоматаар бөглөгдөнө.

::: tip Үнийн түүх
Үйлчилгээний үнийн түүх автоматаар хадгалагдана. Дараагийн удаад ижил машинд ижил үйлчилгээ хийхэд өмнөх 3 үнийг харуулж, хамгийн сүүлд ашигласан үнийг санал болгоно. Каталогийн жагсаалт дээр мөн сүүлд ашигласан үнэ харагдана.
:::
