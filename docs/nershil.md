# Нэршил

Энэ хуудсанд TOLOM системд хэрэглэгддэг нэр томьёо, товчлолуудын тайлбар, монгол орчуулгыг оруулав.

## Нийтлэг нэр томьёо

| Англи                                    | Монгол                                 | Тайлбар                                                                                                                                            |
| ---------------------------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **VIN** (Vehicle Identification Number)  | Тээврийн хэрэгслийн код / **VIN код**  | Машин бүрийн өвөрмөц 17 тэмдэгтээс бүрдсэн серийн дугаар. Үйлдвэрлэгч, марк, загвар, үйлдвэрлэсэн он, хөдөлгүүрийн төрөл зэрэг мэдээллийг агуулна. |
| **ERP** (Enterprise Resource Planning)   | Байгууллагын нөөцийн төлөвлөлт         | Байгууллагын бүх үйл ажиллагаа (захиалга, бараа, санхүү, ажилтан) нэг системд нэгтгэсэн удирдлагын систем.                                         |
| **SaaS** (Software as a Service)         | Үйлчилгээ хэлбэрийн програм хангамж    | Програм хангамжийг суулгахгүйгээр интернетээр шууд ашигладаг загвар. Жишээ нь: Gmail, Google Docs, TOLOM.                                          |
| **Multi-tenant**                         | Олон байгууллагын тусгаарлагдсан орчин | Нэг систем дотор олон байгууллага тус тусдаа тусгаарлагдсан өгөгдөлтэй ажиллах архитектур. Та зөвхөн өөрийн байгууллагын өгөгдлийг харна.          |
| **Cloud**                                | Үүлэн технологи                        | Өгөгдлийг өөрийн компьютер биш, интернетээр холбогдсон алсын серверт хадгалах технологи.                                                           |
| **Dashboard**                            | Хяналтын самбар                        | Системийн үндсэн үзүүлэлтүүдийг нэг дэлгэцэнд харуулдаг хуудас.                                                                                    |
| **PIN** (Personal Identification Number) | Хувийн таних дугаар / **PIN код**      | Засварын буланд нэвтрэхэд ашиглагддаг 4-6 оронтой нууц код.                                                                                        |

## Системийн үндсэн хэсгүүд

| Англи                       | Монгол                    | Тайлбар                                                                                                           |
| --------------------------- | ------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **Work Order**              | Ажлын захиалга            | Засвар үйлчилгээний бүртгэл. Машины мэдээлэл, үйлчилгээ, сэлбэг, үнэ, төлөвийг багтаасан баримт.                  |
| **Bay View**                | Засварын булан            | Засварын газрын байрлал (bay) бүрийн төлөвийг хардаг харагдац. Ямар машинд аль механикч ажиллаж байгааг харуулна. |
| **Customer**                | Харилцагч / Үйлчлүүлэгч   | Авто засварын газарт үйлчлүүлж буй хүн эсвэл байгууллага.                                                         |
| **Vehicle**                 | Тээврийн хэрэгсэл         | Автомашин, жийп, микро автобус зэрэг тээврийн хэрэгсэл.                                                           |
| **Inventory**               | Бараа материал            | Сэлбэг хэрэгсэл, тос, шүүлтүүр зэрэг ашиглалтын нөөц.                                                             |
| **Supplier**                | Ханган нийлүүлэгч         | Сэлбэг, бараа материал нийлүүлдэг байгууллага, хувь хүн.                                                          |
| **Purchase Order** / **PO** | Худалдан авалтын захиалга | Ханган нийлүүлэгчээс бараа материал захиалах баримт.                                                              |

## Нэмэлт ойлголтууд

- **Үйлчилгээний ангилал** — Захиалгад нэмэгдсэн үйлчилгээнүүдийн төрөл, тоо.
- **Техничний гүйцэтгэл** — Механикч бүрийн хийсэн захиалга, зарцуулсан цаг, орлогын үзүүлэлт.
- **Өдрийн тайлан** — Тухайн өдрийн орлого, зарлага, гүйцэтгэсэн захиалгын тоо.
- **7 хоногийн тайлан** — Сүүлийн 7 хоногийн санхүүгийн хураангуй.
- **Сарын тайлан** — Сарын нийт орлого, зарлагын дэлгэрэнгүй тайлан.
- **Олон валют** — Систем хэд хэдэн валютыг нэгэн зэрэг дэмжих чадвар.
- **Босго хэмжээ** — Бараа материалын доод түвшин. Энэ хэмжээнээс доош буухад систем дохиолол өгнө.
- **LEDGER / Дансны дэвтэр** — Бараа материалын бүх хөдөлгөөнийг тэмдэглэх arith-логийн бүртгэл. Шууд тоо өөрчилдөггүй, харин бүртгэлээр дамжуулан нөөцөө хөтөлнө.
- **Зарлага (Expense)** — Бизнесийн үйл ажиллагаанд зарцуулсан мөнгө (түрээс, цалин, сэлбэг, татвар). Ангилал, төлөвтэй.
- **Зарлагын ангилал (Expense Category)** — Зарлагыг төрөл тус бүрээр бүлэглэх. Өнгө, дүрс, дараалалтай.
- **Үйлчилгээний сануулга (Service Reminder)** — Машины тогтмол үйлчилгээний хугацааг сануулах систем. Интервал, сувгаар тохируулна.
- **Үйлчилгээний хуваарь (Service Schedule)** — Машин-үйлчилгээ-интервалын холбоос. Тухайн машинд ямар үйлчилгээ хэзээ хийх ёстойг тодорхойлно.
- **CRM / Харилцагчийн тэмдэглэл (Customer Note)** — Харилцагчийн түүх, сануулга, холбогдсон мэдээллийг хөтлөх тэмдэглэл. Төрөл, агуулгатай.
