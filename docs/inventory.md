# Бараа материал

Бараа материалын хэсэг нь 4 үндсэн дэд хэсгээс бүрдэнэ:

1. **Сэлбэг ба нөөц** — агуулахын үлдэгдэл, үнэ
2. **Хөдөлгөөний түүх** — орлого, зарлагын бүртгэл
3. **Ханган нийлүүлэгчид** — нийлүүлэгчдийн мэдээлэл
4. **Худалдан авалтын захиалга** — PO удирдлага

---

## 1. Сэлбэг ба нөөц

Сэлбэгийн жагсаалт, агуулахын үлдэгдэл, үнийн мэдээлэл харагдана.

### Өнгөт тэмдэглэгээ

| Өнгө          | Утга               | Тайлбар                                               |
| ------------- | ------------------ | ----------------------------------------------------- |
| 🟢 **Ногоон** | Хангалттай нөөц    | Босго хэмжээнээс дээш үлдэгдэлтэй                     |
| 🟡 **Шар**    | Дуусч дөхсөн       | Босго хэмжээнд ойртсон, нөөцлөх шаардлагатай          |

::: warning Дансны дэвтэр (Ledger)
Сэлбэгийн үлдэгдэл нь дансны дэвтрээр бүртгэгддэг. Үлдэгдлийг шууд засварлах боломжгүй — зөвхөн зөв төрлийн хөдөлгөөн нэмэх замаар өөрчлөнө.
:::

## 2. Хөдөлгөөний түүх

Хөдөлгөөний түүх нь сэлбэгийн орлого, зарлагын бүрэн бүртгэл юм. Энэ нь **immutable ledger** — өөрчлөх, устгах боломжгүй.

| Хөдөлгөөний төрөл | Тайлбар                             | Үлдэгдэлд үзүүлэх нөлөө |
| ----------------- | ----------------------------------- | ----------------------- |
| `purchase`        | Ханган нийлүүлэгчээс худалдан авалт | + нэмэгдэнэ             |
| `sale`            | Захиалгаар зарлагадсан              | — хорогдоно             |
| `adjustment`      | Тооллогын дүнгээр тохируулга        | + эсвэл —               |
| `transfer_in`     | Өөр салбараас шилжүүлэг ирсэн       | + нэмэгдэнэ             |
| `transfer_out`    | Өөр салбарт шилжүүлсэн              | — хорогдоно             |
| `return`          | Нийлүүлэгчид буцаасан               | — хорогдоно             |
| `waste`           | Гэмтэл / хаягдал                    | — хорогдоно             |

::: tip Шүүлтүүр
Хөдөлгөөний түүхээс төрөл тус бүрээр шүүж харах боломжтой. Жишээ нь зөвхөн "Худалдан авалт" эсвэл "Зарлага"-ын түүхийг тусдаа харж болно.
:::

## 4. Худалдан авалтын захиалга

### Төлөвүүд

| Төлөв                       | Тайлбар                                   |
| --------------------------- | ----------------------------------------- |
| **Төсөл (draft)**           | Захиалга үүсгэгдсэн, хараахан илгээгээгүй |
| **Захиалсан (ordered)**     | Нийлүүлэгчид илгээгдсэн, хүлээгдэж буй    |
| **Хэсэгчилсэн (partial)**   | Захиалгын зарим хэсэг ирсэн               |
| **Хүлээн авсан (received)** | Бүх бараа ирж, хүлээн авсан               |
| **Цуцлагдсан (cancelled)**  | Захиалга цуцлагдсан                       |

::: info Автомат нөөц нэмэгдэх
Бараа хүлээн авах (receive) үед систем автоматаар агуулахын үлдэгдэлд `purchase` төрлийн хөдөлгөөн нэмж, сэлбэгийн тоо хэмжээг нэмэгдүүлнэ.
:::

## 5. Нөөцийн мэдэгдэл (Low Stock Alerts)

Нөөцийн мэдэгдэл хэсэг нь агуулахын үлдэгдэл босго хэмжээнээс доош буухад автоматаар мэдэгдэж, дахин захиалга хийхэд тусална.

### Босго хэмжээ тохируулах

Сэлбэг тус бүрийн доод босго хэмжээг (minimum quantity) Parts табаас шууд тохируулах боломжтой:

1. **Parts** табад орно
2. Хүссэн сэлбэгийн **Min** баганад байгаа утга дээр дарна
3. Шинэ босго хэмжээг бичээд Enter дарна

Анхдагчаар босго хэмжээ тогтоогоогүй сэлбэгт **5 ширхэг** утгыг ашиглана.

### Хэрхэн ажилладаг

| Үлдэгдэл | Төлөв | Өнгө |
|----------|-------|------|
| Босго хэмжээнээс дээш | Хангалттай нөөц | 🟢 Ногоон |
| 0-с их, босго хэмжээнээс доош | Дуусч дөхсөн | 🟡 Шар |
| 0 эсвэл түүнээс бага | Дууссан / маш бага | 🔴 Улаан |

### Alert-ийн төрлүүд

| Шинж тэмдэг | Тайлбар | Үйлдэл |
|------------|---------|--------|
| **Low Stock** | Үлдэгдэл 0-с их боловч босго хэмжээнээс доош | Нөөцлөх захиалга хийх |
| **Out of Stock** | Үлдэгдэл 0 буюу түүнээс бага | Яаралтай захиалга хийх |

### Хяналтын самбар дээр харагдац

Хэрэв нөөц дуусч дөхсөн эсвэл дууссан сэлбэг байвал:

- **Хяналтын самбар** дээр шар өнгийн мэдэгдэл гарч ирнэ
- Тус мэдэгдэлд: хэдэн сэлбэг дууссан, хэдэн сэлбэг босго хэмжээнээс доош байгааг харуулна
- **View** товч — сэрэмжлүүлгийн дэлгэрэнгүй хуудас руу шилжих
- **Order** товч — шинэ худалдан авалтын захиалга үүсгэх

### Сэрэмжлүүлгийн хуудас

Бараа материалын дээд хэсэгт **Alerts** товч дээр дарж, эсвэл хяналтын самбараас **View** товч дээр дарж сэрэмжлүүлгийн хуудас руу шилжинэ. Эндээс:

- Дууссан болон дуусч дөхсөн сэлбэгийн жагсаалт
- Тус бүрийн үлдэгдэл, босго хэмжээ, дутагдал (shortage)
- **Create PO** товч — сэлбэг бүрээс шууд худалдан авалтын захиалга үүсгэх

## 6. Машины сэлбэг (Parts Cars)

Машины сэлбэгийн хэсэг нь **салгасан (буулгасан) машинаас** гаргаж авсан сэлбэгийг бүртгэх боломжийг олгоно.

### Машин бүртгэх

Шинэ машин бүртгэхдээ үйлдвэрлэгч, загвар, он, улсын дугаар, VIN код, өнгө зэрэг мэдээллийг оруулна.

### Машины төлөв

| Төлөв             | Тайлбар                                 |
| ----------------- | --------------------------------------- |
| **Arrived**       | Машин ирсэн, салгаж эхлээгүй            |
| **Disassembling** | Салгаж байгаа (хэсэгчлэн задалсан)      |
| **Completed**     | Салгалт дууссан, бүх сэлбэг бүртгэгдсэн |
| **Cancelled**     | Цуцлагдсан                              |

### Сэлбэг нэмэх

Машинаас гаргаж авсан сэлбэг тус бүрийг дараах мэдээллээр бүртгэнэ:

| Талбар              | Тайлбар                                                                                                                                           |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Сэлбэгийн нэр**   | Сэлбэгийн тодорхойлолт                                                                                                                            |
| **Тоо хэмжээ**      | Гаргаж авсан тоо хэмжээ                                                                                                                           |
| **Байрлалын бүлэг** | Сэлбэгийн байрлал (хөдөлгүүр, дамжуулга, түдгэлзүүлэлт, тоормос, их бие, дотор, цахилгаан, хөргөлт, яндан, түлш, жолоодлого, агааржуулагч, бусад) |

Бүртгэгдсэн сэлбэг нь бараа материалын нөөцөд автоматаар нэмэгдэхгүй (зөвхөн салгасан машины сэлбэгийн бүртгэлд үлдэнэ).
