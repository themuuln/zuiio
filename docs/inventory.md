# Бараа материал

Бараа материалын хэсэг нь сэлбэгийн каталог, үлдэгдэл, хөдөлгөөн, нийлүүлэгч, худалдан авалтын захиалга, задаргааны машин болон үлдэгдлийн үнэлгээг нэгтгэнэ.

## Үндсэн табууд

Inventory хуудасны дээд хэсэгт **4 таб** байрлана:

| Таб | Тайлбар |
| --- | --- |
| **Parts** | Сэлбэгийн каталог болон Глобал каталог |
| **Movements** | Ledger хэлбэрийн хөдөлгөөний түүх |
| **Suppliers** | Ханган нийлүүлэгчдийн бүртгэл |
| **Purchase Orders** | Худалдан авалтын захиалгууд |

Дээрээс гадна дараах нэмэлт хуудаснууд байна:

| Хуудас | Зам |
|--------|-----|
| **Alerts** | `/dashboard/inventory/alerts` |
| **Valuation** | `/dashboard/inventory/valuation` |
| **Parts Cars** | `/dashboard/inventory/parts-cars` |

---

## KPI картууд

Inventory хуудасны дээд талд **4 KPI карт** байрлана:

| KPI | Тайлбар | Эх сурвалж |
|-----|---------|-----------|
| **Нийт сэлбэг** | Идэвхтэй SKU-ийн нийлбэр тоо | parts_catalog → is_active |
| **Нийт нөөцийн үнэ** | үлдэгдэл × үнийн нийлбэр (₮) | inventory_balances × default_price |
| **Эргэлт** | COGS / дундаж нөөцийн үнэ (жишин: 2.3x) | inventory_movements (purchase) / balances |
| **Удаан хөдөлгөөнтэй** | 90+ хоног хөдөлгөөнгүй сэлбэгийн тоо | last_movement_at < 90 хоног |

**Sidebar:** Баруун талын sidebar-д "Stock" хавтсан дээр **Total SKUs**, **Low Stock** (баганаар), **Out of Stock** (улаан өнгөөр) тоонууд харагдана.

### My Inventory — Жагсаалт

#### Жагсаалтын баганууд

| Багана | Эрэмбэлэх боломжтой | Тайлбар |
|--------|---------------------|---------|
| **Name** | Тийм | Сэлбэгийн нэр (MN/EN хоёрдугаар нэр гарна) |
| **Popularity** | Тийм | Popularity score (80+ дээр ★ тэмдэг гарна) |
| **Category** | Тийм | Ангилал |
| **Default Price** | Тийм | Үндсэн үнэ (₮) |
| **On Hand** | Тийм | Үлдэгдэл тоо (өнгөөр тэмдэглэгдэнэ) |
| **Status** | Үгүй | In Stock / Low Stock / Out of Stock badge |
| **Min** | Үгүй | Босго хэмжээ (дарж засах боломжтой) |
| **Part #** | Үгүй | Сэлбэгийн дугаар |
| **Үйлдлүүд** | — | View (нүд) + Edit (зүүлгүүр) товчууд |

**Эрэмбэлэх:** Name, Popularity, Category, Price, Stock — эцгийн дагуу эсвэл урвуугаар эрэмбэлж болно. **Анхны эрэмбэлбэр:** Popularity (ахицтай).

**Хайлт:** Нэр, Монгол нэр, Part #, Ангилал дээр хайна.

**Статусын өнгө:**
- **In Stock** — ногоон badge
- **Low Stock** — шар badge + ⚠️ тэмдэг
- **Out of Stock** — улаан badge + ⚠️ тэмдэг

#### Үйлдлүүд (Туулбар)

| Товч | Тайлбар |
|------|---------|
| **Export** | Excel файл руу экспортлох (нэр, дугаар, ангилал, үнэ, үлдэгдэл, статус) |
| **Record Movement** | Хөдөлгөөн бүртгэх товч — Movements таб руу шилжүүлнэ |
| **Add Part** | Шинэ сэлбэг нэмэх модал нээх |
| **Set Default Threshold** | Босгогүй бүх сэлбэгт нэг стандарт босго тогтоох |

**Босго хэмжээ засах:** Мин баганы дээрх тоог дарж → input бичиж → Save дарна. Давхарлан засах боломжтой.

**Сэлбэгийн нэр дээр дарах** → `/dashboard/inventory/parts/[partId]` дэлгэрэнгүй хуудас руу орно.

### Global Catalog — Глобал лавлах

Глобал каталогт бүх байгууллагад нийтлэг сэлбэгийн жагсаалт байна.

| Багана | Тайлбар |

### Сэлбэг нэмэх / засах модал (PartForm)

Сэлбэг нэмэх болон засахад нэг модал ашиглагдана.

**Хоёр горим:**

| Горим | Талбарууд |
|-------|----------|
| **Quick Add** | Монгол нэр*, English Name, Part Number, Default Selling Price (₮) |
| **Full Details** | Монгол нэр*, English Name, Part Number, Category (combobox), Default Selling Price (₮), Purchase Price (₮), Unit, Description |

**Category Combobox:**
- Бичиж хайж болно
- Байхгүй ангилал бичвэл "Create '...'" товч гарч ирнэ — шинэ ангилал үүсгэж болно
- `part_categories` хүснэгтэд хадгалагдана

**Validation:** Монгол нэр (name_mn) — заавал байх ёстой.

### Set Default Threshold — Босго тохируулах

"Set Default Threshold" товч дээр дарахад диалог нээгдэнэ:
- Босгогүй бүх сэлбэгт нэг стандарт босго тогтооно
- Зөвхөн `stock_thresholds` хүснэгтэд бичигдээгүй сэлбэгүүдэд хамаарна
- Жишээ нь: 5 гэж бичвэл → босгогүй бүх сэлбэгийн minimum_quantity = 5 болно

## Movements — Хөдөлгөөн

### Хөдөлгөөний төрлүүд

| Төрөл | Монгол нэр | Өнгө | Тайлбар |
|-------|-----------|------|---------|
| **purchase** | Худалдан авалт | Ногоон | Нөөц нэмэх |
| **sale** | Борлуулалт | Улаан | Нөөц хасах |
| **adjustment** | Засвар | Цэнхэр | Тохируулга |
| **transfer_in** | Шилжүүлэг ирсэн | Ягаан | Салбар хооронд ирсэн |
| **transfer_out** | Шилжүүлэг явуулсан | Ягаан | Салбар руу явуулсан |
| **return** | Буцаалт | Шар | Буцааж илгээсэн |
| **waste** | Хог хаягдал | Саарал | Хаясан |
| **disassembly** | Задаргаа | — | Задаргааны машинаас гарсан |

### Movements таб (Дэлгэц)

**Туулбар:**
- **Хайлт:** Нэр, тэмдэглэл, reference_type дээр хайна
- **Шүүлтүүр:** ToggleGroup чипүүдээр төрөл бүрээр шүүж болно
- **Стат:** Нийт хөдөлгөөний тоо
- **Экспорт:** Excel файл руу

**Баганууд (DataTable):**

| Багана | Тайлбар |
|--------|---------|
| **Date** | Хөдөлгөөний огноо |
| **Movement Type** | Төрлийн badge (өнгөөр) |
| **Part** | Сэлбэгийн нэр |
| **Qty** | Тоо |
| **Unit Cost** | Нэгж үнэ (₮) |
| **Reference** | Холбоотой баримтын төрөл |
| **Notes** | Тэмдэглэл |

**Хөдөлгөөн бүртгэх модал:**
1. **Part** — Хайж сонгох (2+ тэмдэгт бичихэд хайна)
2. Сонгосон сэлбэгийн **одоогийн үлдэгдэл** харуулна
3. **Quantity** — Заавал (эерэг/сөрөг)
4. **Unit Cost** — Нэгж үнэ (₮)
5. **Movement Type** — Унадаг цэс
6. **Notes** — Нэмэлт тэмдэглэл

## Purchase Orders — Худалдан авалтын захиалга

### Төлвүүд

| Төлөв | Өнгө | Тайлбар |
|-------|------|---------|
| **Draft** | Саарал | Ноорог — засах боломжтой |
| **Ordered** | Цэнхэр | Нийлүүлэгч рүү илгээсэн |
| **Partial** | Шар | Хэсэгчлэн ирсэн |
| **Received** | Ногоон | Бүрэн хүлээн авсан |
| **Cancelled** | Улаан | Цуцлагдсан |

### Purchase Orders таб (Дэлгэц)

**Туулбар:**
- **Хайлт:** PO дугаар, нийлүүлэгчийн нэр, төлөв дээр хайна
- **Стат:** Нийт PO-ийн тоо
- **Экспорт:** Excel файл руу

**PO картууд (Card-based жагсаалт):**
- Нэг карт нь нэг PO-ийг төлөөлнө
- Дэлгэж болох (expand/collapse)
- **Харагдах байдал:** Order Number · Supplier · Status Badge · Total Amount (₮) · Огноо

**Дэлгэсэн үед:** Барааны жагсаалт:

| Багана | Тайлбар |
|--------|---------|
| **Part** | Сэлбэгийн нэр |
| **Qty Ordered** | Захиалсан тоо |
| **Qty Received** | Хүлээн авсан тоо |
| **Unit Cost** | Нэгж үнэ (₮) |

**Receive Stock товч:** Draft/Ordered/Partial төлөвтэй PO дээр "Receive Stock" товч харагдана. Дарахад:
1. Хүлээн аваагүй бүх барааны хэмжээг нэмнэ
2. `purchase` төрлийн inventory movement үүсгэнэ
3. PO-ийн төлөвийг `received` эсвэл `partial` болгон шинэчилнэ
4. Сэлбэг бүрийн `last_purchase_price` шинэчилнэ

## Valuation — Үлдэгдлийн үнэлгээ

**Зам:** `/dashboard/inventory/valuation`

### KPI карт

Нэг том карт: **Нийт нөөцийн үнэ** (₮) — бүх сэлбэгийн нийлбэр үнэлгээ.

### Шүүлтүүр

- **Хайлт:** Сэлбэгийн нэр, Part # дээр
- **Ангиллын чипүүд:** "All" + ангилал бүр (тойрон хэлбэртэй товчууд)
- **Экспорт:** Excel файл руу

### Баганууд (DataTable)

| Багана | Тайлбар |
|--------|---------|
| **Part Name** | Сэлбэгийн нэр + Part # (жижиг) |
| **Category** | Ангилал |
| **On Hand** | Үлдэгдэл тоо + нэгж |
| **Avg Unit Cost** | Жингийн дундаж нэгж үнэ (₮) |
| **Total Value** | Үлдэгдэл × дундаж үнэ (₮) |

**Жингийн дундаж үнэ (Weighted Average Cost):**
`SUM(purchase_quantity × unit_cost) / SUM(purchase_quantity)` — зөвхөн `purchase` төрлийн хөдөлгөөнөөс тооцно.

## Хөдөлгөөний бүртгэл — Дэлгэрэнгүй

### Хөдөлгөөний жин чухал зарчим

Үлдэгдлийг шууд тоо болгон засварлахын оронд **ledger зарчмаар** удирддаг:

1. `inventory_movements` хүснэгтэд шинэ мөр оруулна
2. PostgreSQL trigger-ээр `inventory_balances` хүснэгт автомат шинэчлэгдэнэ
3. Хэн, хэзээ, ямар шалтгаанаар нөөц өөрчлөгдсөнийг мөрдөх боломжтой

### Хөдөлгөөн бүртгэх үед

Сонгосон сэлбэгийн **одоогийн үлдэгдэл** (balance) модал дотор харуулна — ингэснээр хэрэгтэй эсэхийг шууд харж болно.

### Work Order-той интеграци

Ажлын захиалга (Work Order) **Completed** төлөвт шилжих үед:

1. Захиалгад ашиглагдсан сэлбэг бүрээр `sale` төрлийн inventory movement үүсгэгдэнэ
2. Үлдэгдэл автоматаар хасагдана (real-time)
3. Алдаа гарвал work order хаагдахыг блоклохгүй — зөвхөн log-д тэмдэглэгдэнэ

## Босго хэмжээ (Stock Thresholds)

### Зорилго

Босго хэмжээ тогтоосноор систем **low stock** болон **out of stock** дохио гаргана.

### Төлөв тооцоо

| Байдал | Нөхцөл | Үр дүн |
|--------|--------|--------|
| **In Stock** | quantity_on_hand ≥ minimum_quantity | Ногоон badge |
| **Low Stock** | 0 < quantity_on_hand < minimum_quantity | Шар badge + ⚠️ |
| **Out of Stock** | quantity_on_hand ≤ 0 | Улаан badge + ⚠️ |

**Анхны утга:** Босго тохируулаагүй бол **5** гэж үзнэ.

### Босго тохируулах аргууд

1. **Parts жагсаалт:** Мин баганы тоог дарж inline засах
2. **Parts дэлгэрэнгүй:** Threshold Card дээр edit товч
3. **Set Default Threshold:** Босгогүй бүх сэлбэгт нэг стандарт утга тогтоох

## Нэмэлт модулиуд

### Inventoriesийн тайлангууд (inventory-reports-service)

| Тайлан | Тодорхойлолт |
|--------|-------------|
| **Inventory Turnover** | COGS / дундаж нөөцийн үнэ (жилийн) |
| **Usage Trends** | Сар бүрийн хэрэглээ (sale movement-ээс) |
| **Slow-Moving Stock** | 90+ хоног хөдөлгөөнгүй сэлбэгүүд |

### Задаргааны машины үйлдлүүд

| Үйлдэл | Тайлбар |
|--------|---------|
| **Add Part** | Задаргааны сэлбэг нэмэх |
| **Complete Disassembly** | Задаргаа дуусгах — нийт тоо/үнэлгээ тооцно |
| **Publish to Catalog** | Задаргааны сэлбэгүүдийг parts_catalog руу нийтлэх — inventory movement (disassembly төрөл) автоматаар үүснэ |

**Publish to Catalog логик:**
1. Задаргааны машинд холбогдоогүй (`part_id IS NULL`) сэлбэгүүдийг олно
2. Бүр бүрийг `parts_catalog`-д шинэ бүртгэл болгон нэмнэ
3. `parts_car_parts` → `part_id`-г шинэ каталогийн ID-тэй холбоно
4. `disassembly` төрлийн inventory movement үүсгэнэ (нөөц нэмэгдэнэ)

## Анхаарах зүйл

1. **Леджер зарчим:** Үлдэгдлийг хэзээ ч шууд бичиж болохгүй. Зөвхөн `inventory_movements` бүртгэж, trigger-аар баланс шинэчлэгдэнэ.
2. **Work Order интеграци:** Completed үед сэлбэг бүрээр `sale` movement автоматаар үүснэ. Алдаа гарвал log-д тэмдэглэгдэнэ, блоклохгүй.
3. **Босго хэмжээ:** Анхны утга **5**. Босгогүй сэлбэг "Set Default Threshold" -аар нэг дор тохируулж болно.
4. **Глобал каталог:** Глобал мэдээлэл дээр дарахад зөвхөн локал хувь үүсгэнэ. Глобал өөрчлөхгүй.
5. **PO Хүлээн авах:** Нэг дарахад хүлээн аваагүй бүх барааг нэгэн зэрэг хүлээн авна. Тусдаа partial хүлээн авалт боломжгүй.
6. **Задаргааны машин:** Publish to Catalog нь `disassembly` movement үүсгэнэ — энэ нь нөөцийг нэмнэ, хасахгүй.
7. **Жингийн дундаж үнэ:** Зөвхөн `purchase` төрлийн хөдөлгөөнөөс тооцно. `sale`, `adjustment` зэрэг нь нөлөөлөхгүй.
8. **Branch filter:** Бүх хүснэгтүүд `branch_id` дэмжлэгтэй. Баруун дээд буланд сонгосон салбараас хамааран үлдэгдэл өөрчлөгдөнө.
