# Хяналтын самбар

Хяналтын самбар (Dashboard) нь таны байгууллагын үйл ажиллагааны ерөнхий тоймыг харуулдаг анхны хуудас юм.

## Хугацааны шүүлтүүр

Хяналтын самбарын дээд хэсэгт хугацааны шүүлтүүр байрлана. Дараах хугацаагаар шүүж болно:

| Шүүлтүүр       | Хугацаа     |
| -------------- | ----------- |
| **Today**      | Өнөөдөр     |
| **This Week**  | Энэ 7 хоног |
| **This Month** | Энэ сар     |
| **All Time**   | Бүх хугацаа |

Шүүлтүүрийг өөрчлөхөд доорх KPI үзүүлэлт, графикууд сонгосон хугацаагаар шинэчлэгдэнэ.

## Өдрийн зорилтот орлого

Хяналтын самбарын эхэнд **өдрийн зорилтот орлогын** карт харагдана. Энэ картаар:

- Өдрийн зорилтот орлогын дүнг тохируулах (**Set Goal** / **Edit** товч)
- Зорилтот дүнгийн эсрэг бодит орлогын дэвшил (progress bar)
- Бодит орлого / Зорилтот орлого хувиар

## Үндсэн үзүүлэлтүүд (KPIs)

Хяналтын самбар нийт **8 KPI үзүүлэлтийг** харуулна:

### Эгнээ 1

| Үзүүлэлт               | Тайлбар                             |
| ---------------------- | ----------------------------------- |
| **Total Revenue**      | Сонгосон хугацааны нийт орлого      |
| **Active Work Orders** | Одоо гүйцэтгэгдэж буй захиалгын тоо |
| **Avg Repair Order**   | Захиалга бүрийн дундаж дүн          |
| **Total Customers**    | Нийт харилцагчийн тоо               |

### Эгнээ 2

| Үзүүлэлт            | Тайлбар                                      |
| ------------------- | -------------------------------------------- |
| **Service Revenue** | Үйлчилгээний орлого                          |
| **Parts Revenue**   | Сэлбэгийн орлого                             |
| **Total Vehicles**  | Нийт бүртгэлтэй тээврийн хэрэгсэл            |
| **Service Mix**     | Үйлчилгээний орлогын нийт орлогод эзлэх хувь |

## Графикууд

Хяналтын самбар нь дараах графикуудыг харуулна:

- **Орлогын график** — сонгосон хугацааны өдөр бүрийн нийт орлогын шугаман график
- **Үйлчилгээний ангилалын график** — үйлчилгээний төрөл тус бүрийн орлогын дугуй график (пирог)

Графикууд нь динамик ачаалагдаж (lazy-loaded), өгөгдөл байхгүй үед тохирох хоосон төлөв харуулна.

## Сүүлийн захиалгууд

Хяналтын самбарын доод хэсэгт **Recent Work Orders** хүснэгт харагдана. Энэ хүснэгтэд:

- Захиалгын ID, харилцагчийн нэр, машины дугаар
- Захиалгын төлөв (өнгөт тэмдэглэгээтэй)
- Нийт дүн
- Үүсгэсэн огноо
- Мөр дээр дарахад тухайн захиалгын дэлгэрэнгүй хуудас руу шилжинэ

## Баруун хажуугийн самбар (Right Sidebar)

Хяналтын самбар нь баруун талд хажуугийн самбартай бөгөөд дараах хэсгүүдийг агуулна:

| Хэсэг              | Агуулга                                                               |
| ------------------ | --------------------------------------------------------------------- |
| **Contact Card**   | Сүүлд нэмсэн харилцагчийн мэдээлэл, хурдан холбогдох товч             |
| **Quick Actions**  | Шуурхай үйлдлийн товчлуурууд (шинэ захиалга, шинэ харилцагч, гэх мэт) |
| **Recent List**    | Сүүлийн үйлдлүүдийн жагсаалт                                          |
| **Status Summary** | Захиалгын төлөвүүдийн хураангуй, тоо тус бүрээр                       |

## Түргэн товчлуурууд (Quick Actions)

Хяналтын самбараас дараах үйлдлүүдийг шууд хийх боломжтой:

| Товч               | Үйлдэл                         |
| ------------------ | ------------------------------ |
| **New Work Order** | Шинэ ажлын захиалга үүсгэх     |
| **New Customer**   | Шинэ харилцагч бүртгэх         |
| **New Vehicle**    | Шинэ тээврийн хэрэгсэл бүртгэх |
| **View Reports**   | Тайлан хэсэг рүү очих          |

::: tip Зөвлөмж
Өдөр бүр ажлын эхэнд хяналтын самбараа шалгаж, өдрийн зорилтот орлогоо тохируулж, төлөвлөгөөгөө гаргахыг зөвлөж байна.
:::

::: info Хоосон төлөв
Хэрэв системд өгөгдөл байхгүй бол ("No data yet" төлөв) хяналтын самбар эхний захиалга үүсгэхийг санал болгоно. Эсвэл зөвхөн идэвхтэй захиалга байгаа боловч гүйцэтгэсэн захиалга байхгүй бол хязгаарлагдмал үзүүлэлтүүд харуулна.
:::
