# Хяналтын самбар

Хяналтын самбар (Dashboard) нь таны байгууллагын өдрийн үйл ажиллагааны ерөнхий тоймыг харуулдаг анхны хуудас юм.

## Үзүүлэлтүүд

| Үзүүлэлт | Тайлбар | Хэрэглээ |
|-----------|---------|----------|
| Өнөөдрийн захиалга | Өнөөдөр шинээр үүсгэгдсэн захиалгын тоо | Ачаалал үнэлэх |
| Гүйцэтгэж буй | Одоо хийгдэж байгаа захиалгын тоо | Ажлын төлөвлөлт |
| Өнөөдрийн орлого | Өнөөдөр төлбөр төлөгдсөн захиалгын дүн | Санхүүгийн хяналт |
| Сүүлийн үйл ажиллагаа | Сүүлийн 10 үйлдэл | Түүх хянах |
| Орлогын график | 7 хоног / сарын орлогын график | Тренд шинжилгээ |

## Түргэн товчлуурууд

Хяналтын самбараас дараах үйлдлүүдийг шууд хийх боломжтой:

- **Шинэ захиалга** — шинэ ажлын захиалга үүсгэх
- **Харилцагч хайх** — утас, нэрээр хурдан хайх
- **Өдрийн эцсийн тайлан** — өдрийн тайлан гаргах

::: tip Зөвлөмж
Өдөр бүр ажлын эхэнд хяналтын самбараа шалгаж, өдрийн төлөвлөгөөгөө гаргахыг зөвлөж байна.
:::

## Орлогын график

Хяналтын самбар дээр **7 хоног**, **30 хоногийн** орлогын график харагдана.

- График нь таны бизнесийн орлогын трендийг хянахад тусална.
- График дээрх цэгүүд дээр дарахад тухайн өдрийн дэлгэрэнгүй мэдээлэл харж болно.
- Хулганыг графикаар гүйлгэхэд өдөр тус бүрийн дэлгэрэнгүй харагдана.
