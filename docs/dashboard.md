# Хяналтын самбар

Хяналтын самбар нь байгууллагын өдөр тутмын ажиллагааг нэг дэлгэц дээрээс харах үндсэн нүүр хуудас юм.

## Хугацааны шүүлтүүр

Дээд хэсгийн хугацааны мөрөөс дараах хугацаагаар KPI болон графикуудаа шинэчилж харна:

| Сонголт | Тайлбар |
| --- | --- |
| **Today** | Өнөөдрийн үзүүлэлт |
| **This Week** | Энэ 7 хоногийн үзүүлэлт |
| **This Month** | Энэ сарын үзүүлэлт |
| **All Time** | Бүх хугацааны нийлбэр |

## Салбарын шүүлтүүр

Хяналтын самбарын баруун дээд хэсэгт **Салбар** сонголт байна.

- Нэгээс олон салбартай байгууллага бол **Бүх салбар** болон тухайн салбаруудаас сонгож харна
- Нэг л салбартай байгууллага бол систем тэр салбарыг автоматаар сонгож харуулна
- Салбар солих үед KPI, график, recent work orders, insights зэрэг dashboard-ийн өгөгдөл бүгд шинэчлэгдэнэ
- Сонгосон салбар жагсаалтад байхгүй болсон бол шүүлтүүр **Бүх салбар** төлөв рүү буцна

## Үндсэн KPI үзүүлэлтүүд

Орлого бүртгэгдсэн үед хяналтын самбар дараах картуудыг харуулна:

| Үзүүлэлт | Тайлбар |
| --- | --- |
| **Total Revenue** | Сонгосон хугацааны нийт орлого |
| **Avg Repair Order** | Захиалга бүрийн дундаж дүн |
| **Active Work Orders** | Одоогоор явагдаж буй захиалгын тоо |
| **Total Customers** | Нийт харилцагчийн тоо |
| **Service Revenue** | Үйлчилгээний орлого |
| **Parts Revenue** | Сэлбэгийн орлого |
| **Total Vehicles** | Бүртгэлтэй тээврийн хэрэгслийн тоо |
| **Service Mix** | Нийт орлогод үйлчилгээний эзлэх хувь |

Өмнөх хугацаатай харьцуулсан өөрчлөлт боломжтой үед карт дээр тренд хэлбэрээр харагдана.

## Орлого бүрдээгүй үед харагдах төлөв

Хэрэв орлого хараахан бүрдээгүй боловч идэвхтэй захиалга байгаа бол:

- Идэвхтэй ажлын тооны анхааруулга
- Хязгаарлагдмал KPI картууд
- Хоосон төлөвөөс анхны захиалга үүсгэх санал

гэсэн layout хадгалагдсан харагдац гарна.

## График ба ойлголтууд

KPI-гийн доор дараах харагдацууд байна:

- **Орлогын графикууд**: орлогын тренд болон ангиллын хуваарилалт
- **Low Stock Card**: дуусч буй сэлбэгийн анхааруулга
- **Insights**: системээс гаргасан богино тайлбар, ажиглалтууд

## Recent Work Orders

Сүүлийн захиалгуудын хүснэгт нь:

- захиалгын ID
- харилцагч
- машин
- төлөв
- нийт дүн
- огноо

зэрэг мэдээллийг харуулна.

Энэ хэсэгт нэмэлтээр:

- **Огнооны хүрээний шүүлтүүр** ашиглах
- **Clear filter** хийж хүрээг арилгах
- **Экспорт** хийх
- мөр дээр дарж захиалгын дэлгэрэнгүй рүү орох

боломжтой.

## Daily Timeline

Баруун талын хэсэгт тухайн өдрийн үйл ажиллагааны богино timeline харагдана. Энэ нь ажлын урсгал, сүүлийн хөдөлгөөнүүдийг хурдан шалгахад тохиромжтой.

## Хэрэглэх зөвлөмж

- Олон салбартай бол эхлээд салбараа сонгож, дараа нь хугацааны шүүлтүүрээ тохируулж KPI-гаа харьцуул
- Өглөө бүр хугацааны шүүлтүүрээ тохируулж KPI-гаа шалгах
- Low Stock дохиог хараад худалдан авалтын захиалгаа эрт бэлдэх
- Recent Work Orders хэсгээс өнөөдрийн яаралтай ажлуудаа нээж хянах
