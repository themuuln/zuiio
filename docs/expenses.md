# Зарлагын бүртгэл

Зарлагын бүртгэлийн хэсэг нь таны бизнесийн бүх зарлага, түүний дотор түрээс, цалин, сэлбэг, тоног төхөөрөмжийн зардлыг нэг дороос хянах боломжийг олгоно.

## Зарлагын жагсаалт

Зарлагын хуудас дараах үзүүлэлтүүдийг харуулна:

| Үзүүлэлт | Тайлбар |
|-----------|---------|
| **Total Expenses** | Бүртгэлтэй нийт зарлагын тоо |
| **Total Amount** | Бүртгэлтэй бүх зарлагын нийт дүн |
| **This Month** | Тухайн сарын нийт зарлагын дүн |
| **Overdue** | Хугацаа хэтэрсэн төлөгдөөгүй зарлагын тоо |
| **Unpaid** | Хараахан төлөгдөөгүй зарлагын дүн |

KPI картууд **5 баганатай** хүснэгтээр ээлжлэн харагдана (мобайл дээр 2 багана, tablet дээр 3, дэлгэц дээр 5).

### Шүүлтүүрийн самбар

Хүснэгтийн дээд хэсэгт дараах шүүлтүүрүүд байрлана:

| Шүүлтүүр | Тайлбар |
|----------|---------|
| **Хайлт** | Тодорхойлолт, ханган нийлүүлэгч, лавлагаа дугаараар хайж болно |
| **Ангилал** | Ангиллын dropdown сонголт (All Categories) |
| **Огнооны хүрээ** | DateRangePicker-аар эхлэх/дуусах огноо сонгох |
| **Төлбөрийн төлөв** | ToggleGroup: All / Unpaid / Overdue / Paid |
| **Шүүлтүүр цэвэрлэх** | Шүүлтүүр идэвхтэй үед гарч ирэх "Clear filters" товч |

Шүүлтүүрийн тоо хэмжээг харуулна ("X results" гэж).

### Хүснэгтийн мэдээлэл

Зарлагын жагсаалтад дараах мэдээлэл харагдана:

| Талбар | Тайлбар |
|--------|---------|
| **Огноо** | Зарлагын бүртгэгдсэн огноо (Mon DD, YYYY) |
| **Тодорхойлолт** | Зарлагын дэлгэрэнгүй тодорхойлолт (лавлагаа дугаартай) |
| **Ангилал** | Зарлагын төрөл (өнгөт тэмдэглэгээтэй) |
| **Ханган нийлүүлэгч** | Зарлага хүлээн авсан байгууллага / хувь хүн |
| **Төлөх хугацаа** | Төлбөр төлөх ёстой огноо (хэтэрсэн бол улаанаар тэмдэглэгдэнэ + ⚠️ дүрс) |
| **Дүн** | Зарлагын дүн (₮ тэмдэгтэй) |
| **Төлөв** | Төлсөн / Төлөгдөөгүй / **Хугацаа хэтэрсэн** (Overdue) |
| **→** | Дэлгэрэнгүй харах товч |

- Бүх баганаар **эрэмбэлэх** боломжтой
- Хүснэгт нь **20 мөр** нэг хуудсанд харуулна
- Мобайл дээр зарлага бүрийг **карт хэлбэрээр** харуулна (огоноо, төлөв, тодорхойлолт, дүн)
- Зарлагын мөр дээр **дарж** дэлгэрэнгүй хэсэг нээгдэнэ

### Excel экспорт

Зарлагын жагсаалтыг Excel-д экспортлох боломжтой. Экспортод дараах мэдээлэл багтана: Date, Description, Vendor, Category, Amount, Reference, Status.

## Шинэ зарлага бүртгэх

1. Дээд хэсэгт байрлах **"Add Expense"** товч эсвэл хоосон үеийн "Record Your First Expense" товч дарна уу.
2. Дараах талбаруудыг бөглөнө үү:

| Талбар | Заавал | Тайлбар |
|--------|--------|---------|
| **Тодорхойлолт (Description)** | Тийм | Зарлагын дэлгэрэнгүй тодорхойлолт (утгаа оруулах) |
| **Дүн (Amount)** | Тийм | Зарлагын мөнгөн дүн (0-с их, ₮ тэмдэгтэй) |
| **Зарлагын огноо** | Үгүй | Анхдагчаар өнөөдрийн огноо |
| **Төлөх хугацаа (Due Date)** | Үгүй | Төлбөр төлөх ёстой огноо |
| **Ангилал** | Үгүй | Зарлагын төрөл сонгох (dropdown) |
| **Ханган нийлүүлэгч** | Үгүй | Нийлүүлэгч байгууллагын нэр |
| **Татварын дүн** | Үгүй | Нэмэгдсэн татварын дүн (АНХДАГЧ: 0) |
| **Төлбөрийн хэрэгсэл** | Үгүй | cash / card / bank_transfer / manual |
| **Лавлагаа дугаар** | Үгүй | Нэхэмжлэх эсвэл гүйлгээний лавлагаа дугаар |
| **Төлсөн эсэх (Paid)** | Үгүй | Чек бокс — шуурхай төлсөн гэж тэмдэглэх |
| **Тэмдэглэл (Notes)** | Үгүй | Нэмэлт тайлбар (3 мөртэй textarea) |

### Баталгаажуулалт

- **Description** болон **Amount** талбарууд заавал бөглөх ёстой
- Дүн 0-с бага эсвэл хоосон бол алдааны мессеж гарна
- Төлсөн чек боксыг идэвхжүүлбэл `paid_at` огноо автоматаар тодорхойлогдоно

### Хугацаа хэтэрсэн зарлага (Overdue)

Зарлагын төлөх хугацаа (Due Date) хэтэрсэн боловч төлөгдөөгүй бол систем автоматаар **Overdue** гэж тэмдэглэнэ:

- **Overdue шүүлтүүр** — зөвхөн хугацаа хэтэрсэн зарлагыг харах
- **Улаан тэмдэглэгээ** — хүснэгтэд хугацаа хэтэрсэн огноо, төлөв улаанаар тэмдэглэгдэнэ + ⚠️ дүрс нэмэгдэнэ
- **KPI карт** — хэдэн зарлагын хугацаа хэтэрсэнийг тоо хэлбэрээр харуулна (Overdue карт)
- **Дэлгэрэнгүй хэсэг** — захиалгын дэлгэрэнгүйд Due Date ба Overdue төлөв харагдана

## Зарлагын ангилал

Зарлагын ангилал нь зардлуудыг төрөл тус бүрээр бүлэглэх боломжийг олгоно. Ангиллын хуудас дээр ангилалууд **3 баганатай карт хэлбэрээр** харуулагдана.

### Ангиллын карт бүр

Ангиллын карт бүрт:
- Дээд хэсэгт **өнгөт зураас** (1.5px)
- Ангиллын **нэр**
- **Тайлбар** (байвал, 2 мөр хүртэл)
- Засах / Устгах товчууд (карт дээр hover хийхэд гарч ирнэ)

### Анхдагч ангилалууд

Систем шинэ байгууллага бүрт дараах анхдагч ангилалуудыг автоматаар үүсгэдэг:

| Ангилал | Өнгө | Дүрс |
|----------|-------|------|
| Rent & Utilities | Цэнхэр | 🏢 |
| Salaries & Wages | Ягаан | 👥 |
| Parts & Supplies | Шар | 📦 |
| Equipment & Tools | Ногоон | 🔧 |
| Marketing & Advertising | Ягаан | 📣 |
| Insurance | Цайвар цэнхэр | 🛡️ |
| Taxes & Licenses | Улаан | 🧾 |
| Transportation & Fuel | Улбар шар | 🚚 |
| Office Expenses | Индиго | 📓 |
| Other | Саарал | … |

### Ангилал удирдах

**Шинэ ангилал нэмэх:**
1. **Зарлага → Ангилал** хэсэгт орно.
2. **"Add Category"** товч дарна.
3. Дараах талбаруудыг бөглөнө:

| Талбар | Заавал | Тайлбар |
|--------|--------|---------|
| **Нэр (Name)** | Тийм | Ангиллын нэр |
| **Тайлбар (Description)** | Үгүй | Нэмэлт тодорхойлолт |
| **Өнгө (Color)** | Тийм | 9 өнгөнөөс сонгох: Blue, Purple, Orange, Green, Pink, Cyan, Red, Amber, Gray |

4. **"Save"** товч дарж хадгална.

**Ангилал засах:**
- Ангиллын карт дээрх ✏️ засах товч дээр дарна
- Нэр, тайлбар, өнгийг өөрчлөн **"Save"** дарна

**Ангилал устгах:**
- Ангиллын карт дээрх 🗑️ устгах товч дээр дарна
- Баталгаажуулалтын цонх гарч ирнэ: "Are you sure you want to delete X?"
- **"Delete"** дарж баталгаажуулна (soft-delete)

::: warning Ангилал устгахад анхааруулга
Ангилал устгахад тухайн ангилалд хамаарах зарлагууд нөлөөлөхгүй — тэдгээр зарлагууд ангилалгүй болно.
:::

### Ангилалаар тайлагнах

Санхүүгийн тайланд зарлагыг ангилалаар нь бүлэглэн харуулж, аль төрлийн зардал хамгийн их байгааг тодорхойлох боломжтой.

## Зарлага засах, устгах

- **Засах**: Зарлагын мөр дээр дарж дэлгэрэнгүй хэсгээс мэдээллийг шинэчилнэ.
- **Устгах**: Зарлагыг зөөлөн устгалт (soft-delete) хийнэ. Өгөгдөл мэдээллийн санд үлдэх боловч жагсаалтад харагдахгүй.

## Баруун sidebar

Зарлагын хуудас дээр баруун талын sidebar дээр:
- **This Month**: Энэ сарын нийт зарлага, төлөгдөөгүй зарлага
- **Categories**: Ангилал бүрийн нэр, тоо

## Тайлантай холбоо

Зарлагын мэдээлэл нь **Тайлан** хуудастай нэгдсэн. Тайлан хэсгээс:
- **Сарын зарлага** — энэ сарын нийт зарлагын дүн
- **Цэвэр ашиг** — Нийт орлого − Нийт зарлага
- **Уртрагийн зарлагын өгөгдөл** — түүхэн зарлагын үзүүлэлтүүд

::: tip Зөвлөмж
Зарлагыг тогтмол бүртгэж байх нь бизнесийн ашиг, алдагдлыг бодитой үнэлэх, татварын тайлан гаргахад тусална. Сар бүрийн эцэст зарлагын тайлангаа шалгаж, төсөвтөө хяналт тавихыг зөвлөж байна.
:::

::: info Ангилал тохируулах
Та өөрийн бизнесийн онцлогт тохируулан шинэ ангилал нэмэх, одоо байгаа ангилалын нэр, өнгө, тайлбарыг өөрчлөх боломжтой. Ангилал бүрт 9 өнгөнөөс сонгох боломжтой бөгөөд эдгээр өнгө нь жагсаалтад ангиллын badge болон картын зураас болж ашиглагдана.
:::
