# Засварын булан (Bay View)

Засварын булан (Bay View) нь таны цехийн булангуудын бодит харагдацыг харуулна. Эндээс аль буланд ямар захиалга хийгдэж байгааг нэг дороос харж болно.

TOLOM нь **Bay View v1** (сонгодог) болон **Bay View v2** (шинэчлэгдсэн, drag-and-drop хийх боломжтой) гэсэн хоёр хувилбартай. Энэхүү гарын авлага нь v2 хувилбарыг тайлбарлана.

## Булангийн харагдац (v2)

Bay View v2 нь **3 харагдацтай**:

| Харагдац           | Тайлбар                                  |
| ------------------ | ---------------------------------------- |
| **Grid** (анхдагч) | Булангуудыг grid байдлаар харуулна       |
| **Kanban**         | Төлөвөөр нь багана болгон харуулна       |
| **List**           | Хүснэгт хэлбэрээр, хугацааны үзүүлэлттэй |

Булангийн төлөв, өнгө:

| Төлөв         | Тайлбар                                                  |
| ------------- | -------------------------------------------------------- |
| Чөлөөтэй      | Буланд захиалга байхгүй, шинэ захиалга авахад бэлэн      |
| Захиалгатай   | Буланд гүйцэтгэгдэж буй захиалга байна                   |
| Хүлээгдэж буй | Дараалалд хүлээгдэж буй захиалгууд, буланд томилогдоогүй |

PIN хамгаалалтыг Тохиргоо хэсгээс тохируулж болно.

## PIN хамгаалалт

Засварын буланг PIN кодоор хамгаалах боломжтой. Энэ нь зөвшөөрөлгүй хандалтаас сэргийлнэ.

1. **Тохиргоо** хэсэгт очно уу.
2. **"Засварын булангийн PIN"** хэсэгт 4-6 оронтой PIN оруулна уу.
3. **"Хадгалах"** товч дарна уу.
4. Дараагийн удаа булангийн хуудсыг нээхэд PIN шаардах болно.

::: warning PIN кодоо нууцлах
PIN кодоо хэнд ч бүү хэлээрэй. PIN кодыг тогтмол сольж байхыг зөвлөж байна.
:::

## Хүлээгдэж буй захиалгууд

Хэрэв бүх булан завгүй байвал шинэ захиалгуудыг **Хүлээгдэж буй** жагсаалтад харуулна. Булан сулрах үед захиалгыг тухайн буланд шилжүүлж болно.

## Үйлчилгээний дараах мэдээлэл

Захиалга **"Хүлээлгэхэд бэлэн"** болгох үед дараах мэдээллийг бүртгэх цонх нээгдэнэ:

### Механикийн мэдээлэл

| Талбар                            | Тайлбар                                                                                                                           |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Одометр (км)**                  | Машины одометрийн заалтыг бүртгэнэ. Өмнөх заалтаас автоматаар бөглөгдөнө                                                          |
| **Үйлчилгээ тус бүрийн интервал** | Үйлчилгээний каталогийн анхдагч интервалаас автоматаар бөглөгдөнө. Шаардлагатай бол өөрчилж болно (жишээ: синтетик тос 10,000 км) |
| **Чухал ач холбогдол**            | Стандарт / Чухал / Яаралтай — дараагийн үйлчилгээний тэргүүлэх чиглэл                                                             |
| **Дараагийн хугацаа**             | Интервалаас автоматаар тооцогдоно                                                                                                 |
| **Тэмдэглэл**                     | Механикийн нэмэлт тэмдэглэл                                                                                                       |

Мэдээллийг хадгалснаар:

- Үйлчилгээ тус бүрийн зөвлөмж хадгалагдана
- Машины үйлчилгээний хуваарь автоматаар шинэчлэгдэнэ
- Дараагийн үйлчилгээний сануулга автоматаар үүсгэгдэнэ
- Машины одометрийн заалт шинэчлэгдэнэ

### Харилцагчид хүлээлгэн өгөх

**"Дууссан"** төлөвт шилжүүлэх үед харилцагчийн сэтгэл ханамжийн мэдээлэл цуглуулна:

| Талбар            | Тайлбар                               |
| ----------------- | ------------------------------------- |
| **Сэтгэл ханамж** | 1-5 одны үнэлгээ                      |
| **Санал хүсэлт**  | Харилцагчийн нэмэлт санал             |
| **Сануулга**      | Үйлчилгээний сануулгыг авах эсэх      |
| **Дараагийн цаг** | Дараагийн үзлэгийн огноо (заавал биш) |

### Үйлчилгээний дүгнэлт

Захиалга дууссаны дараа хэвлэх боломжтой дүгнэлт харуулна:

- Гүйцэтгэсэн үйлчилгээнүүдийн жагсаалт
- Үйлчилгээ тус бүрийн дараагийн хугацаа
- Нийт дүн
- **Хэвлэх** — хэвлэгч рүү илгээнэ
- **Хуваалцах** — дүгнэлтийг хуваалцах
- **Дараагийн цаг захиалах** — дараагийн үзлэгийн огноо сонгох
