# Механикийн гүйцэтгэлийн үнэлгээ

Механикийн гүйцэтгэлийн хуудас нь механикчдын ажлын бүтээмж, орлого, цагийн үзүүлэлтүүдийг нэгтгэн харуулна.

## Хугацааны сонголт

Дээд хэсэгт **7 хоног / Сар / Улирал** гэсэн гурван үеээр сонгож харах боломжтой.

## KPI картууд

| Карт | Тайлбар |
| --- | --- |
| **Нийт орлого** | Сонгосон үеийн механикчдын нийт орлого |
| **Захиалгын тоо** | Гүйцэтгэсэн нийт захиалга |
| **Механикчдын тоо** | Идэвхтэй механикчдын тоо |
| **Дундаж захиалга** | Нэг механикчийн дундаж захиалгын тоо |

## Механикчдын жагсаалт

Механикчин бүрийн мөрөнд:

- Нэр
- Гүйцэтгэсэн захиалгын тоо
- Нийт орлого
- Дундаж орлого
- Ажилласан цаг (хэрэв цагийн бүртгэл идэвхтэй бол)

## График дүрслэл

Механикчдын гүйцэтгэлийг баганан графикаар харж болно. Графикаас механикчдын орлого, захиалгын тоог харьцуулан харах боломжтой.

## Бусад холбоосууд

Баруун талын самбарт (sidebar) дараах хэсгүүд рүү холбоосууд байрлана:

- **Төлвийн хураангуй** — захиалгын төлвүүдийн тоо
- **Сүүлийн үйл ажиллагаа** — хамгийн сүүлийн захиалгуудын жагсаалт
