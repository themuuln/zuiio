# Харилцагчид мэдэгдэл

Нэхэмжлэлийн сануулга, борлуулалтын баримтыг автомат имэйлээр илгээх.

**Яагаад хэрэгтэй вэ:** Харилцагчид төлбөрийн хугацааг мартахаас сэргийлнэ.

## Хэрэгжүүлэх тэмдэглэл

- `nodemailer` аль хэдийн dependency-д байгаа
- Telegram notification загвар бий — түүн дээр суурилна
- Имэйл загварууд (HTML template) хэрэгтэй
