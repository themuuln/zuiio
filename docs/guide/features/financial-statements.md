# Санхүүгийн тайлан

Ашиг-алдагдлын тайлан, баланс — бизнесийн үндсэн тайлангууд.

**Яагаад хэрэгтэй вэ:** Бизнесийн санхүүгийн байдлыг харах үндсэн хэрэгсэл.

## Хэрэгжүүлэх тэмдэглэл

- Trial balance query аль хэдийн бий
- P&L = орлого (борлуулалт) - зарлага (зардал)
- Balance Sheet = актив (бараа, авлага) - пассив (өглөг)
- Хэвлэх болон CSV export дэмжлэг
