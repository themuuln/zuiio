# Харилцагчийн портал

Харилцагчийн портал нь таны үйлчлүүлэгчдэд зориулсан онлайн хуудас юм. Порталыг харилцагчид portal token-оор эсвэл имэйл/нууц үгээр нэвтрэх боломжтой. Порталын URL-ийг нэхэмжлэх эсвэл имэйлээр илгээж болно.

## Нэвтрэх

### Нэвтрэх аргууд

| Арга | Тайлбар |
| --- | --- |
| **Portal Token** | `Authorization: Bearer <token>` header-ээр API хүсэлт илгээх |
| **Имэйл + Нууц үг** | Supabase auth ашиглан нэвтрэх |

### Нэвтрэх урсгал

1. Системээс илгээсэн портал холбоос дээр дарна
2. Имэйл хаяг болон нууц үгээ оруулна
3. Амжилттай нэвтэрсний дараа үндсэн самбар харагдана

### Нууц үг тохируулах

Портал руу анх нэвтрэхэд нууц үг тохируулах шаардлагатай. `/auth/customer/set-password` хуудсан дээр:
- Имэйл хаяг
- Нууц үг
- Нууц үг баталгаажуулах

Дараа нь "Toхиргоо" хуудас дээрээс нууц үгээ солих боломжтой.

## Навигаци

Portal layout нь дээрх navigation bar-той байна:

| Навигаци | Зам | Икон |
| --- | --- | --- |
| **Үндсэн самбар** | `/portal` | Wrench |
| **Машинууд** | `/portal/vehicles` | Car |
| **Ажлын захиалгууд** | `/portal/work-orders` | ClipboardList |
| **Нэхэмжлэх** | `/portal/invoices` | FileText |
| **Тохиргоо** | `/portal/settings` | Settings |
| **Захиалга өгөх** | `/portal/booking` | CalendarPlus |

Дээрх толгой хэсэгт харилцагчийн нэр, "Logout" товч байна. Доорх footer-т "TOLOM: Auto Service Management" бичиг байна.

## Үндсэн самбар (Dashboard)

`/portal` — Портал нэвтэрсэн дараа анх харах хуудас.

### Статистик картууд (3 карт)

| Карт | Агуулга |
| --- | --- |
| **Миний машинууд** | Бүртгэлтэй тээврийн хэрэгслийн тоо (Car icon) |
| **Нийт үзлэг** | Нийт үйлчилгээний тоо (`total_visits`) |
| **Сүүлийн үзлэг** | Хамгийн сүүлд ирсэн огноо |

### Машинуудын хурдан жагсаалт

- Дээрх картуудын доор машинуудын жагсаалт гарна (дээд талд "View all" холбоос)
- Дээд 5 машиныг харуулна
- Бүр машины дугаар, марк, загвар, жил харуулна
- Дээр дарахад тухайн машины дэлгэрэнгүй хуудас руу шилжинэ
- Хэрэв машин үгүй бол "No vehicles" гэсэн мессеж гарна

## Тээврийн хэрэгсэл (Vehicles)

`/portal/vehicles` — Харилцагчийн бүртгэлтэй машинуудын жагсаалт.

### Жагсаалт

Бүр машины карттай (Card):
- **Дугаар** (plate_number) — картны гарчиг
- **Марк, загвар** (make, model) — жижиг мөрөнд
- **Жил** (year) — загварын дараа эсвэл мөрний доор
- **Өнгө** (color) — хэрэв байвал мөрний доор

Дээр дарахад `/portal/vehicles/[id]` хуудас руу шилжинэ.

### Машины дэлгэрэнгүй (`/portal/vehicles/[id]`)

#### Машины мэдээлэл

| Талбар | Тайлбар |
| --- | --- |
| Дугаар | Тээврийн хэрэгслийн улсын дугаар |
| Марк, загвар, жил | Make + Model + Year |
| VIN | Vehicle Identification Number (хэрэв байвал) |
| Одометр | Kilometers-ээр |
| Өнгө | Машиний өнгө |

#### Ирэх үйлчилгээ (Upcoming Services)

- Дараагийн төлөвлөсөн үйлчилгээний жагсаалт
- Үйлчилгээний нэр, дуусах огноо, километр
- "Urgent" тэмдэглэгээр яаралтай үйлчилгээг ялгана

#### Үйлчилгээний түүх (Service History)

- Холбогдсон ажлын захиалгуудын жагсаалт
- Төлөв badge (New, In Progress, Diagnosing, Ready for Pickup, Completed, Cancelled)
- Огноо, нийт дүн (MNT)
- Дээр дарахад ажлын захиалгын дэлгэрэнгүй хуудас руу шилжинэ

## Ажлын захиалга (Work Orders)

`/portal/work-orders` — Харилцагчийн бүх ажлын захиалгуудын жагсаалт.

### Жагсаалт

Бүр ажлын захиалгын карт:
- **Тээврийн хэрэгсэл** — дугаар, марк, загвар
- **Төлөв badge** — төлөв бүрийн өнгөтэй:
  - `Completed` — default (нухцар)
  - `In Progress` — secondary (шар)
  - `Diagnosing` — secondary (шар)
  - `New` — outline (цэнхэр)
  - `Ready for Pickup` — secondary (ногоон)
  - `Cancelled` — destructive (улаан)
- **Тайлбар** — ажлын захиалгын нэр/тодорхойлолт
- **Нийт дүн** — MNT-ээр
- **Огноо** — үүсгэсэн огноо

### Ажлын захиалгын дэлгэрэнгүй (`/portal/work-orders/[id]`)

Дэлгэрэнгүй хуудас дээр дараах хэсгүүд гарна:

#### Толгой мэдээлэл

| Талбар | Тайлбар |
| --- | --- |
| Нэр | Ажлын захиалгын нэр/тодорхойлолт |
| Төлөв | Status badge (дээрх өнгөтэй) |
| Огноо | Үүсгэсэн, эхэлсэн, дуусгасан огнууд |
| Одометр | Үйлчилгээний үеийн километр |
| Нийт дүн | Бүх үйлчилгээ + эд хэрэгслийн нийлбэр |

#### Гомдол ба оношлогоо

- **Гомдол** (Complaint) — харилцагчийн хүсэлт/гомдол
- **Оношлогоо** (Diagnosis) — механикийн оношлогоо

#### Үйлчилгээний хүснэгт

| Багана | Тайлбар |
| --- | --- |
| Үйлчилгээ | Үйлчилгээний нэр |
| Тоо | Количеств |
| Үнэ | Нэгжийн үнэ (MNT) |
| Дүн | Нийт дүн (MNT) |
| Тэмдэглэл | Нэмэлт мэдээлэл (хэрэв байвал) |

#### Эд хэрэгслийн хүснэгт

| Багана | Тайлбар |
| --- | --- |
| Эд хэрэгсэл | Эд хэрэгслийн нэр |
| Дугаар | Part number |
| Тоо | Количеств |
| Үнэ | Нэгжийн үнэ (MNT) |
| Дүн | Нийт дүн (MNT) |
| Тэмдэглэл | Нэмэлт мэдээлэл (хэрэв байвал) |

#### Төлөвийн цахим хугацаа (Status Timeline)

Төлөв бүрийн өөрчлөлтийг timeline хэлбэрээр харуулна:
- Дүрс (dot) — тухайн төлөвийн өнгө
- Нэр — төлөвийн нэр
- Огноо/цаг
- Тэмдэглэл (хэрэв байвал)
- Хүлээлтийн мөр — timeline дээрхи холбоос

#### Нэхэмжлэхүүд

Холбогдсон нэхэмжлэхүүдийн жагсаалт:
- Нэхэмжлэхийн дугаар (`#invoice_number`)
- Төлөв badge (`paid`, `sent`, `overdue`, `draft`, `partial`, `cancelled`)
- Нийт дүн (MNT)
- Огноо, хугацаа
- "View" товч — нэхэмжлэхийг нийтийн холбоосоор нээх

### Realtime шинэчлэл

Ажлын захиалгын дэлгэрэнгүй хуудас дээр **Supabase Realtime** ашиглан төлөвийн өөрчлөлтийг бодит цагт хүлээн авна.

## Нэхэмжлэх (Invoices)

`/portal/invoices` — Харилцагчийн нэхэмжлэхүүдийн жагсаалт.

### Нэхэмжлэхийн жагсаалт

Бүр нэхэмжлэхийн карт:
- **Дугаар** (`#invoice_number`)
- **Төлөв badge** — төлөв бүрийн өнгө:
  - `paid` — default (нухцар)
  - `sent` — secondary (шар)
  - `overdue` — destructive (улаан)
  - `draft` — outline
  - `partial` — secondary
  - `cancelled` — outline
- **Огноо** — гаргасан огноо
- **Машины дугаар** — хэрэв байвал
- **Нийт дүн** — MNT-ээр

### Төлбөр

Төлбөр хийх боломжтой төлөвүүд: `sent`, `overdue`, `partial`, `draft`

"Pay Now" товч дээр дарахад:
1. Төлбөрийн диалог нээгдэнэ
2. Банкны шилжүүлгийн мэдээлэл харна
3. Төлбөрийн нийт дүн
4. Төлбөрийн тэмдэглэл
5. "Confirm Payment" товч дээр дарж төлбөрийг баталгаажуулна

### Нэмэлт үйлдлүүд

- **View** — нийтийн холбоосоор нэхэмжлэхийг шинэ цонхонд нээх (`/invoice/[public_token]`)
- **PDF** — нэхэмжлэхийг PDF болгон татаж авах (`/api/invoice/public/[public_token]/pdf`)

## Захиалга өгөх (Booking)

`/portal/booking` — Харилцагч шинэ үйлчилгээний захиалга өгөх хуудас.

### Захиалгын форм

| Талбар | Шаардлагатай | Тайлбар |
| --- | --- | --- |
| **Нэр** | Тийм | Харилцагчийн нэр (автоматаар нөхөгдсөн) |
| **Утас** | Тийм | Монгол утасны формат (+976 XXXX XXXX) |
| **Машины дугаар** | Тийм | Тээврийн хэрэгслийн улсын дугаар |
| **Захисан огноо** | Үгүй | Хүсэлтэй өдөр (өнөөдрөөс хойш) |
| **Тэмдэглэл** | Үгүй | Ямар үйлчилгээ шаардлагатай талаар (3 мөр) |

### Захиалгын урсгал

1. Формыг бөглөх (нэр, утас, дугаар — заавал)
2. "Request Appointment" товч дээр дарах
3. Амжилттай илгээсний дараа амжилтын мессеж харна
4. Механик холбогдож цагийг тохируулна

## Тохиргоо (Settings)

`/portal/settings` — Харилцагчийн хувийн тохиргоо.

### Холбоо барих мэдээлэл (Contact Info)

| Талбар | Тайлбар |
| --- | --- |
| **Нэр** | Харилцагчийн нэр |
| **Утас** | Утасны дугаар |
| **Имэйл** | Имэйл хаяг |

### Нууц үг

- "Нууц үг тохируулах" товч дээр дарахад нууц үг солих хуудас руу шилжинэ
- Амжилттай солисны дараа ногоон тэмдэглэгээр харуулна

## API замууд

| Зам | Метод | Тайлбар |
| --- | --- | --- |
| `/api/portal/vehicles` | GET | Харилцагчийн машинуудын жагсаалт |
| `/api/portal/vehicles/[id]` | GET | Машины дэлгэрэнгүй (машин + ажлын захиалгууд + ирэх үйлчилгээ) |
| `/api/portal/work-orders` | GET | Ажлын захиалгуудын жагсаалт |
| `/api/portal/work-orders/[id]` | GET | Ажлын захиалгын дэлгэрэнгүй (үйлчилгээ, эд хэрэгсэл, timeline, нэхэмжлэх) |
| `/api/portal/invoices` | GET | Нэхэмжлэхүүдийн жагсаалт |
| `/api/portal/invoices/[id]/pay` | POST | Төлбөр хийх |
| `/api/portal/bookings` | POST | Захиалга илгээх |
| `/api/portal/customer` | GET | Харилцагчийн мэдээлэл |
| `/api/portal/set-password` | POST | Нууц үг тохируулах |

## Аюулгүй байдал

- **Rate limiting** — хэт их хүсэлтээс хамгаалах (authRateLimiter)
- **RLS (Row Level Security)** — харилцагч зөвхөн өөрийнхөө мэдээллийг харна
- **Portal Token** — хүчтэй нууцлалтай токен, зөвхөн өөрийнхөө харилцагчийг идэвхжүүлнэ
- **Supabase Auth** — нэвтрэлтийн session-д нэмэлт хамгаалалт

## Практик зөвлөмжүүд

- **Нэхэмжлэхийн холбоосыг** имэйл эсвэл SMS-ээр илгээ — харилцагч шууд харах боломжтой
- **PDF татаж авах** боломжийг ашиглан нэхэмжлэхийг хэвлэж болно
- **Zахиалга өгөх** хуудсыг харилцагчийн portal холбоосоор илгээ — хэрэглэгч өөрөө захиалга өгч чадна
- **Нууц үгийг** анх нэвтрэхэд заавал тохируулна — энэ нь аюулгүй байдлын шаардлага
- **Realtime** ашиглан ажлын захиалгын төлөв өөрчлөгдөхөд харилцагч шууд харна
- **Төлбөрийн** "Confirm Payment" нь банкны шилжүүлгийг баталгаажуулна — зөвхөн мөнгө шилжүүлсний дараа дарна уу
