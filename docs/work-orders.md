# Ажлын захиалга

Ажлын захиалга (Work Order) нь үйлчлүүлэгчийн машинд хийх засвар үйлчилгээг бүртгэх үндсэн баримт бичиг юм.

## Шинэ захиалга үүсгэх

Шинэ захиалга нь **баруун талын самбар (Sheet)** хэлбэрээр нээгдэх wizard-ээр үүсгэгдэнэ. Wizard нь дараах үе шатуудаас бүрдэнэ:

1. **Customer (Харилцагч)** — нэр, утас эсвэл улсын дугаараар хурдан хайх, эсвэл шинэ харилцагч үүсгэх.
2. **Vehicle (Машин)** — харилцагч сонгосны дараа тухайн харилцагчийн машинуудаас сонгох.
3. **Complaint (Гомдол)** — захиалгын шалтгаан, гомдлын тодорхойлолт.
4. **Services (Үйлчилгээ)** — каталогаас сонгох эсвэл шинээр оруулах.
5. **Parts (Сэлбэг)** — шаардлагатай сэлбэгүүдийг бүртгэх.
6. **Mechanic (Механикч)** — захиалгыг гүйцэтгэх механикчийг томилох.

Сүүлийн шатанд үйлчилгээ, сэлбэгийн нийт дүн харагдах бөгөөд **Create** товч дарж захиалгыг хадгална.

::: tip Үнийн түүх
Үйлчилгээ болон сэлбэгийн үнийн түүх автоматаар хадгалагдана. Дараагийн удаад ижил машинд ижил үйлчилгээ хийхэд сүүлийн 3 үнийг харуулж, хамгийн сүүлийн үнийг автоматаар санал болгоно.
:::

## Захиалгын төлөвүүд

| Төлөв                 | Дүрс         | Тайлбар                                       | Дараагийн төлөв            |
| --------------------- | ------------ | --------------------------------------------- | -------------------------- |
| **Шинэ**              | 🔵 Цэнхэр    | Захиалга шинээр үүсгэгдсэн                    | Оношилгоо / Цуцлагдсан     |
| **Оношилгоо**         | 🟡 Шар       | Машины гэмтэл оношилж байгаа                  | Гүйцэтгэж буй / Цуцлагдсан |
| **Гүйцэтгэж буй**     | 🟠 Улбар шар | Засвар үйлчилгээ хийгдэж байгаа               | Хүлээлгэхэд бэлэн          |
| **Хүлээлгэхэд бэлэн** | 🟢 Ногоон    | Засвар дууссан, харилцагчид хүлээлгэхэд бэлэн | Дууссан                    |
| **Дууссан**           | ⚪ Саарал    | Захиалга бүрэн дууссан, төлбөр төлөгдсөн      | —                          |
| **Цуцлагдсан**        | 🔴 Улаан     | Захиалга цуцлагдсан                           | —                          |

::: tip Үйлчилгээний дараах мэдээлэл
Захиалгыг **"Хүлээлгэхэд бэлэн"** болгох үед одометрийн заалт, үйлчилгээ тус бүрийн дараагийн интервал, тэргүүлэх чиглэлийг бүртгэх цонх нээгдэнэ. Энэ мэдээлэл нь үйлчилгээний сануулгын системд автоматаар шилжиж, харилцагчид дараагийн үйлчилгээг сануулахад ашиглагдана.
:::

**"Дууссан"** төлөвт шилжүүлэх үед харилцагчийн сэтгэл ханамжийн үнэлгээ (1-5 од), санал хүсэлт, сануулгын зөвшөөрөл, дараагийн цаг захиалах боломжтой.

::: warning Төлөв өөрчлөх
Төлөв бүрийн өөрчлөлт нь захиалгын түүхэнд бүртгэгддэг бөгөөд буцаан өөрчлөх боломжгүй (immutable ledger). Төлөв өөрчлөхдөө болгоомжтой байна уу.
:::

## Үйлчилгээ нэмэх

Захиалгад нэг буюу хэд хэдэн үйлчилгээ нэмж болно:

- **Үйлчилгээний нэр** — каталогаас сонгосон эсвэл гараар оруулсан
- **Тоо хэмжээ** — нэгжээр (тос солих × 1, лаа солих × 4)
- **Үндсэн үнэ** — каталогийн үнэ
- **Сүүлийн үнэ** — ижил үйлчилгээний өмнөх 3 үнэ харагдаж, хамгийн сүүлийн үнэ автоматаар бөглөгдөнө
- **Хямдрал** — мөнгөн дүнгээр эсвэл хувиар
- **Эцсийн үнэ** — автоматаар бодогдоно

## Сэлбэг нэмэх

Захиалгад ашигласан сэлбэгийг бүртгэнэ:

- **Сэлбэгийн нэр**, **код**
- **Тоо хэмжээ**, **нэгж үнэ**
- **Сүүлийн үнэ** — өмнөх сэлбэгийн үнэ байвал нэгж үнэд санал болгоно
- **Эцсийн үнэ** — автоматаар бодогдоно

## Захиалгын түүх

Захиалга бүрийн дэлгэрэнгүй хуудаснаас дараах мэдээллийг харж болно:

- ✅ Үйлчилгээний жагсаалт
- ✅ Сэлбэгийн жагсаалт
- ✅ Төлөвийн өөрчлөлтийн түүх (хэн, хэзээ өөрчилсөн)
- ✅ Үнийн дэлгэрэнгүй
