# Ажлын захиалга (Work Orders)

Ажлын захиалга нь харилцагч, машин, үйлчилгээ, сэлбэг, механикч, төлбөрийн урсгалыг холбодог үндсэн баримт бичиг юм. Захиалга бүр Bay View дээр харагдаж, бодит цагийн горимоор шинэчлэгддэг.

## Жагсаалтын хуудас

### Хэрэглэгчийн интерфейс

Жагсаалтын хуудаснаас дараах зүйлсийг нэг дороос удирдана:

- **Хайлт** — харилцагчийн нэр, улсын дугаар, эсвэл захиалгын дугаараар хайх
- **Төлвийн шүүлтүүр (filter chips)** — бүх төлөвөөр шүүх, зөвхөн идэвхтэйгээр шүүх эсвэл тус бүрээр шүүх
- **Төлвийн тоо** — идэвхтэй захиалгуудын тоог өнгөт badge-аар харуулна
- **Excel экспорт** — жагсаалтыг `.xlsx` файл болгон экспортлох (WO#, Харилцагч, Машин, Механикч, Төлөв, Огноо, Нийт дүн, Үйлчилгээний өртөг, Сэлбэгийн өртөг, Ашиг)
- **Мөр дээр дарж** захиалгын дэлгэрэнгүй хуудас руу орох
- **Захиалга цуцлах** — мөрийн цэсээр эсвэл төлөвийн dropdown-оос

### Баганууд (Columns)

| Багана | Тайлбар |
| --- | --- |
| **ID** | Захиалгын дугаар (жишээ: `#a1b2c3d4`) |
| **Харилцагч** | Харилцагчийн нэр + улсын дугаар |
| **Машин** | Машиний брэнд, загвар, улсын дугаар |
| **Механикч** | Томилогдсон механикчийн нэр |
| **Төлөв** | Өнгөт badge + dropdown-оор шууд өөрчлөх боломжтой |
| **Нас** | Захиалга үүссэнээс хойшхи хоног (өнөөдөр / өчигдөр / X хоног) |
| **Нийт дүн** | Монгол төгрөгөөр (₮) |
| **Үйлчилгээний өртөг** | Үйлчилгээний нийт зардал |
| **Сэлбэгийн өртөг** | Сэлбэгийн нийт зардал |
| **Ашиг (Gross Profit)** | Ногоон = ашигтай, Улаан = алдагдалтай. Алдагдалтай бол шалтгааныг tooltip-д харуулна |
| **Margin %** | Ашиг хүү. Мөн алдагдал бол шалтгааныг tooltip-д харуулна |
| **Алдагдлын шалтгаан** | Захиалга дээр алдагдал гарсан бол шалтгааны тэмдэглэл |
| **Үйлдлүүд** | Дэлгэрэнгүй харах, захиалга цуцлах |

### Төлөв өөрчлөх (жиагсаалтаас)

Мөрийн **Төлөв** баганад дарвал dropdown гарч ирдэг. Дотор нь:

- Бусад төлвүүд (одоогийн төлөвөөс бусад) сонгох боломжтой
- **Захиалга цуцлах** товч (улаан өнгөөр)

### Мобайл хувилбар

Утасны дэлгэц дээр мөр бүр card хэлбэрээр харуулагдана:

- Захиалгын дугаар + төлөв badge
- Харилцагчийн нэр + машиний мэдээлэл
- Механикч + нас
- Нийт дүн
- Төлвийн явцын цэг (progress dots) — `New` → `Diagnosing` → `In Progress` → `Ready for Pickup` → `Completed`

## Шинэ захиалга үүсгэх

Шинэ захиалга нь **sheet хэлбэрийн wizard**-аар нээгдэнэ. Алхмууд:

1. **Харилцагч** — сонгох эсвэл шинээр үүсгэх
2. **Машин** — харилцагчийн машиныг сонгох
3. **Гомдол / шалтгаан** — харилцагчийн гомдол, шалтгаан оруулах
4. **Үйлчилгээ** — каталогоос үйлчилгээ сонгох эсвэл гараар оруулах
5. **Сэлбэг** — сэлбэгийн мөр нэмэх
6. **Механикч** — механикч томилох
7. **Хураангуй** — бүх мэдээллийг хянаж, хадгалах

Wizard дотор үнэ, тоо хэмжээ, нийт дүн автоматаар тооцогдоно.

## Төлвийн урсгал

| Төлөв | Өнгө | Тайлбар |
| --- | --- | --- |
| **New** | Хөх | Шинээр үүссэн захиалга |
| **Diagnosing** | Шар | Оношилгоо хийж байгаа үе |
| **In Progress** | Улбар шар | Засвар гүйцэтгэж байгаа үе |
| **Ready for Pickup** | Ногоон | Дууссан, харилцагч хүлээж авахад бэлэн |
| **Completed** | Саарал | Бүрэн дууссан |
| **Cancelled** | Улаан | Цуцлагдсан |

### Төлөв өөрчлөх журам

- **Аливаа төлөвөөс** бусад төлөв рүү шилжих боломжтой (жишээ: `New` → `In Progress` шууд)
- **`Completed` эсвэл `Cancelled`** төлөв рүү шилжихэд **баталгаажуулах цонх** гарч ирнэ
- Баталгаажуулах цонхонд **тэмдэглэл** нэмж болно
- **Алдагдалтай захиалга** (gross profit < 0) дээр `Completed` эсвэл `Cancelled` төлөв рүү шилжихэд **алдагдлын шалтгаан заавал** бичих шаардлагатай
- Төлөв өөрчлөхөд жагсаалт болон холбогдох дэлгэцүүд **realtime** байдлаар шинэчлэгддэг

## Дэлгэрэнгүй хуудас

### Толгой хэсэг

- Захиалгын дугаар (`WO #a1b2c3d4`)
- Төлөвийн badge
- Огноо, харилцагчийн нэр, улсын дугаар
- **Буцах** товч

### Төлөвийн хяналт

Бүх төлвүүдийн товчууд харуулагдана. Аль нэгийг дарвал:

- **`Completed` / `Cancelled`** рүү шилжихэд:
  - Амбар өнгийн сануулгатай карт гарч ирнэ
  - Тэмдэглэл оруулах талбар
  - Алдагдалтай бол алдагдлын шалтгааны талбар (захавар)
  - Баталгаажуулах / Цуцлах товчууд

### Харилцагч ба Машиний мэдээлэл

- Харилцагчийн нэр, утас, имэйл
- Машиний улсын дугаар, марк, загвар, жил
- **Гомдол** (complaint) — харилцагчийн гомдол
- **Онош** (diagnosis) — оношийн label (өнгөт badge)

### Механикч томилох

- `MechanicSelect` dropdown ашиглан механикч сонгох
- Механикч бүрийн одоогийн ажлын тоог харуулна
- Нэмэлт механикч (helper) нэмэх, хасах боломжтой

### Үйлчилгээний хэсэг

- **Нэмэх** товч — каталогийн хайлтаар үйлчилгээ сонгох
  - Хайлтын талбарт нэр оруулахад санал болгох жагсаалт гарч ирнэ
  - Нэг удаа дарвал үйлчилгээ нэмэгдэнэ
  - **Үнийн түүх** — өмнөх нэгжийн үнийг автоматаар ашиглана
- **Өмнөх зочлолтоос давтах** товч — өмнөх зочлолтын үйлчилгээ, сэлбэгийг нэмнэ
- **Excel экспорт** — үйлчилгээний жагсаалтыг экспортлох
- Мөр бүрт: нэр, тоо хэмжээ × нэгжийн үнэ, хөнгөлөлт, нийт үнэ, хасах товч
- **Өмнөх нэгжийн үнэ** (last sold price) хэрэв байвал шар өнгөөр харуулна

### Сэлбэгийн хэсэг

- **Нэмэх** талбарт:
  - Сэлбэгийн нэр оруулах — каталогоос хайж, сонгох
  - Тоо хэмжээ, нэгжийн үнэ тохируулах
  - **Үнийн түүх** — өмнөх худалдан авалтын үнийг шар өнгөөр санал болгоно
- **Excel экспорт** — сэлбэгийн жагсаалтыг экспортлох
- Мөр бүрт: нэр, тоо хэмжээ × нэгжийн үнэ, нийт үнэ, хасах товч
- Сэлбэг/үйлчилгээ хасахад **баталгаажуулах цонх** гарч ирдэг (дахин нэмэх боломжтой)

### Төлвийн түүх (Status History)

- Цаг хугацааны мөрөнд төлвийн өөрчлөлтүүдийг харуулна
- Бүр тус бүр дээр: төлөвийн badge, огноо, тэмдэглэл (хэрэв байвал)

### Зураг болон баримтууд (Photos & Documents)

- Зураг ачаалах боломжтой (camera icon товч)
- Зургуудыг grid хэлбэрээр харуулна
- Зураг дээр дарвал нэмэлт цонхонд нээгдэнэ
- Зургийг устгах боломжтой (hover үед Trash icon гарч ирдэг)
- Зурагнаас гадна баримт файлуудыг (PDF гэх мэт) хавсаргаж болно

### Нэхэмжлэх үүсгэх (Invoice Generation)

- **`Ready for Pickup`** эсвэл **`Completed`** төлөвтэй үед ногоон карттай нэхэмжлэх хэсэг гарч ирдэг
- **Нэхэмжлэх үүсгэх** товч дарвал:
  - Нэхэмжлэх автоматаар үүсгэгдэнэ
  - Нэхэмжлэхийн нийтийн холбоос руу шилжинэ
  - Цонхон дотор **Нэхэмжлэх харах** товч гарч ирдэг

### Төлбөр бүртгэх (Record Payment)

Нэхэмжлэх үүссэний дараа төлбөрийн хэсэг гарч ирдэг:

- Төлбөрийн төлөв badge (pending / partial / paid)
- Өмнөх төлбөрүүдийн жагсаалт (арга, огноо, дүн, лавлагаа)
- **Нийт төлсөн** дүн
- **Үлдэгдэл** (хэрэв байвал)
- **Төлбөр бүртгэх** товч — дараах мэдээллийг оруулна:
  - Дүн (зээлийн үлдэгдэл хүртэл)
  - Төлбөрийн арга: бэлэн, карт, банкны шилжүүлэг, гарын тэмдэг
  - Лавлагаа (сонголтоор)
  - Тэмдэглэл (сонголтоор)

### Нийт дүн (Totals)

- Үйлчилгээний нийт
- Сэлбэгийн нийт
- Хөнгөлөлт (хэрэв байвал)
- **Нийт дүн (Grand Total)**

### Ашиг болон өртөгийн хураангуй (Profit & Cost Summary)

| Зүйл | Тайлбар |
| --- | --- |
| **Үйлчилгээний өртөг** | Нэгжийн өртөг × тоо хэмжээ |
| **Сэлбэгийн өртөг** | Нэгжийн өртөг × тоо хэмжээ |
| **Орлого** | Үйлчилгээ + сэлбэгийн нийт үнэ |
| **Нийт зардал** | Үйлчилгээний өртөг + сэлбэгийн өртөг |
| **Ашиг / Алдагдал** | Ногоон = ашигтай, Улаан = алдагдалтай |
| **Margin %** | Ашгийн хувь |
| **Алдагдлын шалтгаан** | Хэрэв алдагдалтай бол шалтгааны тэмдэглэл |

## PDF үүсгэх

Ажлын захиалгыг PDF файл болгон татаж авах боломжтой. PDF файлд:

- Байгууллагын нэр, лого
- Салбарын хаяг, утас, имэйл
- Захиалгын дэлгэрэнгүй мэдээлэл
- Үйлчилгээ, сэлбэгийн жагсаалт
- Нийт дүн

## Тусгай боломжууд

### Өмнөх зочлолтоос давтах (Repeat from Last Visit)

Тухайн машины өмнөх зочлолтын үйлчилгээ, сэлбэгийг нэг даралтаар энэ захиалгад нэмнэ. Идэвхтэй захиалга дээр л боломжтой.

### Optimistic UI

Үйлчилгээ, сэлбэг нэмэх, хасах үед серверийн хариу ирэхээс өмнө дэлгэцэнд шууд тусгагдана. Алдаа гарвал буцаагдана.

### Realtime шинэчлэлт

Захиалга нэмэгдэх, өөрчлөгдөх, устгагдах бүрт жагсаалт автомат шинэчлэгддэг. Дараах хүснэгтүүдийн өөрчлөлтийг мөрддөг:

- `work_orders`
- `work_order_services`
- `work_order_parts`
- `mechanic_assignments`

## API

```
GET    /api/organizations/:id/work-orders                    — Жагсаалт (status, mechanic, date, search, branch_id шүүлтүүр)
POST   /api/organizations/:id/work-orders                    — Шинэ захиалга
GET    /api/organizations/:id/work-orders/:woId              — Дэлгэрэнгүй
PATCH  /api/organizations/:id/work-orders/:woId              — Засварлах (status, complaint, diagnosis, notes, mechanic_id)
DELETE /api/organizations/:id/work-orders/:woId              — Цуцлах (soft delete)
POST   /api/organizations/:id/work-orders/:woId/services     — Үйлчилгээ нэмэх
DELETE /api/organizations/:id/work-orders/:woId/services/:sId — Үйлчилгээ хасах
POST   /api/organizations/:id/work-orders/:woId/parts        — Сэлбэг нэмэх
DELETE /api/organizations/:id/work-orders/:woId/parts/:pId   — Сэлбэг хасах
POST   /api/organizations/:id/work-orders/:woId/helpers      — Нэмэлт механикч нэмэх
DELETE /api/organizations/:id/work-orders/:woId/helpers?mechanicId=X — Нэмэлт механикч хасах
GET    /api/organizations/:id/work-orders/:woId/pdf          — PDF татах
POST   /api/organizations/:id/work-orders/:woId/attachments  — Зураг/баримт хавсаргах
GET    /api/organizations/:id/work-orders/:woId/attachments  — Хавсралтуудын жагсаалт
DELETE /api/organizations/:id/work-orders/:woId/attachments/:aId — Хавсралт устгах
```

Portal API (харилцагчийн хувьд):

```
GET    /api/portal/work-orders                               — Харилцагчийн захиалгууд
GET    /api/portal/work-orders/:id                           — Захиалгын дэлгэрэнгүй
```

## Хэрэглээний зөвлөмж

- Захиалга үүсгэхээсээ өмнө харилцагч болон машины мэдээллийг шалгана уу
- **Төлөвийг шууд өөрчлөх** боломжтой — жагсаалтын "Төлөв" баганын dropdown-оос сонгоно
- Үйлчилгээ, сэлбэг нэмэхэд **өмнөх нэгжийн үнэ** автоматаар санал болгоно
- **Алдагдалтай захиалга** дээр `Completed` эсвэл `Cancelled` төлөвт шилжихэд алдагдлын шалтгаан заавал бичих шаардлагатай
- Нэхэмжлэх үүсгэхээсээ өмнө бүх үйлчилгээ, сэлбэгийг нэмж дуусгана уу
- Зураг ачаалах нь засварын явцыг баримтжуулахад тустай
- **Өмнөх зочлолтоос давтах** нь тухайн машины хувьд давтагдах үйлчилгээнд хурдан бөглөх боломж олгоно
