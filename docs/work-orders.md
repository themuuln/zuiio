# Ажлын захиалга

Ажлын захиалга нь харилцагч, машин, үйлчилгээ, сэлбэг, механикч, төлбөрийн урсгалыг холбодог үндсэн баримт бичиг юм.

## Жагсаалтын хуудас

Ажлын захиалгын жагсаалтаас дараах зүйлсийг нэг дороос удирдана:

- хайлт
- төлвийн шүүлтүүр
- filter chips
- Excel экспорт
- мөр дээр дарж дэлгэрэнгүй рүү орох
- захиалга цуцлах

## Шинэ захиалга үүсгэх

Шинэ захиалга нь sheet хэлбэрийн wizard-аар нээгдэнэ. Үндсэн алхмууд:

1. **Харилцагч** сонгох эсвэл шинээр үүсгэх
2. **Машин** сонгох
3. **Гомдол / шалтгаан** оруулах
4. **Үйлчилгээ** нэмэх
5. **Сэлбэг** нэмэх
6. **Механикч** томилох

Wizard дотор үнэ, тоо хэмжээ, нийт дүн автоматаар тооцогдоно.

## Төлвийн урсгал

| Төлөв | Тайлбар |
| --- | --- |
| **New** | Шинээр үүссэн захиалга |
| **Diagnosing** | Оношилгоо хийж байгаа үе |
| **In Progress** | Засвар гүйцэтгэж байгаа үе |
| **Ready for Pickup** | Дууссан, харилцагч хүлээж авахад бэлэн |
| **Completed** | Бүрэн дууссан |
| **Cancelled** | Цуцлагдсан |

Төлөв өөрчлөхөд жагсаалт болон холбогдох дэлгэцүүд realtime байдлаар шинэчлэгддэг.

## Үйлчилгээ ба сэлбэгийн мөрүүд

Захиалгад:

- каталогоос үйлчилгээ сонгох
- гараар үйлчилгээ оруулах
- сэлбэгийн мөр нэмэх
- тоо хэмжээ, үнэ, хөнгөлөлт тохируулах
- өмнөх үнийн мэдээлэлд тулгуурлан хурдан бөглөх

боломжтой.

## Дэлгэрэнгүй хуудас

Захиалгын дэлгэрэнгүй хуудаснаас:

- үйлчилгээний мөрүүд
- сэлбэгийн мөрүүд
- механикчийн томилгоо
- төлөвийн түүх
- PDF / нэхэмжлэхтэй холбоотой үйлдлүүд
- хавсралтууд

зэрэг мэдээллийг харна.

## Санхүүгийн хяналт

Захиалга бүр дээр ашигт ажиллагааны үндсэн тооцоонууд хийгдэнэ:

- нийт орлого
- сэлбэгийн өртөг
- хөнгөлөлт
- gross profit
- margin

Ингэснээр ямар ажил ашигтай, ямар ажил алдагдалтай байгааг хянах боломжтой.

## Үйлчилгээний сануулгатай холбоо

`Ready for Pickup` болон дараах алхмуудад бүртгэсэн үйлчилгээний интервал, одометрийн мэдээлэл нь үйлчилгээний сануулгын системтэй холбогдож болно. Энэ нь дараагийн тос солих, тогтмол үйлчилгээний reminder-уудыг бэлтгэхэд ашиглагдана.
