# Telegram Ботын мэдэгдэл

Telegram бот нь байгууллагын эзэмшигч, менежерүүдэд үйлчилгээний сануулгатай холбоотой мөнгөн үзүүлэлтүүдийг шуурхай мэдээлж, орлогын алдагдлыг бууруулах боломжийг олгоно. Мөн харилцагчид өөрсдийн утасны дугаараар холбогдож, үйлчилгээний сануулгыг Телеграмаар шууд хүлээн авах боломжтой.

## Ерөнхий ойлголт

Энэхүү систем нь:

- **Өдөр тутмын хураангуй** мэдэгдэл илгээх (22:00 цагт)
- **Долоо хоногийн хураангуй** мэдэгдэл илгээх (Даваа гарагт 22:00 цагт)
- **Сарын хураангуй** мэдэгдэл илгээх (сар бүрийн 1-ний өдөр 22:00 цагт)
- Дуусах хугацаа ойртсон үйлчилгээний мөнгөн нөлөөллийн үнэлгээ
- Буцаж ирсэн харилцагчдын орлогын тайлан
- Ашиглагдаагүй боломжийн үнэлгээ

## Telegram Боттой холбогдох

### Урьдчилсан нөхцөл

Та Telegram аппликешн суулгасан байх шаардлагатай.

### Холбох алхамууд

1. **Токен үүсгэх**
   - TOLOM системд нэвтрэн **Тохиргоо > Telegram Bot** хэсэгт очно уу.
   - **"Generate Link"** товчийг дарж нэг удаагийн холбох токен үүсгэнэ.
   - Токен 15 минутын хугацаанд хүчинтэй.

2. **Telegram нээх**
   - Үүсгэсэн холбоосыг (deep link) дарах эсвэл Telegram-нээж `@tolomerpbot` хаягийг хайж олоод чат нээнэ.

3. **Токеныг илгээх**
   - Бот руу `/start <таны_токен>` командыг илгээнэ.
   - Хэрэв холбоосоор нээсэн бол токен автоматаар хавсаргагдана.

4. **Баталгаажуулах**
   - Бот амжилттай холбогдсоныг баталгаажуулж, байгууллагын нэрийг харуулна.

### Боломжтой тушаалууд

| Тушаал | Тайлбар | Зорилго |
|--------|---------|---------|
| `/start [токен]` | TOLOM-тэй холбох (токенгүйгээр илгээвэл заавар харуулна) | Эзэмшигч / Ажилтан |
| `/status` | Одоогийн үзүүлэлтүүдийг харуулах | Эзэмшигч / Харилцагч |
| `/link [утасны дугаар]` | Утасны дугаараар холбогдож сануулга хүлээн авах | Харилцагч |
| `/unlink` | Сануулгын холболтыг салгах | Харилцагч |
| `/stop` | Мэдэгдлийг зогсоох (холбоог идэвхгүй болгох) | Эзэмшигч / Ажилтан |

## Үзүүлэлтүүдийн тооцоолол

| Үзүүлэлт | Тайлбар | Тооцоолол |
|----------|---------|------------|
| **Орлого** | Гүйцэтгэсэн захиалгын нийт дүн | `work_orders.status = 'Completed' AND completed_at >= өнөөдөр` |
| **Зарлага** | Өнөөдрийн зарлагын нийт дүн | `expenses.expense_date = өнөөдөр` |
| **Цэвэр ашиг** | Орлого − Зарлага | Орлого − Зарлага |
| **Идэвхтэй захиалга** | Хүлээгдэж буй, оношлогдож буй, хийгдэж буй захиалгууд | `status IN ('New', 'Diagnosing', 'In Progress')` |
| **Гүйцэтгэсэн захиалга** | Өнөөдөр дууссан захиалгын тоо | `status = 'Completed' AND completed_at >= өнөөдөр` |
| **Үйлчлүүлэгч** | Өнөөдөр үйлчлүүлсэн давхаргүй харилцагчдын тоо | `work_orders.customer_id` давхаргүй тоо |
| **Дуусах үйлчилгээ** | Ойрын 7 хоногт дуусах үйлчилгээний тоо | `vehicle_service_schedules.next_due_date` 7 хоногийн дотор |
| **Төлөгдөөгүй нэхэмжлэх** | Төлөгдөөгүй нэхэмжлэхийн тоо ба дүн | `invoices.status NOT IN ('paid', 'cancelled')` |

## Холбоог таслах (эзэмшигч / ажилтан)

1. Telegram бот руу `/stop` командыг илгээнэ үү.
2. Бот мэдэгдэл зогссоныг баталгаажуулна.
3. Дахин холбогдохын тулд TOLOM системээс шинэ токен үүсгэн `/start` командыг илгээнэ үү.

# Харилцагчийн Телеграм холболт

Харилцагчид TOLOM Telegram боттой утасны дугаараа ашиглан холбогдож, үйлчилгээний сануулгыг Телеграмаар шууд хүлээн авах боломжтой. Энэ нь имэйлээс илүү үр дүнтэй, учир нь Монголд хүмүүс Телеграмыг өдөр бүр идэвхтэй ашигладаг.

## Холбогдох алхамууд

1. Telegram нээгээд **@tolomerpbot** хайж олоод чат нээнэ.
2. `/link 99112233` гэж бичих (өөрийн утасны дугаараар).
3. Систем утасны дугаарыг таньж, баталгаажуулна.
4. Бот амжилттай холбогдсоныг мэдэгдэнэ.

::: tip Утасны дугаарын формат
Дугаараа олон янзаар бичиж болно:
- `99112233`
- `+97699112233`
- `97699112233`
- `99-11-22-33`

Систем автоматаар таньж, хэвийн болгоно.
:::

## Харилцагчийн тушаалууд

| Тушаал | Тайлбар |
|--------|---------|
| `/link 99112233` | Утасны дугаараар холбогдож сануулга хүлээн авах |
| `/unlink` | Холболтыг салгах |
| `/status` | Одоогийн үйлчилгээний хугацаа харах |

## Мэдэгдлийн жишээ

Харилцагчид үйлчилгээний хугацаа ойртоход дараах мэдэгдлийг хүлээн авна:

```
🔔 Тос солих

Машин: 9999 UNA
Үйлчилгээ: Тос солих
Хугацаа: 2026 оны 6 сарын 15

Засвар үйлчилгээнд цаг товлохыг хүсвэл бидэнтэй холбогдоно уу.

— Миний Цех
```

## Хэрхэн ажилладаг

1. **Харилцагч холбогдох** — `/link 99112233` командыг илгээнэ. Систем утасны дугаарыг таньж `telegram_chat_id`-г харилцагчийн бүртгэлд хадгална.
2. **Өдөр бүр шалгах** — `check-service-reminders` функц өдөр бүр дуусах хугацаа ойртсон үйлчилгээнүүдийг шалгана (7 хоногийн дотор).
3. **Сувгийн тэргүүлэх дараалал** — Хэрэв харилцагчийн Телеграм холбогдсон бол **Телеграмаар** сануулга илгээнэ. Хэрэв холбогдоогүй, имэйл бүртгэлтэй бол **имэйлээр** илгээнэ. Аль нь ч байхгүй бол **систем дотор** бүртгэгдэнэ.
4. **24 цагийн хязгаарлалт** — Нэг хуваарьт 24 цагт нэг л сануулга илгээгдэнэ.
5. **Амжилтгүй бол** — Хэрэв ботыг хаасан бол (403 алдаа) сануулга `failed` төлөвт шилжиж, дараагийн удаа имэйлээр илгээгдэнэ.

## Холболтыг салгах

Харилцагч хүссэн үедээ `/unlink` командыг илгээж холболтоо салгах боломжтой. Үүний дараа сануулга имэйл эсвэл апп дотор харагдана.

## Системийн тохиргоо

Байгууллагын эзэмшигч **Тохиргоо > Үйлчилгээний сануулга** хэсгээс анхдагч сувгийг тохируулах боломжтой:

| Суваг | Тайлбар |
|-------|---------|
| `email` | Зөвхөн имэйлээр (анхдагч) |
| `telegram` | Телеграм тэргүүлэх — холбогдсон бол Телеграм, үгүй бол имэйл |
| `both` | Бүх сувгаар зэрэг илгээх |

## Интерактив товчнууд ба командын цэс

Бот нь текстэн тушаалаас гадна дараах интерактив боломжуудыг дэмждэг:

### Командын цэс (`/`)

Чатны текст талбарт `/` дархад бүх боломжтой командын жагсаалт харагдана:

| Команд | Тайлбар |
|--------|---------|
| `/start [токен]` | 🔗 TOLOM-тэй холбох |
| `/status` | 📊 Орлогын хураангуй харах |
| `/link [утас]` | 📱 Утасны дугаараар холбогдох (харилцагч) |
| `/unlink` | 🛑 Сануулгын холболтыг салгах (харилцагч) |
| `/stop` | 🔕 Мэдэгдлийг зогсоох |

### Inline товчнууд

Бүх мэдэгдэл, хариу мессежүүдэд товчнууд хавсаргагдсан байдаг:

**Эзэмшигчийн хураангуй (өдөр/долоо/сар):**
```
[📊 Хураангуй] [🔔 Сануулга]
[❌ Зогсоох]
```

**Харилцагчийн сануулга:**
```
[📊 Миний үйлчилгээ] [🛑 Зогсоох]
```

Товч дээр дарахад тухайн үйлдэл шуурхай гүйцэтгэгдэнэ.

## Давуу тал

- **Шуурхай** — имэйлээс илүү хурдан хүргэлт
- **Өндөр нээлттэй түвшин** — Телеграм мессежийг 90%+ хүмүүс нээдэг
- **Автомат** — гар аргаар илгээх шаардлагагүй
- **Хялбар холболт** — харилцагч өөрөө утасны дугаараар холбогдоно
- **Нэг бот, хоёр зорилго** — эзэмшигчид мэдэгдэл, харилцагчид сануулга хүлээн авна
