# Telegram Ботын мэдэгдэл

Telegram бот нь байгууллагын эзэмшигч, менежерүүдэд үйлчилгээний сануулгатай холбоотой мөнгөн үзүүлэлтүүдийг шуурхай мэдээлж, орлогын алдагдлыг бууруулах боломжийг олгоно.

## Ерөнхий ойлголт

Энэхүү систем нь:

- Өдөр тутмын хураангуй мэдэгдэл илгээх (22:00 цагт)
- Долоо хоногийн хураангуй мэдэгдэл илгээх (Даваа гарагт 22:00 цагт)
- Дуусах хугацаа ойртсон үйлчилгээний мөнгөн нөлөөллийн үнэлгээ
- Буцаж ирсэн харилцагчдын орлогын тайлан
- Ашиглагдаагүй боломжийн үнэлгээ

## Telegram Боттой холбогдох

### Урьдчилсан нөхцөл

Та Telegram аппликешн суулгасан байх шаардлагатай.

### Холбох алхамууд

1. **Токен үүсгэх**
   - TOLOM системд нэвтрэн **Тохиргоо > Telegram Bot** хэсэгт очно уу.
   - **"Generate Link"** товчийг дарж нэг удаагийн холбох токен үүсгэнэ.
   - Токен 15 минутын хугацаанд хүчинтэй.

2. **Telegram нээх**
   - Үүсгэсэн холбоосыг (deep link) дарах эсвэл Telegram-нээж `@tolomerpbot` хаягийг хайж олоод чат нээнэ.

3. **Токеныг илгээх**
   - Бот руу `/start <таны_токен>` командыг илгээнэ.
   - Хэрэв холбоосоор нээсэн бол токен автоматаар хавсаргагдана.

4. **Баталгаажуулах**
   - Бот амжилттай холбогдсоныг баталгаажуулж, байгууллагын нэрийг харуулна.

### Боломжтой тушаалууд

| Тушаал | Тайлбар |
|--------|---------|
| `/start [токен]` | TOLOM-тэй холбох (токенгүйгээр илгээвэл заавар харуулна) |
| `/status` | Одоогийн үзүүлэлтүүдийг харуулах |
| `/stop` | Мэдэгдлийг зогсоох (холбоог идэвхгүй болгох) |

## Мэдэгдлийн агуулга

### Өдөр тутмын хураангуй

Сүүлийн 24 цагийн үзүүлэлтүүд:

```
📊 Өдрийн хураангуй — Авто Сервис
📅 2026-05-31

📨 Өчигдөр илгээгдсэн сануулга: 8
👥 Сануулга авсны дараа ирсэн үйлчлүүлэгч: 3
💰 Сэргээгдсэн орлого: ₮450K

📅 Өнөөдөр дуусах үйлчилгээ: 5, тооцоолсон орлого: ₮1.2M
⚠️ Хугацаа хэтэрсэн үйлчилгээнээс алдсан орлого: ₮600K
```

### Долоо хоногийн хураангуй

Долоо хоногийн хураангуйд илүү дэлгэрэнгүй мэдээлэл харуулна:

```
📊 Долоо хоногийн хураангуй — Авто Сервис
📅 2026-05-24 → 2026-05-31

📨 Илгээгдсэн сануулга: 12
👥 Буцаж ирсэн үйлчлүүлэгч: 5
💰 Сэргээгдсэн орлого: ₮1.2M
📅 Долоо хоногт дуусах үйлчилгээ: 15
💵 Ашиглагдаагүй боломж: ₮450K

│ 15 үйлчлүүлэгч энэ долоо хоногт үйлчилгээнд дуусах хугацаатай.
│ Тооцоолсон орлого: ₮3.5M
```

## Үзүүлэлтүүдийн тооцоолол

| Үзүүлэлт | Тайлбар | Тооцоолол |
|----------|---------|------------|
| **Илгээгдсэн сануулга** | Сүүлийн хугацаанд илгээгдсэн сануулгын тоо | `reminder_logs.status = 'sent'` |
| **Буцаж ирсэн үйлчлүүлэгч** | Сануулга хүлээн авснаас хойш 60 хоногийн дотор захиалга хийлгэсэн харилцагчдын тоо | Сануулга илгээгдсэн → захиалга гүйцэтгэсэн |
| **Сэргээгдсэн орлого** | Буцаж ирсэн харилцагчдын захиалгын нийт дүн | Захиалгын нийт дүнгийн нийлбэр |
| **Дуусах үйлчилгээ** | Дараагийн хугацаанд дуусах үйлчилгээний тоо | `next_due_date` хугацаанд байгаа хуваариуд |
| **Тооцоолсон орлого** | Дуусах үйлчилгээнүүдийн тооцоолсон орлого | Каталогийн үнэ / сүүлийн захиалгын дундаж |
| **Ашиглагдаагүй боломж** | Хугацаа хэтэрсэн үйлчилгээнүүдийн тооцоолсон алдагдсан орлого | Хугацаа хэтэрсэн × дундаж захиалгын үнэ |

## Холбоог таслах

1. Telegram бот руу `/stop` командыг илгээнэ үү.
2. Бот мэдэгдэл зогссоныг баталгаажуулна.
3. Дахин холбогдохын тулд TOLOM системээс шинэ токен үүсгэн `/start` командыг илгээнэ үү.
