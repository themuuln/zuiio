# Үнийн дүрмүүд (Pricing Rules)

Үнийн дүрмүүд нь тээврийн хэрэгслийн төрөл, ангилалаас хамааран
сэлбэг, үйлчилгээний үнийг автоматаар тохируулах боломж юм.

Жишээ нь:
- Lexus, BMW зэрэг **тансаг** машинд сэлбэгийн үнийг **25% нэмж**
- **Эрлийз (hybrid)** машины оношилгооны үйлчилгээнд **+20,000₮ нэмж**
- Lexus RX-ийн тоормосны үйлчилгээг **120,000₮ тогтмол** үнээр тогтоох

## Үнийн тодорхойлох гинжин хэлхээ

Систем дараах дарааллаар үнийг тодорхойлно:

1. **vehicle_model_parts.specific_price** — Тухайн загварт зориулсан тусгай үнэ
2. **Үнийн дүрэм (price rule)** — Энэ хуудаснаас тохируулсан дүрмүүд
3. **Үнийн түүх (price history)** — Өмнө нь ижил тээврийн хэрэгсэлд авсан үнэ
4. **Каталогийн анхдагч үнэ (default_price)** — Анхдагч үнэ

## Үнийн дүрэм үүсгэх

**Тохиргоо → Pricing Rules** хэсгээс үнийн дүрмүүдийг удирдана.

### Дүрмийн талбарууд

| Талбар | Тайлбар |
|--------|---------|
| **Rule Name** | Дүрмийн нэр (жишээ нь "Тансаг машины сэлбэг × 1.25") |
| **Description** | Дүрмийн тайлбар |
| **Applies To** | Аль хэсэгт хамаарах: Parts / Services / Both |
| **Vehicle Condition** | Ямар тээврийн хэрэгсэлд хамаарах |
| **Operator** | Үнэнд хэрхэн нөлөөлөх (үржүүлэх, нэмэх, тогтмол болгох, хувь нэмэх/хасах) |
| **Value** | Операторын утга |
| **Priority** | Эрэмбэ (бага = түрүүнд тооцогдоно) |
| **Category Filter** | Зөвхөн тодорхой категорийн сэлбэг/үйлчилгээнд хамаарах |

### Vehicle Condition (Нөхцөл)

Дүрэм ямар тээврийн хэрэгсэлд хамаарахыг дараах нөхцөлөөр тодорхойлно:

| Нөхцөл | Жишээ |
|---------|-------|
| **Vehicle class** | `luxury`, `standard`, `economy`, `performance` |
| **Vehicle make** | `Lexus`, `Toyota`, `BMW` |
| **Make + Model** | `Lexus RX`, `Toyota Harrier` |
| **Fuel type** | `hybrid`, `plug-in-hybrid`, `electric` |
| **Body type** | `suv`, `sedan`, `crossover` |
| **All vehicles** | Бүх тээврийн хэрэгсэлд хамаарах |

### Операторууд

| Оператор | Тайлбар | Жишээ |
|----------|---------|-------|
| **Multiply** | Үнэ × value | 1.25 = 25% нэмэгдэл |
| **+ Fixed** | Үнэ + value | 20000 = +20,000₮ |
| **Fixed price** | Үнэ = value | 120000 = 120,000₮ тогтмол |
| **+ Percentage** | Үнэ × (1 + value/100) | 15 = +15% |
| **- Percentage** | Үнэ × (1 - value/100) | 10 = -10% |

## Анхдагч дүрмүүд

Системд дараах анхдагч дүрмүүд орсон:

| Дүрэм | Үр дүн |
|-------|--------|
| Luxury parts × 1.25 | Тансаг машины сэлбэг 25% нэмэгдэл |
| Luxury services × 1.20 | Тансаг машины үйлчилгээ 20% нэмэгдэл |
| Performance parts × 1.15 | Спорт машины сэлбэг 15% нэмэгдэл |
| Economy parts × 0.90 | Энгийн машины сэлбэг 10% хямдрал |
| Hybrid surcharge | Эрлийз машины оношилгоо +20,000₮ |
| Lexus RX brake fixed price | RX тоормосны үйлчилгээ 120,000₮ |
| Premium oil for luxury | Тансаг машины тос 30% нэмэгдэл |

## Тээврийн хэрэгслийн ангилал

Тээврийн хэрэгсэл бүр дараах ангилалд хуваагдана:

- **luxury** — Тансаг зэрэглэлийн (Lexus, BMW, Mercedes-Benz, Audi, Land Rover, Porsche, Genesis)
- **standard** — Стандарт (Toyota, Honda, Nissan, Mazda, Hyundai гэх мэт)
- **economy** — Эдийн засгийн (жижиг, хямд тээврийн хэрэгсэл)
- **performance** — Спорт гүйцэтгэлтэй (GR, AMG, M series, Porsche)

Ангилалыг **Тохиргоо → Vehicle Models** хэсгээс өөрчилж болно.

## Ажлын захиалга дээр хэрхэн ажилладаг

1. Механикч ажлын захиалга дээр сэлбэг/үйлчилгээ нэмэх үед
2. Систем автоматаар үнийн дүрмүүдийг шалгана
3. Тухайн тээврийн хэрэгсэлд тохирох дүрэм байвал үнийг автоматаар тохируулна
4. Дүрэм байхгүй бол өмнөх үнийн түүх, эсвэл каталогийн анхдагч үнийг ашиглана

## Зөвлөмж

- **Тодорхой дүрмүүдэд бага priority өгөх** — жишээ нь `Lexus RX brake fixed price`
  (priority 30) нь `Luxury services × 1.20` (priority 80)-оос өндөр эрэмбэтэй
- **Ангилалын дүрмүүдийг өргөн хэрэглэх** — тансаг, стандарт, эдийн засгийн
  гэсэн үндсэн ангилалаар үнийн ерөнхий бодлого тогтоох
- **Категорийн шүүлтүүр ашиглах** — жишээ нь зөвхөн тос, тосолгооны материалд
  хамаарах дүрэм үүсгэх
