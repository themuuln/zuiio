# Байгууллагын удирдлага

Байгууллагын хэсэг нь танай байгууллагын профайл, захиалга, гишүүд, үүрэг, зөвшөөрлүүдтэй холбоотой удирдлагын төв юм.

## Organization profile

Эндээс:

- байгууллагын нэр
- logo URL
- профайлын зураг

зэрэг мэдээллийг засаж хадгална.

## Subscription

Баруун талын мэдээллийн хэсэг болон үндсэн хуудас дээр subscription-ийн төлөв харагдана:

- plan type
- status
- started date
- trial дуусах огноо

## Members (Гишүүд)

Гишүүдийн хэсэгтэй хамт дараах урсгал ажиллана:

- шинэ гишүүн урих
- урилгын холбоос үүсгэх
- хүлээгдэж буй урилгуудыг харах
- урилгыг цуцлах
- гишүүний үүргийг өөрчлөх

## Roles (Үүргүүд)

Тус систем **5 үүрэг**-тэй ажилладаг бөгөөд үүрэг бүр өөр өөр эрхтэй:

| Үүрэг | Эрх | Тайлбар |
|-------|-----|--------|
| **Super Admin** | Бүх байгууллагад хандах | Платформын администратор — байгууллага, захиалгыг удирдах |
| **Org Owner** | Бүх эрх | Байгууллагын эзэмшигч — бүх модуль, тохиргоо, тайланд бүрэн хандах |
| **Manager** | Үйл ажиллагааны эрх | Өдөр тутмын үйл ажиллагаа, тайлан, батламж, бараа материалын удирдлага |
| **Mechanic** | Ажлын захиалга + үйлчлүүлэгч | Даалгавартай ажиллах, өөрийн гүйцэтгэл харах, бараа материалын үлдэгдэл харах |
| **Guest** | Зөвхөн нэхэмжлэх харах | Token-д суурилсан порталаар зөвхөн нэхэмжлэхээ үзэх боломжтой |

### Эрхийн шатлал

Үүрэг бүр дараах шатлалтай:

```
Guest → Mechanic → Manager → Org Owner → Super Admin
```

Доод шатны үүрэг дээд шатны үүргийн эрхийг автоматаар авдаггүй. Үүрэг бүрт **тусгай зөвшөөрөл (permission)** олгогдсон:

| Нөөц | Org Owner | Manager | Mechanic | Guest |
|------|-----------|---------|----------|-------|
| Ажлын захиалга | Бүрэн | Бүрэн | Унших+шинэчлэх | — |
| Нэхэмжлэх | Бүрэн | Бүрэн | — | Зөвхөн унших |
| Бараа материал | Бүрэн | Унших+шинэчлэх | Зөвхөн унших | — |
| Харилцагчид | Бүрэн | Бүрэн | Зөвхөн унших | — |
| Тээврийн хэрэгсэл | Бүрэн | Бүрэн | Зөвхөн унших | — |
| Тайлан | Бүрэн | Унших | — | — |
| Тохиргоо | Бүрэн | Зөвхөн унших | — | — |
| Гишүүд | Бүрэн | Зөвхөн унших | — | — |

### Үүргийн хуудас

**Үүргүүд (Roles)** хуудас (`/dashboard/organization/roles`) дээр:

- бүх үүргийн жагсаалт (нэр, тайлбар)
- үүрэг тус бүрийн гишүүдийн тоо
- системийн үүрэг эсэх мэдээлэл

харж болно.

### Гишүүдийн үүргийг өөрчлөх

**Гишүүд (Members)** хуудас дээр гишүүн бүрийн үүргийг солих боломжтой. Шинэ гишүүн урихдаа үүргийг нь сонгох, эсвэл урилгын дараа өөрчлөх боломжтой.

## Салбар ба байгууллагын бүтэц

Байгууллага нь олон салбартай байж болох бөгөөд салбар бүр дээр:

- харилцагч
- машин
- захиалга
- бараа материал

зэрэг өгөгдөл салангид байдлаар ажиллах боломжтой.
