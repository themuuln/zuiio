# Механикийн ажлын самбар

Механикийн самбар нь механикч бүрийн өнөөдрийн ажил, гүйцэтгэл, цаг бүртгэлийг төвлөрүүлсэн дэлгэц юм.

## Clock In / Clock Out

Механикч ажлаа эхлэх, дуусгахдаа:

- **Clock In**
- **Clock Out**

товчоор цагаа бүртгэнэ.

Hours Today карт дээр:

- өнөөдрийн нийт цаг
- clocked in / out төлөв

харагдана.

## KPI үзүүлэлтүүд

Самбар дээр дараах гол картууд байна:

- Completed Today
- Revenue Today
- Active Jobs
- Hours Today
- Avg Job Value
- Jobs Per Day

## Ажлын жагсаалт

Механикчид өөрт томилогдсон ажлуудаа жагсаалтаар харна. Эндээс:

- төлөв дараагийн шат руу шилжүүлэх
- захиалгын дэлгэрэнгүй рүү орох
- цуцлах

боломжтой.

## Төлвийн шилжилт

| Одоогийн төлөв | Дараагийн төлөв |
| --- | --- |
| **New** | Diagnosing |
| **Diagnosing** | In Progress |
| **In Progress** | Ready for Pickup |
| **Ready for Pickup** | Completed |

Мөн шаардлагатай үед цуцлах сонголт харагдана.

## Тренд харагдац

MechanicTrendChart нь сүүлийн хэдэн долоо хоногийн:

- ажлын тоо
- орлого

үзүүлэлтийг харуулна.

- тухайн механикчийн KPI-г харах
- шинэ механикч нэмэх

боломжтой.
