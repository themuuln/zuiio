# Механикийн ажлын самбар

Механикийн ажлын самбар (Mechanic Dashboard) нь механикч нарт өөрт томилогдсон ажлын захиалгуудыг хянах, цагаа бүртгэх, гүйцэтгэлийн үзүүлэлтээ харах боломжийг олгоно.

## Цаг бүртгэл (Clock In / Clock Out)

Механикч нар ажлын цагаа системд бүртгэх боломжтой.

| Товч | Үйлдэл |
|------|--------|
| **Clock In** ( ▶︎ ) | Ажлын цагаа эхлүүлэх — цаг бүртгэл эхэлнэ |
| **Clock Out** ( ■ ) | Ажлын цагаа дуусгах — цаг бүртгэл зогсоно |

- Цаг бүртгэл идэвхтэй үед урсгал цаг (elapsed time) автоматаар харуулагдана
- Clock Out товч улаан өнгөтэй, Clock In товч ногоон өнгөтэй
- Систем нь `/api/organizations/{orgId}/me/time/clock-in` болон `clock-out` эндпойнтуудаар цагийн бүртгэл хөтөлнө
- Ажлын самбар дээрх **Цаг бүртгэл** хэсэг (Hours Today): өдрийн нийт ажилласан цагийг харуулна

### Цагийн бүртгэлийн төлөв

| Төлөв | Тайлбар |
|-------|---------|
| **Clocked In** | Ажиллаж байгаа, цаг бүртгэл идэвхтэй |
| **Clocked Out** | Ажлын цаг дууссан, цаг бүртгэл идэвхгүй |

## KPI үзүүлэлтүүд

Дөрвөн үндсэн KPI карт:

| Үзүүлэлт | Дүрс | Тайлбар |
|---------|------|---------|
| **Completed Today** | ✅ | Өнөөдөр дуусгасан захиалгын тоо. Дэд мөрөнд үйлчилгээ, сэлбэгийн тоо харагдана |
| **Revenue Today** | 💰 | Өнөөдрийн нийт орлого. Дууссан захиалгуудын нийт дүн |
| **Active Jobs** | 📋 | Одоо гүйцэтгэж буй захиалгын тоо |
| **Hours Today** | ⏰ | Өнөөдөр ажилласан нийт цаг. Доор Clocked In/Out төлөв харагдана |

### Үр ашгийн KPI

Нэмэлт хоёр үр ашгийн KPI:

| Үзүүлэлт | Тайлбар |
|---------|---------|
| **Avg Job Value** | Дууссан захиалга бүрийн дундаж орлого |
| **Jobs Per Day** | Сонгосон хугацааны өдөр тутмын дундаж захиалга |

## Тренд график

Механикийн 8 долоо хоногийн гүйцэтгэлийн график:
- **Баганан график** — долоо хоног бүрийн захиалгын тоо
- **Шугаман график** — долоо хоног бүрийн орлого
- График нь `MechanicTrendChart` компонентоор динамик ачаалагдана

## Ажлын захиалгын жагсаалт

Механикчид өөрт томилогдсон захиалгуудыг жагсаалт хэлбэрээр харна.

### Ангилах дараалал

Захиалгууд дараах дарааллаар эрэмбэлэгдэнэ:
1. **In Progress** — Гүйцэтгэж буй (тэргүүн зэрэг)
2. **Ready for Pickup** — Хүлээлгэхэд бэлэн
3. **New** — Шинэ
4. **Diagnosing** — Оношилгоо

### Төлөв өөрчлөх

Механикч шууд жагсаалтаас захиалгын төлөвийг өөрчлөх боломжтой:

| Одоогийн төлөв | Дараагийн төлөвүүд |
|---------------|-------------------|
| **New** | Diagnosing |
| **Diagnosing** | In Progress |
| **In Progress** | Ready for Pickup |
| **Ready for Pickup** | Completed |
| Дурын төлөв | Cancelled |

Төлөв өөрчлөх үед:
- Статус өөрчлөлт шууд хадгалагдана (optimistic update)
- Амжилтгүй болсон тохиолдолд буцаагдана (auto-rollback)
- 30 секунд тутамд автоматаар шинэчлэгдэнэ

### Захиалгын дэлгэрэнгүй

Захиалгын мөрөн дээр дарж тухайн захиалгын дэлгэрэнгүй хуудас руу шилжинэ.

## Админ харагдац

Админ эрхтэй хэрэглэгч механикийн хуудсыг нээвэл:

1. **Механикч сонгох** — унадаг цэснээс аль нэг механикчийг сонгох
2. **Механикчийн ажлын самбар** — сонгосон механикчийн бүх мэдээлэл (KPI, захиалга, тренд) харагдана
3. **Шинэ механикч урих** — `UserPlus` товчоор шинэ механикч нэмэх
4. Механикч байхгүй бол хоосон төлөв (Empty State) харуулж, шинэ механикч урих санал болгоно

## Баруун хажуугийн самбар

Механикийн хуудас нь баруун талд хажуугийн самбартай:

| Таб | Агуулга |
|-----|---------|
| **Stats** | Өнөөдрийн хураангуй: дууссан захиалга, өнөөдрийн орлого, идэвхтэй ажлын тоо |
| **Jobs** | Томилогдсон захиалгуудын жагсаалт (тээврийн хэрэгслийн дугаар, төлөв, хугацаа) |

## Хандалт

- **Механик** — зөвхөн өөрийн ажлын самбарыг харна
- **Админ** — бүх механикчдын ажлын самбарыг харж болно
- **Бусад** — эрхгүй гэсэн мэдэгдэл харуулна

::: tip Зөвлөмж
Өдөр бүр ажлын эхэнд Clock In дарж цагаа бүртгэж, захиалгуудаа шалгахыг зөвлөж байна. Ажлын төлөвийг тогтмол шинэчлэх нь багийн бусад гишүүдэд мэдээлэлтэй байхад тусална.
:::
