# Механикийн ажлын самбар

Механикийн самбар нь механикч бүрийн өнөөдрийн ажил, гүйцэтгэл, цаг бүртгэлийг төвлөрүүлсэн дэлгэц юм.

## Хандалт

- `/dashboard/mechanic` хаягаар орно
- **Механикч** эрхтэй хэрэглэгч өөрийн мэдээллийг харна
- **Админ** эрхтэй хэрэглэгч бүх механикчдын мэдээллийг харж, механикч сонгох боломжтой
- Бусад эрхтэй хэрэглэгчид "Restricted Access" мэдэгдэл харна

## Header хэсэг

Дээд хэсэгт дараах мэдээлэл харагдана:

- Механикийн **нэр**
- **Live** тэмдэг (ногоон, аниматай — бодит цагийн шинэчлэлтийг илэрхийлнэ)
- **Өнөөдрийн огноо** (монгол хэлээр)
- **Clock In / Clock Out** товч

## Clock In / Clock Out

Механикч ажлаа эхлэх, дуусгахдаа Clock In/Out товчоор цагаа бүртгэнэ.

| Төлөв | Товчны төрөл | Тайлбар |
| --- | --- | --- |
| **Clocked Out** | Ногоон (Play дүрс) | Цаг эхлүүлэх |
| **Clocked In** | Улаан (Square дүрс) | Цаг зогсоох |

- Цаг бүртгэсэн бол **хугацааны тоолуур** (HH:MM:SS) харагдана
- Цагийн төлөв, өнөөдрийн нийт цаг Hours Today карт дээр харагдана

::: tip Цагийн бүртгэлийн аюулгүй байдал
QR цагийн бүртгэлийг ашиглахад механикийн хувийн утас баталгаажуулалт болдог. Дэлгэрэнгүйг [QR цагийн бүртгэл](/qr-clock-in) хуудаснаас үзнэ үү.
:::

## KPI үзүүлэлтүүд

Самбар дээр **6 KPI карт** байрлана (хоёр эгнээ):

### Эхний эгнээ (4 карт)

| Карт | Дүрс | Өнгийн акцент | Тайлбар |
| --- | --- | --- | --- |
| **Completed Today** | CheckCircle2 | Ногоон | Өнөөдөр гүйцэтгэсэн захиалгын тоо. Дэд текст: services / parts тоо |
| **Revenue Today** | Coins | Цэнхэр | Өнөөдөр олсон орлого (₮). Дэд текст: "From completed orders" |
| **Active Jobs** | ClipboardList | Шар | Одоогоор идэвхтэй захиалгын тоо |
| **Hours Today** | Clock | Цэнхэр | Өнөөдөр ажилласан цаг (нэг аравтын бутархай). Clocked in/out төлөв харуулна |

### Дараагийн эгнээ (2 карт)

| Карт | Дүрс | Өнгийн акцент | Тайлбар |
| --- | --- | --- | --- |
| **Avg Job Value** | Coins | Цэнхэр | Захиалга бүрийн дундаж орлого (₮). Тренд өгөгдлөөс тооцно |
| **Jobs Per Day** | CheckCircle2 | Ногоон | Өдөр бүрийн дундаж захиалгын тоо. Тренд өгөгдлөөс тооцно |

::: tip KPI картууд
Бүх картууд **loading** төлөвтэй (Skeleton) эхний удаа ачаалахад харагдана. Өгөгдөл ирсний дараа бодит утгуудыг харуулна.
:::

## Trend график

**MechanicTrendChart** нь сүүлийн хэдэн долоо хоногийн ажлын тоо, орлого үзүүлэлтийг графикаар харуулна. График нь зөвхөн trend өгөгдөл байгаа үед л харагдана.

## Ажлын жагсаалт (Work Orders)

Механикчид өөрт томилогдсон ажлуудыг жагсаалтаар харна.

### Жагсаалтын загвар

Нэг мөрөнд дараах мэдээлэл байна:

| Элемент | Тайлбар |
| --- | --- |
| **Төлөвийн өнгөн бар** | Зүүн талд, төлөвийн өнгөтэй нарийн багана |
| **Төлөвийн цэг** | Төлөвийн өнгөтэй жижиг цэг. "In Progress", "Ready for Pickup" төлөвүүд аниматай (pulse) |
| **Харилцагчийн нэр** | Үндсэн текст |
| **Машины дугаар** | Бага хэмжээтэй дэд текст |
| **Тайлбар** | Захиалгын тайлбар (эсвэл "No description") |
| **Хугацаа** | Хэдэн минут/цагийн өмнө үүсгэсэн |
| **Дүн** | Баруун талд, форматлагдсан төгрөг |
| **Төлөвийн Badge + Dropdown** | Төлөвийн нэр + буулгах сум |

### Эрэмбэлэлт

Захиалгууд төлвөөр нь дараах дарааллаар эрэмбэлэгдэнэ:

1. **In Progress** (0)
2. **Ready for Pickup** (1)
3. **New** (2)
4. **Diagnosing** (3)
5. Бусад төлөвүүд (99)

### Төлөвийн шилжилт (Allowed Transitions)

| Одоогийн төлөв | Зөвшөөрөгдсөн дараагийн төлөв |
| --- | --- |
| **New** | Diagnosing |
| **Diagnosing** | In Progress |
| **In Progress** | Ready for Pickup |
| **Ready for Pickup** | Completed |
| **Cancelled** | — (төлөв солигдохгүй) |
| **Completed** | — (төлөв солигдохгүй) |

- Идэвхтэй төлөвүүдэд (New, Diagnosing, In Progress, Ready for Pickup) **Cancelled** нэмэгдэнэ
- Төлөвийн dropdown-оос шинэ төлөв сонговол шууд шинэчлэгдэнэ
- **Completed** төлөвт шилжүүлэхэд **PickupCompleteDialog** нээгдэж, харилцагчийн сэтгэл ханамж, санал, дараагийн цагийг бүртгэнэ

## Админ харагдац

Админ эрхтэй хэрэглэгч механикийн самбарт нэмэлт боломжуудтай:

### Механикч сонгох

- **MechanicSelect** дропдаунаар аль механикчийг харахаа сонгоно
- Анх ачаалахад анхны механикч автоматаар сонгогдоно

### Удирдлагын самбар (Quick Action Bar)

Админд дараах товчнууд гарч ирнэ:

| Товч | Дүрс | Холбоотой хуудас |
| --- | --- | --- |
| **Invite Mechanic** | UserPlus | Шинэ механикч нэмэх цонх |
| **Members** | Users | `/dashboard/organization/members` |
| **Payroll** | DollarSign | `/dashboard/payroll` |
| **Roles** | Shield | `/dashboard/organization/roles` |
| **Organization** | Building2 | `/dashboard/organization` |

### Шинэ механикч нэмэх

**NewMechanicSheet** цонхоор шинэ механикчийг бүртгэнэ. Ажлын самбарыг хаахад механикийн жагсаалт автоматаар шинэчлэгдэнэ.

## Sidebar (Баруун талын хэсэг)

Баруун талын самбарт дараах табууд байрлана:

| Таб | Дүрс | Агуулга |
| --- | --- | --- |
| **Stats** | BarChart3 | StatusSummary: Completed Today, Revenue Today, Active Jobs |
| **Jobs** | Wrench | RecentList: томилогдсон захиалгууд (төлөв, хугацаа, холбоос) |

### Stats таб

| Талбар | Тайлбар |
| --- | --- |
| Completed Today | Өнөөдөр гүйцэтгэсэн захиалгын тоо |
| Revenue Today | Өнөөдрийн нийт орлого (₮) |
| Active Jobs | Идэвхтэй захиалгын тоо |

### Jobs таб

| Талбар | Тайлбар |
| --- | --- |
| Primary | Машины дугаар (эсвэл "—") |
| Secondary | Төлөв |
| Timestamp | Хэдэн минут/цагийн өмнө |
| Холбоос | Захиалгын дэлгэрэнгүй хуудас руу шилжих |

::: info Ажлын тоо
Жагсаалтын дээд хэсэгт "X jobs" гэсэн тоо харагдана.
:::

## Ачаалах төлөв

Дараах тохиолдолд **Skeleton** харагдана:

- Эхний ачаалахад (күүшийн бус өгөгдөл)
- Күүшийн дараагийн өгөгдөл авч байх үед "Updating" тэмдэг (ногоон аниматай цэг) харагдана

## Түүхийн мэдээлэл

Work order бүрийн мөрөнд:

- Хэдэн минут/цагийн өмнө үүсгэсэн (`timeAgo`)
- 1 минутаас бага бол "Just now"
- 60 минутаас бага бол "Xm"
- 60 минутаас дээш бол "Xh Ym" форматаар
