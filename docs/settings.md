# Системийн тохиргоо

Тохиргооны хуудас нь байгууллагын үндсэн утгууд, харагдац, Telegram, комисс, оношилгооны шошго, өгөгдөл хуваалцах болон экспортын тохиргоог удирдана.

## Тохиргооны 8 хэсэг

| Хэсэг | Тайлбар |
| --- | --- |
| **General** | Байгууллагын үндсэн мэдээлэл, анхдагч утгууд |
| **Appearance** | Theme, өнгө, density |
| **Commission Rules** | Механикчийн комиссын дүрэм |
| **Pricing Rules** | Тээврийн хэрэгслийн төрөл, ангилалаас хамааран сэлбэг, үйлчилгээний үнийг автоматаар тохируулах |
| **Diagnosis Labels** | Оношилгооны шошгууд |
| **Telegram Bot** | Telegram холболт ба мэдэгдэл |
| **Vehicle Niche** | Аль марк, загварт төвлөрөхөө хязгаарлах |
| **Data Sharing** | Бусад байгууллагад харагдах өгөгдлийг удирдах |
| **Data & Export** | Өгөгдөл татах, backup хийх |

## General

General хэсэгт:

- байгууллагын нэр
- slug
- logo
- invoice prefix
- default currency
- default tax rate
- timezone
- date format
- default language
- brand color

зэргийг тохируулна.

Хэл солих үед систем locale cookie-г шинэчилж хуудсыг дахин ачаална. Brand color өөрчлөхөд preview шууд харагдана.

## Appearance

Appearance хэсгээс:

- **Light**
- **Dark**
- **System**

theme сонгоно.

Мөн интерфейсийн нягтрал, брэнд өнгөтэй холбоотой харагдацын тохиргоонуудыг өөрчилж болно.

## Commission Rules

Комиссын дүрмийн боломжит төрлүүд:

- labor хувь
- parts хувь
- revenue хувь
- work order бүрт тогтмол дүн

Дүрэм бүр дээр механикч, хувь, хязгаар, priority, идэвхтэй эсэхийг удирдана.

## Diagnosis Labels

Ажлын захиалгын complaint хэсэгт ашиглагдах шошгуудыг эндээс нэмэх, засах, устгана.

## Telegram Bot

Telegram хэсгээс:

- нэг удаагийн холболтын link үүсгэх
- bot-той холбогдох
- сануулга болон summary мэдэгдлүүдийг ашиглах

боломжтой.

## Vehicle Niche

Vehicle Niche нь цехийг тодорхой марк, загварт төвлөрүүлэхэд ашиглагдана.

- brand-уудаар сонгох
- model-уудаар нарийвчлах
- select all, clear all хийх

боломжтой.

## Data Sharing

Data Sharing идэвхтэй үед бусад байгууллагууд танай:

- харилцагч
- тээврийн хэрэгсэл
- үйлчилгээний түүх

зэрэг мэдээллийг зөвхөн харах түвшинд ашиглах боломжтой.

## Data & Export

Энэ хэсэгт customers, vehicles, work orders, inventory, services, expenses зэрэг өгөгдлийг экспортлох болон backup-тэй холбоотой үйлдлүүд байрлана.
