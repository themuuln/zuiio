# Системийн тохиргоо

Тохиргоо хэсгээс системийн үндсэн тохиргоонуудыг өөрчилж болно.

## Тохиргооны жагсаалт

| Тохиргоо | Тайлбар | Сонголтууд |
|----------|---------|-----------|
| Хэл | Интерфейсийн хэлийг солих | Монгол (MN), English (EN) |
| Валют | Мөнгөн тэмдэгтийг солих | MNT, USD, EUR, CNY |
| Байгууллагын тохиргоо | Байгууллагын нэр, PIN код | Засах холбоос |
| Засварын булангийн PIN | Булангийн хамгаалалт | 4-6 оронтой PIN |

## Хэл солих

1. **Тохиргоо** хэсэгт очно уу.
2. **"Хэл"** хэсэгт хүссэн хэлээ сонгоно уу.
3. Хуудас автоматаар шинэчлэгдэж, сонгосон хэлээр харуулна.

::: info
Хэлний тохиргоо нь cookie-д хадгалагдах бөгөөд дараагийн нэвтрэхэд автоматаар хэрэгжинэ.
:::

## Валют солих

Системийн бүх үнийг сонгосон валютаар харуулна. Өмнөх захиалгуудын үнэ өөрчлөгдөхгүй, зөвхөн дэлгэц дээр харуулах валют өөрчлөгдөнө.

## PIN код тохируулах

1. **Тохиргоо** хэсэгт очно уу.
2. **"Засварын булангийн PIN"** хэсэгт 4-6 оронтой PIN оруулна.
3. **"Хадгалах"** товч дарна.
4. Дараагийн удаа засварын булангийн хуудсыг нээхэд PIN шаардах болно.

::: danger
PIN кодоо хэнд ч бүү хэлээрэй! PIN кодыг тогтмол сольж байхыг зөвлөж байна.
:::
