# Системийн тохиргоо

Тохиргоо хэсгээс системийн үндсэн тохиргоонуудыг өөрчилж болно. Тохиргооны хуудас нь **Business defaults**, **Appearance** гэсэн хэсгүүдээс бүрдэнэ.

## Байгууллагын мэдээлэл

Хуудасны зүүн талд байгууллагын үндсэн мэдээлэл харагдана:

| Мэдээлэл | Тайлбар |
|-----------|---------|
| **Name** | Байгууллагын бүтэн нэр |
| **Slug** | Байгууллагын систем дэх товч нэр |

## Business defaults

### Үндсэн тохиргоонууд

| Тохиргоо | Тайлбар | Сонголтууд |
|----------|---------|-----------|
| **Invoice prefix** | Нэхэмжлэхийн дугаарын угтвар | 12 тэмдэгт хүртэлх текст (жишээ: INV) |
| **Default currency** | Системийн үндсэн валют | MNT (₮), USD ($), EUR (€), CNY (¥) |
| **Default tax rate (%)** | Үндсэн татварын хувь | 0-100% |
| **Timezone** | Цагийн бүс | Жишээ: Asia/Ulaanbaatar |
| **Date format** | Огнооны формат | Жишээ: YYYY-MM-DD |
| **Default language** | Интерфейсийн хэл | Монгол (MN), English (EN) |

### Хэл солих

1. **Default language** хэсэгт хүссэн хэлээ сонгоно уу.
2. **Save** товч дарна уу.
3. Хэрэв одоогийн хэлнээс өөр хэл сонговол хадгалах үед cookie-д хадгалагдаж, хуудас дахин ачаалагдана.

::: info
Хэлний тохиргоо нь cookie-д хадгалагдах бөгөөд дараагийн нэвтрэхэд автоматаар хэрэгжинэ.
:::

### Валют солих

Default currency хэсгээс системийн бүх үнийг харуулах валютыг сонгоно. Өмнөх захиалгуудын үнэ өөрчлөгдөхгүй, зөвхөн дэлгэц дээр харуулах валют өөрчлөгдөнө.

### Нэмэлт тохиргоонууд

**Email notifications** — харилцагчдад имэйл мэдэгдэл илгээх боломжийг идэвхжүүлнэ.

Эдгээр тохиргоонууд нь toggle хэлбэрээр харагдана.

## Appearance (Гадаад байдал)

Хуудасны доод хэсэгт гадаад байдлын тохиргоо байрлана:

| Сонголт | Тайлбар |
|---------|---------|
| **Light** | Цагаан дэвсгэртэй гэрэлтэй горим |
| **Dark** | Хар дэвсгэртэй харанхуй горим |
| **System** | Системийн тохиргоогоор автоматаар солигдоно |

Сонголтоо өөрчлөхөд шууд хэрэгжиж, дараагийн нэвтрэлтэнд хадгалагдана.
