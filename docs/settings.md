# Системийн тохиргоо

Тохиргооны хуудас нь 5 табаас бүрдэнэ: **General**, **Appearance**, **Commission Rules**, **Diagnosis Labels**, **Data & Export**.

---

## General

### Байгууллагын мэдээлэл

Зүүн талд байгууллагын үндсэн мэдээлэл харагдана:

| Мэдээлэл | Тайлбар                                      |
| -------- | -------------------------------------------- |
| **Name** | Байгууллагын бүтэн нэр                       |
| **Slug** | Байгууллагын систем дэх товч нэр             |
| **Logo** | Байгууллагын лого дээр дарж шинэ зураг солих |

### Үндсэн тохиргоонууд

| Тохиргоо                 | Тайлбар                      | Сонголтууд                            |
| ------------------------ | ---------------------------- | ------------------------------------- |
| **Invoice prefix**       | Нэхэмжлэхийн дугаарын угтвар | 12 тэмдэгт хүртэлх текст (жишээ: INV) |
| **Default currency**     | Системийн үндсэн валют       | MNT (₮), USD ($), EUR (€), CNY (¥)    |
| **Default tax rate (%)** | Үндсэн татварын хувь         | 0-100%                                |
| **Timezone**             | Цагийн бүс                   | Жишээ: Asia/Ulaanbaatar               |
| **Date format**          | Огнооны формат               | Жишээ: YYYY-MM-DD                     |
| **Default language**     | Интерфейсийн хэл             | Монгол (MN), English (EN)             |
| **Brand color**          | Байгууллагын брэнд өнгө      | Hex өнгөний код (жишээ: #2563eb)      |

#### Хэл солих

**Default language** хэсэгт хүссэн хэлээ сонгоод **Save** дарна. Хэрэв одоогийн хэлнээс өөр хэл сонговол cookie-д хадгалагдаж, хуудас дахин ачаалагдана.

#### Валют солих

Default currency хэсгээс системийн бүх үнийг харуулах валютыг сонгоно. Өмнөх захиалгуудын үнэ өөрчлөгдөхгүй, зөвхөн дэлгэц дээр харуулах валют өөрчлөгдөнө.

#### Брэнд өнгө

**Brand color** талбарт Hex код оруулснаар системийн акцент өнгө (товчлуур, холбоос, идэвхтэй элемент) тухайн өнгөөр шинэчлэгдэнэ.

## Appearance

### Theme (Гадаад байдал)

| Сонголт    | Тайлбар                                     |
| ---------- | ------------------------------------------- |
| **Light**  | Цагаан дэвсгэртэй гэрэлтэй горим            |
| **Dark**   | Хар дэвсгэртэй харанхуй горим               |
| **System** | Системийн тохиргоогоор автоматаар солигдоно |

Сонголтоо өөрчлөхөд шууд хэрэгжиж, дараагийн нэвтрэлтэнд хадгалагдана.

### Интерфейсийн нягтрал (Density)

| Сонголт         | Тайлбар                                     |
| --------------- | ------------------------------------------- |
| **Comfortable** | Зай завсар ихтэй, уншихад хялбар            |
| **Compact**     | Бага зайтай, илүү их мэдээлэл нэг дэлгэцэнд |

### Харагдах байдлын тохиргоо

| Тохиргоо                | Тайлбар                             |
| ----------------------- | ----------------------------------- |
| **Show Sidebar**        | Зүүн хажуугийн цэсийг харуулах/нуух |
| **Show Language Badge** | Хэлний тэмдэглэгээг харуулах/нуух   |

## Commission Rules

Комиссын дүрэм хэсэгт механикчдын урамшууллын тохиргоог удирдана.

### Комиссын төрлүүд

| Төрөл                     | Тайлбар                         |
| ------------------------- | ------------------------------- |
| **Percentage of Labor**   | Ажлын хөлсний тодорхой хувь     |
| **Percentage of Parts**   | Сэлбэгийн орлогын тодорхой хувь |
| **Percentage of Revenue** | Нийт орлогын тодорхой хувь      |
| **Fixed per Work Order**  | Захиалга бүрт тогтмол дүн       |

### Шинэ дүрэм нэмэх

1. **"Add rule"** товч дарна уу.
2. **Нэр** — дүрмийн нэр (жишээ нь: "Механикийн үндсэн комисс").
3. **Механикч** — тодорхой механикч эсвэл бүх механикчид.
4. **Комиссын төрөл** — дээрх төрлүүдээс сонгоно.
5. **Комиссын хувь / дүн** — хувиар эсвэл тогтмол дүнгээр.
6. **Хамгийн бага / Их дүн** — заавал биш, комиссын дээд/доод хязгаар.
7. **Тэргүүлэх дараалал** — нэг механикчид хэд хэдэн дүрэм хамаарах бол аль дүрэм давамгайлахыг тодорхойлно. **Бага тоо = өндөр тэргүүлэх дараалал**.
8. **"Save"** товч дарна уу.

### Идэвхжүүлэх/Идэвхгүй болгох

Дүрэм бүрийг toggle товчоор идэвхжүүлэх/идэвхгүй болгох боломжтой.

## Diagnosis Labels

Оношилгооны шошго нь ажлын захиалгын гомдол (complaint)-ыг ангилахад ашиглагдана.

### Жишээ шошго

| Шошго        | Тайлбар             |
| ------------ | ------------------- |
| Engine       | Хөдөлгүүрийн гэмтэл |
| Brake        | Тоормосны систем    |
| Electrical   | Цахилгаан           |
| Suspension   | Түдгэлзүүлэлт       |
| Transmission | Хурдны хайрцаг      |
| AC           | Агааржуулагч        |
| Tire         | Дугуй               |
| Body         | Их бие              |
| Steering     | Жолооны механизм    |
| Exhaust      | Яндангийн систем    |
| Cooling      | Хөргөлтийн систем   |
| Fuel System  | Түлшний систем      |
| Other        | Бусад               |

### Шинэ шошго нэмэх

1. **"Add label"** товч дарна уу.
2. **Нэр** — шошгоны нэр (жишээ нь: "Engine").
3. **Тодорхойлолт** — заавал биш, нэмэлт тайлбар.
4. **Өнгө** — шошгоны өнгө.
5. **"Save"** товч дарна уу.

Шошго нь ажлын захиалга үүсгэх үед гомдлын төрлийг сонгоход хэрэглэгдэнэ. Захиалгын жагсаалтад шошго өнгөт тэмдэглэгээтэй харагдана.

## Data & Export

### Data Export

Өгөгдлийг JSON форматаар экспортлох боломжтой:

| Өгөгдлийн төрөл | Агуулга                      |
| --------------- | ---------------------------- |
| **Customers**   | Харилцагчдын мэдээлэл        |
| **Vehicles**    | Тээврийн хэрэгслийн мэдээлэл |
| **Work Orders** | Ажлын захиалгууд             |
| **Inventory**   | Бараа материал               |
| **Services**    | Үйлчилгээний каталог         |
| **Expenses**    | Зарлагын бүртгэл             |

Экспорт хийхдээ:

1. Хүссэн өгөгдлийн төрлөө сонгоно уу.
2. **"Export"** товч дарна уу.
3. JSON файл татагдаж эхэлнэ.

### Database Backup

Өгөгдлийн сангийн backup-ийг дараах форматаар татаж авах боломжтой:

- **PostgreSQL dump** (.sql)
- **CSV export** — хүснэгт тус бүрээр
