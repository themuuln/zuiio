# Санхүү

Санхүүгийн хэсэг нь таны бизнесийн орлогын тайлан, гүйлгээний бүртгэл, нэхэмжлэхийн удирдлагыг нэг дороос харуулна.

## Хугацааны шүүлтүүр

Хуудасны дээд хэсэгт дараах хугацааны шүүлтүүр байрлана:

| Шүүлтүүр | Хугацаа |
|----------|---------|
| **Today** | Өнөөдөр |
| **This Week** | Энэ 7 хоног |
| **This Month** | Энэ сар |
| **All Time** | Бүх хугацаа |

## Гурван таб

Санхүүгийн хуудас **3 табаас** бүрдэнэ:

### 1. Overview (Тойм)

Сонгосон хугацааны санхүүгийн үндсэн үзүүлэлтүүд:

| Үзүүлэлт | Тайлбар |
|-----------|---------|
| **Нийт орлого** | Сонгосон хугацааны нийт орлого |
| **Идэвхтэй захиалга** | Одоо хийгдэж буй захиалгын тоо |
| **Дундаж захиалга** | Захиалга бүрийн дундаж дүн |
| **Нийт харилцагч** | Бүртгэлтэй харилцагчийн тоо |
| **Үйлчилгээний орлого** | Үйлчилгээнээс олсон орлого |
| **Сэлбэгийн орлого** | Сэлбэг зарлагаас олсон орлого |

Мөн орлого, зарлагын **график харагдац** багтана.

### 2. Transactions (Гүйлгээ)

Бүх санхүүгийн гүйлгээний дэлгэрэнгүй жагсаалт. Эндээс:

- Гүйлгээний төрөл (төлбөр, буцаалт, etc.)
- Дүн, огноо
- Холбогдох захиалга
- Төлбөрийн төрлөөр шүүх (бэлэн мөнгө, карт, шилжүүлэг)

### 3. Invoices (Нэхэмжлэх)

Нэхэмжлэхийн жагсаалт, төлөв. Нэхэмжлэх бүрт:

- Нэхэмжлэхийн дугаар
- Харилцагчийн нэр
- Нийт дүн, төлсөн дүн
- Төлөв (төлсөн / төлөгдөөгүй / хэсэгчилсэн)
- Нээх, татаж авах боломж
