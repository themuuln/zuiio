# Санхүү

Санхүүгийн хэсэг нь орлого, нэхэмжлэх, гүйлгээ, зарлагын төлөвийг нэг дэлгэц дээрээс хянахад зориулагдсан.

## Хугацааны шүүлтүүр

Дараах хугацаагаар санхүүгийн өгөгдлөө шинэчилж харна:

- **Today**
- **This Week**
- **This Month**
- **All Time**

## Дөрвөн үндсэн таб

| Таб | Тайлбар |
| --- | --- |
| **Overview** | Нийт орлого, ашиг, active work orders, revenue split |
| **Transactions** | Санхүүгийн гүйлгээний жагсаалт |
| **Invoices** | Нэхэмжлэхийн удирдлага |
| **Expenses** | Зарлагын хураангуй ба сүүлийн бичилтүүд |

## Overview

Overview таб дээр дараах KPI-ууд түгээмэл харагдана:

- Total Revenue
- Active Work Orders
- Avg Repair Order
- Total Customers
- Gross Profit
- Service Revenue
- Parts Revenue
- Total Vehicles
- Service Mix

Мөн:

- revenue trend chart
- top services
- insight line

харагдана.

## Invoices

Нэхэмжлэхийн урсгал:

| Төлөв | Тайлбар |
| --- | --- |
| **Draft** | Ноорог |
| **Sent** | Харилцагчид илгээсэн |
| **Paid** | Бүрэн төлөгдсөн |
| **Partial** | Хэсэгчлэн төлөгдсөн |
| **Overdue** | Хугацаа хэтэрсэн |
| **Unpaid** | Төлөгдөөгүй |
| **Cancelled** | Цуцлагдсан |

Invoices таб дээр:

- статусын KPI
- хайлт
- статусаар шүүх
- share link
- email илгээх
- экспорт

боломжтой.

## Төлбөр бүртгэл

Нэхэмжлэх дээрх төлбөрүүдийг дараах төрлөөр бүртгэнэ:

- cash
- card
- bank transfer
- manual

Төлбөр бүртгэсний дараа `amount_paid`, `balance_due`, төлөв автоматаар шинэчлэгдэнэ.

## Public invoice link

Нэхэмжлэх бүр public token-той холбоосоор:

- харилцагчид илгээх
- хэвлэх
- PDF хэлбэрээр ашиглах

боломжтой.

## Expenses

Expenses таб нь:

- нийт зарлага
- энэ сарын зарлага
- unpaid зарлага
- сүүлийн зарлагууд

гэсэн товч тоймыг харуулна.

Нарийвчилсан зарлагын модульд [Зарлагын бүртгэл](/expenses) хуудаснаас орно.
