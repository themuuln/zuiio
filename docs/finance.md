# Санхүү

![Санхүү](/images/finance.png)

Санхүүгийн хэсэг нь орлого, нэхэмжлэх, гүйлгээ, зарлагын төлөвийг нэг дэлгэц дээрээс хянахад зориулагдсан.

## Хугацааны шүүлтүүр

Хуудасны дээд хэсэгт **DateRangePicker** компонентоор хүссэн хугацааны хүрээгээ сонгон өгөгдлөө шинэчилж болно. Анхдагчаар сүүлийн **3 сар**-ын хугацааг харуулна.

- Огнооны хүрээг эхлэх болон дуусах огноогоор тохируулна
- Хугацаа сонгоогүй бол бүх өгөгдлийг харуулна (том өгөгдлийн сантай бол удаашралтай байж болно)

## Салбарын шүүлтүүр

Хэрэв **finance_separate_per_branch** тохиргоо идэвхтэй бол салбарын шүүлтүүр нэмэгдэнэ. Нэг салбартай байгууллагад энэ шүүлтүүр харагдахгүй.

## Дөрөв + нэг үндсэн таб

| Таб | Дүрс | Тайлбар |
| --- | --- | --- |
| **Overview** | 📊 | Нийт орлого, ашиг, active work orders, revenue split |
| **Transactions** | 📋 | Санхүүгийн гүйлгээний жагсаалт |
| **Invoices** | 💲 | Нэхэмжлэхийн удирдлага |
| **Expenses** | 📈 | Зарлагын хураангуй ба сүүлийн бичилтүүд |
| **Refunds** | 🔄 | Буцаалтын жагсаалт ба статистик |

## Overview

Overview таб нь бизнесийн санхүүгийн ерөнхий байдлыг харуулна. Гурван төлөв байж болно:

### Бүх өгөгдөл байхгүй үед (Empty State)

Хэрэв ажлын захиалга, орлого, гүйлгээ байхгүй бол **"No financial data"** зургийн мессеж харагдана.

### Орлого байхгүй, идэвхтэй захиалга байгаа үед (No Revenue Banner)

Work order-ууд **Completed** төлөвт ороогүй үед зөвлөх мессеж гарч ирнэ:

- **"X work order(s) in progress"** — идэвхтэй захиалгын тоо
- Захиалгуудыг хаасны дараа санхүүгийн үзүүлэлтүүд гарч ирэх талаар тайлбар
- Дараах KPI картууд харуулна:
  - Active Work Orders ("Currently in progress" дэд мессежтэй)
  - Total Customers
  - Total Vehicles
  - Service Revenue ("Complete WOs to populate" дэд мессежтэй)

### Бүрэн үзүүлэлт (Full View)

Инсайт мөр болон KPI картууд:

**Инсайт мөр (амбер өнгийн карт):**
Орлого, ашиг, margin, дуусгасан захиалга, идэвхтэй захиалга, дундаж захиалгын дүн зэргийг нэг мөрөөр харуулна.

**KPI картууд (2 эгнээ):**

| Карт | Дүрс | Тайлбар |
| --- | --- | --- |
| **Total Revenue** | 💲 | Нийт орлого + "X completed today" дэд мессеж |
| **Active Work Orders** | 🕐 | Идэвхтэй ажлын захиалга + "Currently in progress" |
| **Avg Repair Order** | 📈 | Дундаж захиалгын дүн |
| **Total Customers** | 👥 | Нийт харилцагч |
| **Gross Profit** | 📈 | Цэвэр ашиг + margin хувь |
| **Service Revenue** | 🔧 | Үйлчилгээний орлого + "Labor & services" |
| **Parts Revenue** | 📋 | Сэлбэгийн орлого + "Parts & materials" |
| **Total Vehicles** | 📈 | Нийт тээврийн хэрэгсэл |
| **Service Mix** | % | Үйлчилгээ vs Сэлбэгийн харьцаа |

**Revenue Trend Chart:**
Орлого болон ажлын захиалгын өсөлтийг area chart-аар харуулна. Хоёр шугам: цэнхэр (Revenue), ногоон (Work Orders).

**Revenue Breakdown Bar:**
Үйлчилгээ ба сэлбэгийн орлогын харьцааг хөндлөн шугамаар харуулна:
- Цэнхэр — Services (хувь болон мөнгөн дүн)
- Шаргал — Parts (хувь болон мөнгөн дүн)
- Нийт орлого 0 байвал харагдахгүй

**Top Services:**
Хамгийн их орлого авсан дээд 8 үйлчилгээний хүснэгт:

| Багана | Тайлбар |
| --- | --- |
| **Service** | Үйлчилгээний нэр |
| **Count** | Хийсэн тоо |
| **Revenue** | Орлого |

### Баруун sidebar

Overview таб сонгосон үед баруун талын sidebar дээр:
- **Period Summary**: Нийт орлого, үйлчилгээний орлого, сэлбэгийн орлого, идэвхтэй захиалга, өнөөдөр дуусгасан, цэвэр ашиг
- **Recent Transactions**: Сүүлийн гүйлгээнууд (захиалгын дугаар, харилцагч, машин, дүн, огноо)

## Transactions

Гүйлгээний жагсаалт нь дуусгасан ажлын захиалгуудын мөнгөн урсгалыг харуулна.

### Хайх ба статистик

- **Хайлт**: Харилцагчийн нэр, машиний дугаар, захиалгын дугаараар хайж болно
- **Тоо**: Нийт ажлын захиалгын тоо харуулна

### Хүснэгтийн мэдээлэл

| Багана | Тайлбар |
| --- | --- |
| **#** | Захиалгын дугаар (эхний 8 тэмдэгт) |
| **Customer** | Харилцагчийн нэр |
| **Vehicle** | Машины дугаар (нэмэлт өнгөөр) |
| **Status** | Захиалгын төлөв (Badge) |
| **Services** | Үйлчилгээний нийт дүн |
| **Parts** | Сэлбэгийн нийт дүн |
| **Total** | Нийт дүн (togul-noms, жинлэлттэй) |
| **Date** | Үүсгэсэн огноо |

- Бүх баганаар **эрэмбэлэх** боломжтой
- Хайлтын үр дүнг **Highlight** хийнэ
- Мобайл дээр **карт хэлбэрээр** харуулна

### Excel экспорт

Гүйлгээний хүснэгтийг Excel-д экспортлох боломжтой. Экспортод WO #, Customer, Vehicle, Status, Services, Parts, Total, Date багтана.

## Invoices

Нэхэмжлэхийн удирдлагын хэсэг.

### KPI картууд

| Карт | Тайлбар |
| --- | --- |
| **Total Invoices** | Нийт нэхэмжлэхийн тоо |
| **Sent** | Илгээсэн нэхэмжлэхийн тоо |
| **Paid** | Төлөгдсөн нэхэмжлэхийн тоо + нийт төлсөн дүн |
| **Outstanding** | Төлөгдөөгүй нийт дүн + хэд нь хугацаа хэтэрсэн |

### Шүүлтүүр ба хайлт

- **Хайлт**: Нэхэмжлэхийн дугаар, харилцагчийн нэр, машин дугаараар хайж болно (fuzzy search)
- **Статус шүүлтүүр**: Draft / Sent / Paid товчлуурууд

### Нэхэмжлэхийн хүснэгт

| Багана | Тайлбар |
| --- | --- |
| **Invoice #** | Нэхэмжлэхийн дугаар (monospace) |
| **Customer** | Харилцагчийн нэр |
| **Vehicle** | Машины дугаар |
| **Status** | Төлөв (өнгөт badge) |
| **Total** | Нийт дүн |
| **Date** | Олгосон огноо |
| **Actions** | Үйлдлүүд |

### Нэхэмжлэхийн төлөвүүд

| Төлөв | Өнгө | Тайлбар |
| --- | --- | --- |
| **Draft** | Саарал | Ноорог |
| **Sent** | Цэнхэр | Харилцагчид илгээсэн |
| **Paid** | Ногоон | Бүрэн төлөгдсөн |
| **Partial** | Цэнхэр | Хэсэгчлэн төлөгдсөн |
| **Overdue** | Улаан (анизмитэй) | Хугацаа хэтэрсэн |
| **Unpaid** | Амбер | Төлөгдөөгүй |
| **Cancelled** | Саарал | Цуцлагдсан |

### Үйлдлүүд

- **Холбоос хуулах**: Нэхэмжлэхийн public token-тэй холбоосыг clipboard-д хуулна
- **Имэйл илгээх**: Харилцагчийн имэйл хаягаар нэхэмжлэхийг илгээнэ (илгээсэн бол имэйлийн дүрсээр тэмдэглэгдэнэ)
- **Экспорт**: Excel файл болгон татаж авч болно

## Төлбөр бүртгэл

Нэхэмжлэх дээрх төлбөрүүдийг дараах төрлөөр бүртгэнэ:

- cash
- card
- bank transfer
- manual

Төлбөр бүртгэсний дараа `amount_paid`, `balance_due`, төлөв автоматаар шинэчлэгдэнэ.

## Public invoice link

Нэхэмжлэх бүр public token-той холбоосоор:

- харилцагчид илгээх
- хэвлэх
- PDF хэлбэрээр ашиглах

боломжтой.

### KPI картууд

| Карт | Тайлбар |
| --- | --- |
| **Total Expenses** | Бүртгэлтэй нийт зарлагын тоо |

| --- | --- |

## Refunds (Буцаалт)

Буцаалтын таб нь нэхэмжлэхүүдэд хийсэн буцаалтуудын жагсаалт болон статистикийг харуулна.

### KPI картууд

| Карт | Тайлбар |
| --- | --- |
| **Total Refunds** | Нийт буцаалтын тоо |
| **Total Refunded** | Нийт буцаагдсан дүн (₮) |
| **Pending Amount** | Хүлээгдэж буй буцаалтын дүн (₮) |
| **Avg Refund** | Дундаж буцаалтын дүн (₮) |

### Хайлт ба шүүлтүүр

- **Хайлт**: Нэхэмжлэхийн дугаар, шалтгаан, лавлагаагаар хайж болно
- **Статус шүүлтүүр**: All / Completed / Pending / Cancelled / Failed товчлуурууд

### Буцаалтын хүснэгт

| Багана | Тайлбар |
| --- | --- |
| **Invoice #** | Нэхэмжлэхийн дугаар (monospace) |
| **Customer** | Харилцагчийн нэр |
| **Amount** | Буцаалтын дүн (улаан өнгөөр, -₮) |
| **Method** | Буцаалтын арга (cash, card, bank_transfer, store_credit) |
| **Reason** | Шалтгаан |
| **Status** | Төлөв (өнгөт badge) |
| **Date** | Буцаалт хийсэн огноо |
| **Actions** | Үйлдлүүд (зөвхөн pending үед) |

### Буцаалтын төлөвүүд

| Төлөв | Өнгө | Тайлбар |
| --- | --- | --- |
| **Completed** | Ногоон | Буцаалт амжилттай хийгдсэн |
| **Pending** | Амбер | Буцаалт хүлээгдэж байна |
| **Cancelled** | Саарал | Буцаалт цуцлагдсан |
| **Failed** | Улаан | Буцаалт амжилтгүй болсон |

### Буцаалтын аргууд

| Арга | Тайлбар |
| --- | --- |
| **Cash** | Бэлэн мөнгөөр буцаалт |
| **Card** | Картын буцаалт |
| **Bank Transfer** | Банкны шилжүүлгээр буцаалт |
| **Store Credit** | Дэлгүүрийн зээлээр буцаалт (харилцагчийн зээлийн үлдэгдэлд нэмэгдэнэ) |

### Буцаалт хийх журам

1. Ажлын захиалгын дэлгэрэнгүй хуудасны **Төлбөр** хэсэгт орно
2. "Record Refund" товчийг дарна (зөвхөн төлсөн хэсэг байгаа үед харагдана)
3. Буцаалтын дүн, арга, шалтгааныг бөглөнө
4. Баталгаажуулах цонхонд "Confirm" товчийг дарна

### Анхааруулга

- Буцаалт хийсний дараа **цуцлах** боломжгүй (зөвхөн pending төлөвтэй буцаалтыг цуцалж болно)
- Нэхэмжлэхийн нийт дүнээс их буцаалт хийх боломжгүй
- Нэхэмжлэхийг цуцалбал буцаалтуудад нөлөөлнө

::: tip Дэлгүүрийн зээл
**Store Credit** сонгосон тохиолдолд харилцагчийн зээлийн үлдэгдэл автоматаар нэмэгдэнэ. Дараагийн худалдан авалтаар энэ зээлийг ашиглах боломжтой.
:::

::: warning Анхааруулга
Буцаалтыг зөвхөн шаардлагатай үед хийнэ. Буцаалт нь орлогоос хасагддаг тул бизнесийн тооцоонд нөлөөлнө.
:::

::: tip Зөвлөмж
Санхүүгийн хуудсыг тогтмол шалгаж байх нь бизнесийн санхүүгийн байдлыг цаг тухайд нь мэдэхэд тусална. Revenue Trend Chart-аар орлогын чиг хандлагыг хянах, Top Services-аар хамгийн их орлого авсан үйлчилгээг тодорхойлох боломжтой.
:::

::: info Салбарын шүүлтүүр
Хэрэв танай байгууллага олон салбартай бол **finance_separate_per_branch** тохиргоог идэвхжүүлснээр салбар бүрийн санхүүгийн өгөгдлийг тусад нь харах боломжтой болно.
:::
