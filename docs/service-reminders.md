# Үйлчилгээний сануулга

Үйлчилгээний сануулгын хэсэг нь харилцагчдын тээврийн хэрэгслийн үйлчилгээний хуваарийг хянаж, тогтмол засвар үйлчилгээг мартахгүй байхад тусална.

## Ерөнхий ойлголт

Үйлчилгээний сануулга нь дараах зарчмаар ажилладаг:

1. **Хуваарь үүсгэх** — машин, үйлчилгээ, давтамжаар сануулгын хуваарь үүсгэнэ
2. **Дуусах хугацааг тооцоолох** — сүүлийн үйлчилгээний огноо ба интервалаар дараагийн дуусах хугацааг тооцоолно
3. **Мэдэгдэл илгээх** — дуусах хугацаа ойртоход харилцагчид мэдэгдэл илгээнэ

## Хуваарийн жагсаалт

Үйлчилгээний сануулгын хуудас нь **Сануулга** болон **Түүх** гэсэн хоёр табаас бүрдэнэ.

### Сануулга таб

Энэ хэсэгт бүртгэлтэй бүх үйлчилгээний хуваарийг хүснэгт хэлбэрээр харуулна:

| Талбар | Тайлбар |
|--------|---------|
| **Машин** | Тээврийн хэрэгслийн марк, загвар, улсын дугаар |
| **Үйлчилгээ** | Үйлчилгээний нэр |
| **Интервал** | Давтамж (сар / км-ээр) |
| **Сүүлийн үйлчилгээ** | Хамгийн сүүлд хийгдсэн огноо |
| **Дараагийн хугацаа** | Дараагийн үйлчилгээ хийх ёстой огноо |
| **Сануулга** | Идэвхтэй / Идэвхгүй |

**Дуусах хугацааны өнгөт тэмдэглэгээ:**

| Өнгө | Утга |
|------|------|
| 🟢 Хар | Хугацаа хараахан болоогүй |
| 🟡 Шар | 7 хоногийн дотор дуусах хугацаа ойртсон |
| 🔴 Улаан | Хугацаа хэтэрсэн |

### Түүх таб

Энэ хэсэгт илгээгдсэн сануулгын түүх харагдана:
- Илгээгдсэн огноо
- Харилцагч
- Машин
- Үйлчилгээ
- Суваг (app / email)
- Төлөв (илгээгдсэн / алдаа)

## Шинэ хуваарь нэмэх

1. **"Үйлчилгээний сануулга"** хэсэгт орж **"Сануулга нэмэх"** товч дарна уу.

2. Дараах талбаруудыг бөглөнө үү:

| Талбар | Заавал | Тайлбар |
|--------|--------|---------|
| **Үйлчилгээний нэр** | Тийм | Сануулгын үйлчилгээний нэр |
| **Машин сонгох** | Үгүй | Тухайн машин сонгох (суллавал бүх машины сануулга) |
| **Интервал (сар)** | Үгүй | Хэдэн сар тутамд үйлчилгээ хийх (жишээ: 6 сар) |
| **Интервал (км)** | Үгүй | Хэдэн км тутамд үйлчилгээ хийх (жишээ: 10,000 км) |
| **Сүүлийн үйлчилгээний огноо** | Үгүй | Хамгийн сүүлд энэ үйлчилгээ хийгдсэн огноо |
| **Сүүлийн одометр** | Үгүй | Сүүлд хийх үед байсан одометрийн заалт |
| **Дараагийн хугацаа** | Үгүй | Гараар тохируулах бол энд оруулна |

3. **"Хадгалах"** товч дарна уу.

::: tip Автомат хугацаа тооцоолол
Хэрэв интервал (сар эсвэл км) болон сүүлийн үйлчилгээний огноог оруулбал систем дараагийн хугацааг автоматаар тооцоолно. Жишээ нь: Интервал 6 сар, сүүлийн үйлчилгээ 2026-01-15 → дараагийн хугацаа 2026-07-15.
:::

## Хуваарь устгах

Сануулгын мөрөн дээрх устгах товч дээр дарж хуваарийг устгаж болно. Зөөлөн устгалт (soft-delete) хийгдэх бөгөөд өгөгдөл мэдээллийн санд үлдэнэ.

## Үйл ажиллагааны товчлуурууд

Хуудасны дээд хэсэгт дараах үйлдлийн товчлуурууд байрлана:

| Товч | Үйлдэл |
|------|--------|
| **Түүхээс синхрончлох** | Ажлын захиалгын түүхээс угсарч шинэ хуваарь үүсгэх |
| **Хүлээгдэж буй сануулга илгээх** | Дуусах хугацаа ойртсон үйлчилгээний сануулгыг илгээх |
| **Тохиргоо** | Сануулгын ерөнхий тохиргоо |

### Түүхээс синхрончлох

**Sync History** товч нь өмнөх ажлын захиалгуудыг шинжилж, системд дараах үйлдлүүдийг хийх боломжийг олгоно:
- Захиалгад хийгдсэн үйлчилгээг илрүүлэх
- Тухайн үйлчилгээний сүүлийн огноог тодорхойлох
- Үйлчилгээний каталогид бүртгэгдсэн интервал (interval_months, interval_km) байвал түүгээр хуваарь үүсгэх

::: info Гараар болон автомат
Хуваарийг гараар нэмэх, засах боломжтой. Мөн Sync History товчоор захиалгын түүхээс автоматаар үүсгэж болно.
:::

### Хүлээгдэж буй сануулга илгээх

**Send Pending** товч нь дуусах хугацаа ойртсон эсвэл хэтэрсэн бүх идэвхтэй сануулгыг нэг дор илгээнэ.

### Тохиргоо

Тохиргооны цонхноос дараах тохиргоог өөрчлөх боломжтой:

| Тохиргоо | Тайлбар |
|----------|---------|
| **Сануулгын суваг** | Мэдэгдэл илгээх суваг: Зөвхөн апп, email, эсвэл бүгд |
| **Автомат идэвхжүүлэх** | Шинэ хуваарь нэмэхэд сануулгыг автоматаар идэвхжүүлэх эсэх |

## Үйлчилгээний каталогийн интервал холбоос

Үйлчилгээний каталогид үйлчилгээ бүрт **анхдагч интервал** (interval_months, interval_km) тохируулах боломжтой. Sync History товчоор захиалгын түүхээс хуваарь үүсгэхэд энэхүү интервалыг автоматаар ашиглана.

Анхдагч интервалууд:

| Үйлчилгээ | Интервал |
|-----------|----------|
| Тос солих (Oil change) | 6 сар |
| Дугуй (Tire rotation) | 6 сар |
| Тоормос (Brake) | 12 сар |
| Шүүгч (Filter) | 12 сар |
| Хөргөлт (Coolant) | 24 сар |
| Цагийн бүс (Timing belt) | 60 сар |

## CRM-тэй холбоо

Үйлчилгээний сануулга нь харилцагчийн удирдлагатай нягт холбоотой:
- Харилцагчийн машинд сануулга тохируулах
- Дуусах хугацаа ойртсон үед автомат мэдэгдэл илгээх
- Харилцагчийн үйлчилгээний түүхийг бүрэн харах

::: tip Зөвлөмж
Тос солих, шүүгч солих зэрэг тогтмол үйлчилгээний сануулгыг идэвхжүүлснээр харилцагчдыг цаг тухайд нь үйлчилгээнд ирүүлэх, давтамжийг нэмэгдүүлэх боломжтой.
:::

::: info Ухаалаг синхрончлол
Sync History товчоор захиалгын түүхээс шинэ хуваарь нэмэхэд, каталогид интервал бүртгэгдсэн үйлчилгээнүүд автоматаар илрүүлэгдэнэ. Энэ нь гараар нэмэх шаардлагагүйгээр олон машины хуваарийг хурдан тохируулах боломжийг олгоно.
:::
