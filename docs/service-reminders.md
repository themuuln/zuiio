# Үйлчилгээний сануулга

Үйлчилгээний сануулга нь тээврийн хэрэгсэл бүрийн дараагийн засвар үйлчилгээний хугацааг хянаж, харилцагчид цаг тухайд нь мэдэгдэл хүргэхэд зориулагдсан.

## Хоёр үндсэн таб

| Таб | Тайлбар |
| --- | --- |
| **Schedule List** | Идэвхтэй үйлчилгээний хуваарийн жагсаалт |
| **Reminder Logs** | Илгээсэн болон хүлээгдэж буй мэдэгдлийн түүх |

## Schedule List

Жагсаалтын хүснэгт дараах мэдээлэлтэй:

- машин
- үйлчилгээний нэр
- интервал
- сүүлийн үйлчилгээний огноо
- дараагийн хугацаа
- reminder идэвхтэй эсэх

Хугацааны төлөв:

- **ойртоогүй**
- **7 хоногийн дотор**
- **хэтэрсэн**

гэж ялгарч харагдана.

## Шинэ schedule нэмэх

`Add schedule` цонхоор:

- машин сонгох
- үйлчилгээний нэр оруулах
- catalog service-тай холбох
- сарын интервал
- км интервал
- сүүлийн үйлчилгээний огноо
- сүүлийн одометр
- дараагийн хугацаа

зэргийг бүртгэнэ.

## Засах ба устгах

Мөр бүр дээр:

- **edit**
- **delete**

үйлдэлтэй. Засварлах үед reminder идэвхтэй эсэх, интервал, тэмдэглэл зэргийг шинэчилж болно.

## Тохиргоо

Config sheet дотор дараах ерөнхий тохиргоо бий:

| Тохиргоо | Тайлбар |
| --- | --- |
| **Default channel** | in-app, email зэрэг анхдагч хүргэх суваг |
| **Auto enable** | Шинээр үүсгэсэн schedule-ууд reminder-аа автоматаар асаах эсэх |

## Үндсэн үйлдлүүд

Хуудасны дээд хэсгийн товчлууруудаар:

- **Sync History**: өмнөх ажлын захиалгуудаас schedule үүсгэх
- **Send Pending**: хугацаа болсон reminder-уудыг гараар илгээх
- **Settings**: channel болон auto-enable тохиргоо нээх

боломжтой.

## Reminder Logs

Түүхийн таб дээр:

- хэн рүү
- ямар машинад
- ямар үйлчилгээнд
- ямар сувгаар
- ямар төлөвтэй
- хэзээ илгээсэн

гэдгийг шалгана.

## Telegram холбоос

Хэрэв харилцагч Telegram bot-той холбогдсон бол reminder-уудыг Телеграмаар хүргэж болно. Үгүй бол email эсвэл in-app урсгалаар ажиллана.
