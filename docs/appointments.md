# Цаг товлолт (Appointments)

Цаг товлолт нь харилцагчийн үйлчилгээний цагийг урьдчилан товлох боломж юм.
Товлосон цагаас эхлэн захиалга, үнийн санал руу шилжих боломжтой.

## Төлвийн урсгал

| Төлөв | Тайлбар |
| --- | --- |
| **Scheduled** | Товлогдсон, хүлээгдэж байгаа |
| **Checked In** | Харилцагч ирсэн, бүртгэгдсэн |
| **In Progress** | Үйлчилгээ хийгдэж байгаа |
| **Completed** | Дууссан |
| **Cancelled** | Цуцлагдсан |
| **No Show** | Харилцагч ирээгүй |

## Шинэ цаг товлох

1. Хяналтын самбараас **Appointments** → **New Appointment** товч дарна
2. **Харилцагч** - Харилцагчийг хайж олох эсвэл шинээр үүсгэх
3. **Машин** - Холбогдох машиныг сонгох
4. **Title** - Үйлчилгээний нэр (жишээ нь: Тос солих, Тоормосны шалгалт)
5. **Date & Time** - Цагийг сонгох
6. **Description** - Нэмэлт тодорхойлолт
7. **Notes** - Дотоод тэмдэглэл

## Жагсаалтын хуудас

Одоогийн өдрийн цаг товлолтуудыг харж, төлвийг өөрчлөх, цуцлах боломжтой.
Төлвөөр шүүж, ирэх өдрүүдийн товлолтыг харах боломжтой.

## Үнийн саналтай холбоо

Товлолтоос directly үнийн санал (Quote) үүсгэж болно.
Тухайн appointment-ийн дэлгэрэнгүй хуудаснаас **Create Quote** товчоор
шинэ үнийн санал нээгдэх бөгөөд appointment_id холбогдсон байна.

## API

```
GET    /api/organizations/:id/appointments          — Жагсаалт (status, date, mechanic шүүлтүүр)
POST   /api/organizations/:id/appointments          — Шинэ цаг товлох
GET    /api/organizations/:id/appointments/:apptId  — Дэлгэрэнгүй
PATCH  /api/organizations/:id/appointments/:apptId  — Төлөв өөрчлөх
DELETE /api/organizations/:id/appointments/:apptId  — Цуцлах
```
