# Цаг товлолт (Appointments)

Цаг товлолт нь харилцагчийн үйлчилгээний цагийг урьдчилан товлох боломж юм. Товлосон цагаас эхлэн захиалга, үнийн санал руу шилжих боломжтой.

## Төлвийн урсгал

| Төлөв | Англи | Тайлбар |
| --- | --- | --- |
| **Товлогдсон** | Scheduled | Товлогдсон, хүлээгдэж байгаа |
| **Бүртгэгдсэн** | Checked In | Харилцагч ирсэн, бүртгэгдсэн |
| **Гүйцэтгэж буй** | In Progress | Үйлчилгээ хийгдэж байгаа |
| **Дууссан** | Completed | Дууссан |
| **Цуцлагдсан** | Cancelled | Цуцлагдсан |
| **Ирээгүй** | No Show | Харилцагч ирээгүй |
| **Хүсэлт** | Requested | Харилцагчаас хүсэлт ирсэн |

## Шинэ цаг товлох

1. Хяналтын самбараас **Appointments** → **New Appointment** товч дарна
2. **Харилцагч** (*) — Харилцагчийг хайж олох (CustomerSelect)
3. **Машин** (*) — Холбогдох машиныг сонгох (VehicleSelect). Харилцагч сонгосноор тухайн харилцагчийн машинууд шүүгдэнэ
4. **Title** (*) — Үйлчилгээний нэр (жишээ нь: Тос солих, Тоормосны шалгалт)
5. **Date & Time** (*) — Цагийг сонгох (DatePicker)
6. **Description** — Нэмэлт тодорхойлолт (заавал биш)
7. **Notes** — Дотоод тэмдэглэл (заавал биш)

(*) заавал бөглөх талбар

## Жагсаалтын хуудас

- Өнөөдрийн цаг товлолтуудыг харж, төлвийг өөрчлөх, цуцлах боломжтой
- **Status filter** — бүх төлөв эсвэл тодорхой төлөвөөр шүүж харах боломжтой
- **Branch filter** — салбарын шүүлтүүрээр тухайн салбарын товлолтуудыг харах боломжтой

### Цаг товлолтын жагсаалт

Нэг цаг товлолтын картад дараах мэдээлэл байна:

| Элемент | Тайлбар |
| --- | --- |
| **Цагийн хугацаа** | Эхлэх цаг (HH:MM). Дуусах цаг байвал "to HH:MM" |
| **Тусгаарлагч** | Баганын хооронд босоо шугам |
| **Гарчиг** | Үйлчилгээний нэр (bold) |
| **Харилцагч** | Харилцагчийн нэр (эсвэл "No customer") |
| **Төлөв** | Төлөвийг dropdown-оос шууд өөрчлөх боломжтой |
| **Цуцлах** | Улаан товч — цуцлах (DELETE) |

## Төлөв өөрчлөх

Товлолтын карт дээрх **төлөвийн dropdown**-оос шинэ төлөв сонгож болно:

1. Dropdown дээр дарна
2. Хүссэн төлөвийг сонгоно
3. Систем шууд шинэчилнэ
4. Амжилттай бол "Updated" мэдэгдэл гарна

## Цуцлах

Товлолтын картын баруун талд байрлах **Cancel** (улгаарсан) товч дээр дарж цуцалж болно. Цуцалсан товлолт жагсаалтаас арилна.

## Шинэ цаг товлох цонх (AppointmentCreateSheet)

Шинэ цаг товлох цонх нь **ResponsiveFormModal** ашиглан нээгдэнэ:

- Desktop дээр **Sheet** (баруун талаас нээгдэх)
- Mobile дээр **Modal** (доороос нээгдэх)
- Захиалгын формыг `AppointmentForm` ашиглан бүртгэнэ

## Үнийн саналтай холбоо

Товлолтоос шууд үнийн санал (Quote) үүсгэж болно. Тухайн appointment-ийн дэлгэрэнгүй хуудаснаас **Create Quote** товчоор шинэ үнийн санал нээгдэх бөгөөд appointment_id холбогдсон байна.

## API

```
GET    /api/organizations/:id/appointments          — Жагсаалт (status, date, branch шүүлтүүр)
POST   /api/organizations/:id/appointments          — Шинэ цаг товлох
GET    /api/organizations/:id/appointments/:apptId  — Дэлгэрэнгүй
PATCH  /api/organizations/:id/appointments/:apptId  — Төлөв өөрчлөх
DELETE /api/organizations/:id/appointments/:apptId  — Цуцлах
```

## Зөвлөмж

::: tip Өдөр бүр шалгах
Цаг товлолтуудыг өдөр бүр шалгаж, ирээгүй харилцагчдыг "No Show" төлөвт шилжүүлэхийг зөвлөж байна.
:::

::: tip Товлолтоос захиалга руу
Цаг товлолт нь харилцагчийг урьдчилан бүртгэх арга юм. Харилцагч ирсний дараа товлолтын төлөвийг "Checked In" болгож, дараа нь ажлын захиалга үүсгэнэ.
:::
