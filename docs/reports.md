# Тайлан

Тайлангийн хэсэг нь орлого, ашигт ажиллагаа, механикчийн гүйцэтгэл, үйлчилгээний бүтэц, retention зэрэг бизнесийн үзүүлэлтүүдийг нэг дор харуулна.

## Тайлангийн төрлүүд

| Төрөл | Тайлбар |
| --- | --- |
| **Daily** | Өдрийн гүйцэтгэл |
| **Weekly** | 7 хоногийн тайлан |
| **Monthly** | Сарын тайлан |
| **Custom** | Өөрийн сонгосон огнооны хүрээ |
| **EOD** | End-of-day механикчийн хаалтын тайлан |

## Шүүлтүүрүүд

Тайлангийн хуудаснаас:

- тайлангийн төрөл солих
- өдөр, 7 хоног, сар, custom range сонгох
- тодорхой механикчаар шүүх
- refresh хийх

боломжтой.

## Үндсэн KPI үзүүлэлтүүд

Тайлангийн дээд хэсэгт дараах картууд ээлжлэн харагдана:

- ажлын захиалгын тоо
- борлуулсан үйлчилгээний тоо
- нийт орлого
- gross profit
- margin
- effective labor rate
- parts to labor ratio

## Гол анализууд

Тайлан дотор дараах анализууд байна:

- **Insight Alerts**: системийн анхаарах ажиглалтууд
- **Forecast**: ойрын төсөөлөл
- **Target Card**: зорилтот гүйцэтгэл
- **Revenue Split**: үйлчилгээ ба сэлбэгийн орлогын бүтэц
- **Profit Breakdown**: орлого, өртөг, ашиг
- **Daily Revenue Chart**: өдөр өдрөөрх орлого
- **Mechanic Bar Chart**: механикчдын гүйцэтгэл
- **Service Breakdown Chart**: үйлчилгээний бүтцийн тайлан
- **Retention Card**: давтан үйлчлүүлэгчийн үзүүлэлт
- **PnL Card**: profit and loss тойм

## EOD тайлан

EOD харагдац нь тухайн өдрийн хаалтын тайлан бөгөөд:

- нийт ажлын тоо
- нийт орлого
- нийт комисс
- механикч тус бүрийн breakdown

гаргана.

Механикчийн хүснэгтийг Excel-д экспортлох боломжтой.

## Экспорт

Reports хэсгээс механикчийн хүснэгт болон EOD breakdown зэрэг гол хүснэгтүүдийг Excel файл болгон татаж авч болно.
