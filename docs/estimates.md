# Үнийн санал (Estimates / Quotes)

Үнийн санал (Quote) нь харилцагчид засвар, үйлчилгээний үнийг урьдчилан
мэдээлэх баримт бичиг юм. Зөвшөөрөгдсөн үнийн санал нь ажлын захиалга
(Work Order) болж хувирдаг.

## Төлвийн урсгал

```
Draft → Sent → Approved → Converted (ажлын захиалга болсон)
                     ↘ Declined / Expired
```

| Төлөв | Тайлбар |
| --- | --- |
| **Draft** | Ноорог — засварлах, нэмэх боломжтой |
| **Sent** | Харилцагчид хүргүүлсэн |
| **Approved** | Харилцагч зөвшөөрсөн — ажлын захиалга болгоход бэлэн |
| **Declined** | Харилцагч татгалзсан |
| **Expired** | Хүчинтэй хугацаа дууссан |
| **Converted** | Ажлын захиалга болж хувирсан |

## Шинэ үнийн санал үүсгэх

**Цэс:** Хажуугийн самбараас **Estimates** → **New Quote**

1. **Харилцагч сонгох** — хайх эсвэл шинээр үүсгэх
2. **Машин сонгох** — харилцагчийн машиныг сонгох
3. **Мөрүүд нэмэх:**
   - **Add Service** — Үйлчилгээний каталогаас сонгох
   - **Add Part** — Сэлбэгийн каталогаас сонгох
   - **Custom** — Гараар мөр оруулах
4. **Мөр бүр дээр:**
   - тоо хэмжээ
   - нэгжийн үнэ
   - хөнгөлөлт (хувиар эсвэл төгрөгөөр)
5. **Дүн** — Нийт үнийг автоматаар тооцоолно
6. **Хадгалах:**
   - **Save as Draft** — Ноорог хэлбэрээр хадгалах
   - **Create Quote** — Үүсгэх

## Үнийн саналыг ажлын захиалга болгох

Зөвхөн **Approved** төлөвтэй үнийн саналыг ажлын захиалга болгох боломжтой.

1. Үнийн санал **дэлгэрэнгүй хуудас** руу орно
2. **Convert to Work Order** товч дарна
3. Баталгаажуулах цонх гарч ирнэ
4. **Create Work Order** товч дарна
5. Шинэ ажлын захиалга автоматаар **Bay View** болон **Work Orders** жагсаалтад гарч ирнэ

### Хувиргах үед юу болох вэ?

1. Шинэ `work_order` үүснэ (customer, vehicle, discount зэрэг мэдээллээр)
2. Үнийн саналын мөрүүд (`estimate_items`) дараах байдлаар хуулагдана:
   - **service** төрлийн мөрүүд → `work_order_services`
   - **part** төрлийн мөрүүд → `work_order_parts`
   - **custom** төрлийн мөрүүд → `work_order_services` (service_name болж орно)
3. Алхам бүрт `service_price_history` / `part_price_history` шинэчлэгдэнэ
4. **Status History** дээр "Created from estimate #EST-00001" гэж тэмдэглэгдэнэ
5. Үнийн саналын төлөв `converted` болж, `converted_work_order_id` хадгалагдана
6. Ажлын захиалгын `source_estimate_id` талбарт үнийн саналын ID хадгалагдана

### Яагаад хэрэгтэй вэ?

- Харилцагчид засварын өмнөх үнийг баталгаажуулж авах
- Баталгаажсан үнээр захиалга автоматаар үүсгэх
- Захиалгын гарал үүслийг мөрдөх
- Баталгаажаагүй үнийн саналаас захиалга үүсгэхээс сэргийлэх

## Дэлгэрэнгүй хуудас

Үнийн саналын дэлгэрэнгүй хуудаснаас:

- Үнийн саналын дугаар (EST-00001)
- Харилцагч, машины мэдээлэл
- Мөрүүдийн дэлгэрэнгүй (төрөл, тоо, үнэ, хөнгөлөлт)
- Нийт дүн
- Тэмдэглэл, нөхцөл (terms & conditions)
- Төлөв өөрчлөх (Draft → Sent → Approved → Declined)
- Ажлын захиалга болгох (зөвхөн Approved төлөвт)

## API

```
GET    /api/organizations/:id/estimates               — Жагсаалт (status, customer шүүлтүүр)
POST   /api/organizations/:id/estimates               — Шинэ үнийн санал
GET    /api/organizations/:id/estimates/:estId        — Дэлгэрэнгүй
PATCH  /api/organizations/:id/estimates/:estId        — Засварлах
DELETE /api/organizations/:id/estimates/:estId        — Устгах
POST   /api/organizations/:id/estimates/:estId/convert  — Ажлын захиалга болгох
```
