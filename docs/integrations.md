# Интеграцууд

TOLOM систем нь гуравдагч этгээдийн үйлчилгээнүүдтэй холбогдох интеграцуудыг санал болгодог.

## Боломжтой интеграцууд

### Smartcar

Автомашины VIN код, марк, загварыг улсын дугаараар автоматаар таних боломж. Smartcar API-г ашиглан:

- Улсын дугаараар VIN код татах
- Марк, загвар, он, төрлийг автоматаар бөглөх
- Үйлчилгээний түүхтэй холбох

### Telegram Bot

Үйлчилгээний сануулга, мэдэгдлийг Telegram мессенжерээр хүлээн авах. Дэлгэрэнгүй мэдээллийг [Telegram Bot](/telegram-bot) хэсгээс үзнэ үү.

### Бусад интеграцууд

Ирээдүйд нэмэгдэх интеграцууд:

- PartsCars — сэлбэгийн каталогийн интеграци
- Цахим гүйлгээний системүүд
- Нягтлан бодох программ хангамж
- SMS мэдэгдэл
- Имэйл маркетингийн системүүд

## Статус

Интеграц бүр дараах статустай байж болно:

| Статус | Тайлбар |
| --- | --- |
| **Live** | Идэвхтэй, ашиглахад бэлэн |
| **Ready** | Бэлэн, удахгүй нээгдэнэ |
| **Building** | Хөгжүүлэлтийн шатанд байна |

## Интеграцын хуудас

Интеграцын хуудас нь `/integrations` хаягаар нээгдэнэ. Энд бүх боломжтой интеграцуудын жагсаалт, статусыг харж, дэлгэрэнгүй мэдээлэл авах боломжтой.
