# Тээврийн хэрэгсэл

Тээврийн хэрэгслийн бүртгэл нь харилцагч бүрийн машин, техникийн мэдээлэл, үйлчилгээний түүхийг хадгална.

## Жагсаалтын хуудас

Vehicles хуудаснаас:

- улсын дугаар эсвэл VIN-аар хайх
- Excel экспорт хийх
- шинэ машин нэмэх
- мөр дээр дарж дэлгэрэнгүй нээх
- машин устгах

боломжтой.

Баруун талын sidebar-д нийт машин, үйлдвэрлэгчийн тоо, хамгийн сүүлд нэмэгдсэн машинууд харагдана.

## Бүртгэх мэдээлэл

Ихэнх бүртгэл дараах талбаруудыг агуулна:

- улсын дугаар
- марк
- загвар
- он
- VIN
- өнгө
- одометр
- эзэмшигч

## Дэлгэрэнгүй харагдац

Машины дэлгэрэнгүйгээс:

- эзэмшигчийн мэдээлэл
- өмнөх ажлын захиалгууд
- одометрийн түүх
- сүүлд ирсэн огноо
- үйлчилгээний сануулгатай холбоотой мэдээлэл

харах боломжтой.

## Холбоосууд

- Машинаас шууд ажлын захиалга руу шилжиж болно
- Үйлчилгээний хуваарь нь [Үйлчилгээний сануулга](/service-reminders) хэсэгтэй холбогдоно
