# TOLOM системтэй танилцах

TOLOM — авто засварын газруудад зориулсан бүрэн удирдлагын систем (ERP). Энэ нь захиалга хүлээн авахаас эхлээд санхүүгийн тайлан гаргах хүртэлх бүх үйл ажиллагааг нэг дор зохицуулна.

::: info Олон байгууллагад зориулсан
TOLOM нь multi-tenant SaaS платформ юм. Та өөрийн байгууллагаа бүртгүүлээд тусгаарлагдсан орчинд ажиллана. Өөр байгууллагын өгөгдөл танд харагдахгүй.
:::

## Системийн үндсэн модулиуд

| Модуль | Үүрэг | Гол боломжууд |
|---------|-------|---------------|
| **Хяналтын самбар** | Өдрийн үйл ажиллагааны тойм | График, сүүлийн үйл ажиллагаа, түргэн товч |
| **Засварын булан** | Ажлын байрны харагдац | Булангийн төлөв, PIN хамгаалалт |
| **Ажлын захиалга** | Засвар үйлчилгээний баримт | 6 төлөв, үйлчилгээ + сэлбэг, төлөвийн түүх |
| **Харилцагчид** | Үйлчлүүлэгчийн мэдээлэл | Хувь хүн / байгууллага, хурдан хайлт |
| **Тээврийн хэрэгсэл** | Автомашины бүртгэл | VIN, дугаар, түүх, эзэмшигчтэй холбох |
| **Бараа материал** | Сэлбэгийн нөөцийн бүртгэл | 38+ сэлбэг, дансны дэвтэр, босго хэмжээ |
| **Ханган нийлүүлэгчид** | Нийлүүлэгчийн мэдээлэл | 8 нийлүүлэгч, холбоо барих мэдээлэл |
| **Худалдан авалт** | Захиалгын удирдлага | 5 төлөв, бараа хүлээн авах, авто нөөц нэмэгдэх |
| **Санхүү** | Орлогын тайлан | Өдөр/7 хоног/сар, 4 валют |
| **Тайлан** | Үзүүлэлтүүд | Техничний гүйцэтгэл, үйлчилгээний ангилал |
| **Тохиргоо** | Системийн тохиргоо | Хэл, валют, PIN |

TOLOM-ийн гол онцлог нь **таблет, ухаалаг утас, компьютер** гэх мэт бүх төхөөрөмжөөс ажиллах боломжтой, хэрэглэхэд хялбар интерфейс юм.

## Хэн ашиглах вэ?

- **Авто засварын газрын эзэд** — бизнесийн бүх үйл ажиллагааг нэг дороос хянах
- **Механикч нар** — захиалга хүлээн авах, гүйцэтгэх, төлөв шинэчлэх
- **Админ ажилтнууд** — харилцагчдын мэдээлэл хөтлөх, тайлан гаргах
- **Нягтлан бодогчид** — санхүүгийн тайлан, орлого зарлагын хяналт
