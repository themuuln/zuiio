# TOLOM системтэй танилцах

TOLOM — авто засварын газруудад зориулсан бүрэн удирдлагын систем (ERP). Энэ нь захиалга хүлээн авахаас эхлээд санхүүгийн тайлан гаргах хүртэлх бүх үйл ажиллагааг нэг дор зохицуулна.

::: info Олон байгууллагад зориулсан
TOLOM нь multi-tenant SaaS платформ юм. Та өөрийн байгууллагаа бүртгүүлээд тусгаарлагдсан орчинд ажиллана. Өөр байгууллагын өгөгдөл танд харагдахгүй.
:::

## Системийн үндсэн модулиуд

| Модуль                           | Үүрэг                         | Гол боломжууд                                                                                                           |
| -------------------------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Хяналтын самбар**              | Өдрийн үйл ажиллагааны тойм   | Орлого, идэвхтэй захиалга, дундаж захиалга, харилцагч, график, өдрийн зорилтот орлого                                   |
| **Засварын булан (Bay View v2)** | Ажлын байрны харагдац         | 3 харагдац (grid/kanban/list), drag-and-drop, PIN хамгаалалт, механикчдын бүртгэл, хүлээгдэж буй дараалал, shift report |
| **Ажлын захиалга**               | Засвар үйлчилгээний баримт    | 6 төлөв, үйлчилгээ + сэлбэг, wizard үүсгэх, төлөвийн түүх, үнийн түүх                                                   |
| **Харилцагчид**                  | Үйлчлүүлэгчийн мэдээлэл       | Хувь хүн / байгууллага, CRM тэмдэглэл, хандсан эх үүсвэр, хурдан хайлт                                                  |
| **Тээврийн хэрэгсэл**            | Автомашины бүртгэл            | VIN, дугаар, түүх, олон эзэмшигчтэй холбох                                                                              |
| **Үйлчилгээний каталог**         | Үйлчилгээ, үнийн жагсаалт     | Үйлчилгээ нэмэх, засах, устгах, ангилал, үнийн түүх, Excel экспорт                                                      |
| **Автомашины загвар**            | Марк, загварын мэдээллийн сан | Үйлдвэрлэгч → загвар → хувилбар, мод хэлбэрийн бүтэц, Excel экспорт                                                     |
| **Бараа материал**               | Сэлбэгийн нөөцийн бүртгэл     | Сэлбэг, дансны дэвтэр (ledger), ханган нийлүүлэгчид, худалдан авалт (PO), босго хэмжээ, Машины сэлбэг (PartsCars)       |
| **Санхүү**                       | Орлого, гүйлгээ, нэхэмжлэх    | 3 таб (тойм, гүйлгээ, нэхэмжлэх), өдөр/7 хоног/сар, 4 валют, Excel экспорт                                              |
| **Тайлан**                       | Үзүүлэлт, тайлан              | Өдөр/7 хоног/сар, EOD тайлан, техничний гүйцэтгэл, үйлчилгээний ангилал, зарлагын үзүүлэлт                              |
| **Зарлага**                      | Зарлагын бүртгэл              | Зарлагын ангилал (10 анхдагч), төлөв (төлсөн/төлөгдөөгүй), шүүлтүүр, Excel экспорт                                      |
| **Үйлчилгээний сануулга**        | Үйлчилгээний хуваарь          | Машины үйлчилгээний хуваарь, сануулга илгээх, синхрончлол, reminder logs, тохиргоо                                      |
| **Тохиргоо**                     | Системийн тохиргоо            | 5 таб (General, Appearance, Commission, Diagnosis Labels, Data & Export)                                                |
| **Харилцагчийн портал**          | Үйлчлүүлэгчийн хуудас         | Захиалга, нэхэмжлэх, машин харах — өөрийн имэйл/нууц үгээр нэвтрэх                                                      |

TOLOM-ийн гол онцлог нь **таблет, ухаалаг утас, компьютер** гэх мэт бүх төхөөрөмжөөс ажиллах боломжтой, хэрэглэхэд хялбар интерфейс юм.

## Хэн ашиглах вэ?

- **Авто засварын газрын эзэд** — бизнесийн бүх үйл ажиллагааг нэг дороос хянах
- **Механикч нар** — захиалга хүлээн авах, гүйцэтгэх, төлөв шинэчлэх, булангийн харагдац
- **Админ ажилтнууд** — харилцагчдын мэдээлэл хөтлөх, тайлан гаргах
- **Нягтлан бодогчид** — санхүүгийн тайлан, орлого зарлагын хяналт
- **Үйлчлүүлэгчид** — өөрийн захиалга, нэхэмжлэхээ порталаас харах
