# TOLOM системтэй танилцах

TOLOM — авто засварын газруудад зориулсан бүрэн удирдлагын систем (ERP). Энэ нь захиалга хүлээн авахаас эхлээд санхүүгийн тайлан гаргах хүртэлх бүх үйл ажиллагааг нэг дор зохицуулна.

::: info Олон байгууллагад зориулсан
TOLOM нь multi-tenant SaaS платформ юм. Та өөрийн байгууллагаа бүртгүүлээд тусгаарлагдсан орчинд ажиллана. Өөр байгууллагын өгөгдөл танд харагдахгүй.
:::

## Системийн үндсэн модулиуд

| Модуль | Үүрэг | Гол боломжууд |
|---------|-------|---------------|
| **Хяналтын самбар** | Өдрийн үйл ажиллагааны тойм | Орлого, идэвхтэй захиалга, дундаж захиалга, харилцагч, график, өдрийн зорилтот орлого |
| **Засварын булан** | Ажлын байрны харагдац | Булангийн төлөв, PIN хамгаалалт, механикчдын бүртгэл, хүлээгдэж буй дараалал |
| **Ажлын захиалга** | Засвар үйлчилгээний баримт | 6 төлөв, үйлчилгээ + сэлбэг, wizard үүсгэх, төлөвийн түүх |
| **Харилцагчид** | Үйлчлүүлэгчийн мэдээлэл | Хувь хүн / байгууллага, хурдан хайлт, дэлгэрэнгүй мэдээлэл |
| **Тээврийн хэрэгсэл** | Автомашины бүртгэл | VIN, дугаар, түүх, эзэмшигчтэй холбох |
| **Үйлчилгээний каталог** | Үйлчилгээ, үнийн жагсаалт | Үйлчилгээ нэмэх, засах, ангилал, үнийн түүх |
| **Автомашины загвар** | Марк, загварын мэдээллийн сан | Үйлдвэрлэгч → загвар → хувилбар, мод хэлбэрийн бүтэц |
| **Бараа материал** | Сэлбэгийн нөөцийн бүртгэл | Сэлбэг, дансны дэвтэр, ханган нийлүүлэгчид, худалдан авалт, босго хэмжээ |
| **Санхүү** | Орлого, гүйлгээ, нэхэмжлэх | 3 таб (тойм, гүйлгээ, нэхэмжлэх), өдөр/7 хоног/сар, 4 валют |
| **Тайлан** | Үзүүлэлт, тайлан | Өдөр/7 хоног/сар, EOD тайлан, техничний гүйцэтгэл, үйлчилгээний ангилал |
| **Зарлага** | Зарлагын бүртгэл | Зарлагын ангилал, төлөв (төлсөн/төлөгдөөгүй), шүүлтүүр, Excel экспорт |
| **Үйлчилгээний сануулга** | Үйлчилгээний хуваарь | Машины үйлчилгээний хуваарь, сануулга илгээх, синхрончлол, тохиргоо |
| **Тохиргоо** | Системийн тохиргоо | Хэл, валют, PIN, татвар, цагийн бүс, SMS/QPay, дүрс (theme), сануулгын суваг |

TOLOM-ийн гол онцлог нь **таблет, ухаалаг утас, компьютер** гэх мэт бүх төхөөрөмжөөс ажиллах боломжтой, хэрэглэхэд хялбар интерфейс юм. CRM-ийн сайжруулалтууд (харилцагчийн тэмдэглэл, хандалтын эх үүсвэр) нь харилцагчийн харилцааны бүрэн түүхийг хөтлөх боломжийг олгоно.

## Хэн ашиглах вэ?

- **Авто засварын газрын эзэд** — бизнесийн бүх үйл ажиллагааг нэг дороос хянах
- **Механикч нар** — захиалга хүлээн авах, гүйцэтгэх, төлөв шинэчлэх
- **Админ ажилтнууд** — харилцагчдын мэдээлэл хөтлөх, тайлан гаргах
- **Нягтлан бодогчид** — санхүүгийн тайлан, орлого зарлагын хяналт
