# Өдрийн хаалт (EOD Close)

Өдрийн хаалт нь ажлын өдрийн эцэст орлого, төлбөр, гүйцэтгэлийн хураангуйг нэг дороос харуулж, өдрийн хаалтыг бүртгэх боломж олгоно.

## Үндсэн хэсгүүд

### Статистик картууд

Хуудасны дээд хэсэгт дараах KPI картууд байрлана:

| Карт | Тайлбар |
| --- | --- |
| **Ажиллагдсан захиалга** | Өнөөдөр гүйцэтгэсэн ажлын захиалгын тоо |
| **Орлого** | Өнөөдрийн нийт орлого |
| **Нээлттэй захиалга** | Дуусаагүй үлдсэн захиалгын тоо |
| **Тохируулаагүй нэхэмжлэх** | Төлөгдөөгүй нэхэмжлэхийн тоо ба дүн |

### Төлбөрийн задаргаа

Өнөөдрийн төлбөрийг төрлөөр нь харуулна:

- **Бэлэн** (cash)
- **Карт** (card)
- **Банкны шилжүүлэг** (bank transfer)
- **Бусад** (other)

### Шилдэг механик

Өнөөдөр хамгийн их орлого олсон механикийн нэр, орлого, гүйцэтгэсэн захиалгын тоог харуулна.

### Хамгийн удаан нээлттэй захиалга

Одоогоор дуусаагүй захиалгуудаас хамгийн удаан хугацаанд нээлттэй байгаа захиалгын мэдээлэл (захиалга ID, харилцагч, нээгдсэн хоног) харуулна.

### Бага нөөцтэй сэлбэгүүд

Нөөц багатай сэлбэгийн жагсаалтыг Inventory хэсэг рүү холбоосоор харуулна.

## Өдөр хаах

Хаах товч дээр дарснаар тухайн өдрийн хаалтын түүхэнд бүртгэгдэнэ:

1. **"Өдөр хаах"** товч дарна уу.
2. Систем өдрийн тооцоог баталгаажуулна.
3. Амжилттай хаагдсан бол тасралтгүй хаалтын тоо (streak) нэмэгдэнэ.
4. Өдөр хаагдсаны дараа өдрийн тайланг хэвлэх боломжтой.

## Тайлан хэвлэх

Хуудасны баруун дээд хэсгийн **"Print Report"** товчоор өдрийн тайланг хэвлэгч рүү илгээнэ.
