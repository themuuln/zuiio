# Харилцагчид

Харилцагчдын хэсэг нь таны бүх үйлчлүүлэгчдийн мэдээллийн сан юм.

## Харилцагчийн төрлүүд

| Төрөл | Тайлбар | Жишээ |
|-------|---------|-------|
| **Хувь хүн** | Бие даасан үйлчлүүлэгч | Бат Цэнгэл, Сарангэрэл Ганбаатар |
| **Байгууллага** | Компани, байгууллагын флот | Монголын Төмөр Зам, Найрамдал Такси |

## Харилцагч бүртгэх

1. **"Харилцагчид"** хэсэгт орж **"Шинэ харилцагч"** товч дарна.
2. **Төрөл** сонгох: Хувь хүн эсвэл Байгууллага.
3. **Мэдээлэл бөглөх**:
   - Нэр (хувь хүн бол овог нэр, байгууллага бол байгууллагын нэр)
   - Утасны дугаар
   - Имэйл хаяг
   - Хаяг
4. **"Хадгалах"** товч дарна.

::: tip Хурдан хайлт
Утасны дугаараар хайх нь хамгийн хурдан арга. Хайлтын талбарт дугаарын хэдэн орон ч бичихэд тохирох харилцагчид гарч ирнэ.
:::

## Харилцагчийн дэлгэрэнгүй

Харилцагчийн картанд дараах мэдээлэл харагдана:

- **Үндсэн мэдээлэл** — нэр, утас, имэйл, хаяг
- **Хандсан эх үүсвэр (Source)** — харилцагч хаанаас ирсэн (referral, website, walk-in, social_media, phone, other)
- **Статистик** — нийт айлчлалын тоо, нийт зарцуулсан мөнгө
- **Машинууд** — харилцагчийн бүртгэлтэй тээврийн хэрэгслүүд
- **Захиалгын түүх** — өмнөх захиалгуудын жагсаалт
- **Тэмдэглэл** — харилцагчийн тэмдэглэл, сануулга, түүх

## Харилцагч засах, устгах

- **Засах**: Харилцагчийн мөр дээрх засах товч дээр дарж мэдээллийг шинэчилнэ.
- **Устгах**: Харилцагчийг устгахад зөөлөн устгалт (soft-delete) хийгдэх бөгөөд өгөгдөл мэдээллийн санд үлдэх боловч жагсаалтад харагдахгүй.

## Харилцагчийн тэмдэглэл (CRM)

Харилцагчийн дэлгэрэнгүй хуудаснаас тэмдэглэл нэмэх, харах боломжтой. Энэ нь харилцагчийн түүх, сануулга, холбогдсон мэдээллийг нэг дороос хөтлөх боломжийг олгоно.

### Тэмдэглэлийн төрлүүд

| Төрөл | Тайлбар |
|-------|---------|
| **General** | Ерөнхий тэмдэглэл |
| **Follow Up** | Дараа холбогдох сануулга |
| **Complaint** | Гомдол, санал |
| **Call** | Утасны ярианы тэмдэглэл |
| **Email** | И-мэйл харилцаа |
| **Meeting** | Уулзалтын тэмдэглэл |
| **Other** | Бусад |

### Шинэ тэмдэглэл нэмэх

1. Харилцагчийн дэлгэрэнгүй хуудаснаас **Тэмдэглэл** хэсэгт орно.
2. **"Тэмдэглэл нэмэх"** товч дарна.
3. Агуулга бичиж, төрөл сонгоно.
4. **"Хадгалах"** товч дарна.

### Хандалтын эх үүсвэр (Source)

Харилцагч бүртгэх үед хаанаас ирсэн эх үүсвэрийг тэмдэглэх боломжтой:

| Эх үүсвэр | Тайлбар |
|-----------|---------|
| **Referral** | Санал болголт / найзаар |
| **Website** | Вэб сайтаар |
| **Walk-in** | Өөрөөр ирсэн |
| **Social Media** | Сошиал медиа |
| **Phone** | Утсаар |
| **Other** | Бусад |

Энэ нь таны маркетингийн аль суваг хамгийн үр дүнтэй болохыг тодорхойлоход тусална.

### Аудитын тэмдэглэл

Бүх тэмдэглэл нь хэн, хэзээ үүсгэсэн, хэн, хэзээ зассан гэсэн мэдээлэлтэй байх бөгөөд устгахад зөөлөн устгалт (soft-delete) хийгдэнэ.
