# @zuiio/gateway-facebook

Facebook Messenger + Instagram channel plugin for the agent-gateway middleware.

## Exports

| Export | Type | Description |
|---|---|---|
| `FacebookChannel` | class | Channel adapter implementing `Channel` from `@zuiio/gateway-core` |

## Dependencies

- `@zuiio/gateway-core` — for `Channel` types
- `@zuiio/capture` — for error tracking

## Env vars

- `NEXT_PUBLIC_FACEBOOK_APP_ID`
- `FB_APP_SECRET`
- `FB_VERIFY_TOKEN`
