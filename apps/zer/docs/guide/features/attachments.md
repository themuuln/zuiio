# Файл хавсаргах

Нэхэмжлэх, зарлага, худалдан авалтад баримтын зураг/файл хавсаргах.

**Яагаад хэрэгтэй вэ:** Баримтын цахим хувилбар хадгалах, татварын шалгалтад бэлэн байх.

## Хэрэгжүүлэх тэмдэглэл

- `attachments` хүснэгт (entity_type, entity_id, file_url, file_name, uploaded_by)
- Supabase Storage bucket (аль хэдийн тохируулагдсан)
- File upload component — бүх create/edit формд нэмэх
