# Цалин / Хүний нөөц

Ажилтны бүртгэл, Нийгмийн даатгал, орлогын албан татвар автомат тооцоо.

**Яагаад хэрэгтэй вэ:** Монголд цалингийн тооцоо нь НДШ, ОАТ, ЭМД-ын нарийн дүрэмтэй — гараар тооцоход алдаа их гардаг.

## Хэрэгжүүлэх тэмдэглэл

- `employees` хүснэгт (цалин, албан тушаал, элссэн огноо)
- Нийгмийн даатгалын хувь хэмжээ (2026 онд: НДШ 10.5%, ЭМД 2.5%, ОАТ 10%)
- Цалингийн хуудас хэвлэх
- Сар бүр цалингийн бүртгэл
