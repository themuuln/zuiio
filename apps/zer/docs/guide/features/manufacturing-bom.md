# Үйлдвэрлэл / BOM

Материалын тодорхойлолт (Bill of Materials), үйлдвэрлэлийн даалгавар, барааны зарцуулалтын логик.

**Яагаад хэрэгтэй вэ:** Үйлдвэрлэл эрхэлдэг жижиг бизнесүүд (гурилан бүтээгдэхүүн, гэр ахуйн эдлэл, хүнсний үйлдвэр) өртөг тооцоогоо хөтлөх.

## Хэрэгжүүлэх тэмдэглэл

- `bill_of_materials` хүснэгт (finished_product_id, raw_material_id, quantity)
- `work_orders` хүснэгт (start_date, status, planned_quantity, actual_quantity)
- Материал зарцуулалтын автомат inventory deduction
- Үйлдвэрлэлийн өртөг тооцоо (материал + хөдөлмөр + нэмэгдэл)
