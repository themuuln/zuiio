# Шимтгэл

Ажилтны борлуулалтын шимтгэлийг бүртгэх, тооцоолох, төлөх.

```mermaid
flowchart LR
    A[Шимтгэл] --> B[Борлуулалт]
    B --> C[Шимтгэлийн тооцоо]
    C --> D[Төлөх шимтгэл]
    D --> E[Түүх]
```

## Шимтгэлийн тооцоо

Шимтгэлийг борлуулагч тус бүрээр автоматаар тооцоолно:

- Борлуулалтын дүнгээс хамаарч шимтгэлийн хувь тогтоох
- Шимтгэлийн түүх хөтлөх
- Төлөлтийн бүртгэл

## Шимтгэл бүртгэх

1. `Шимтгэл` цэснээс шимтгэлийн жагсаалт харах.
2. Борлуулагч бүрийн шимтгэлийн дэлгэрэнгүй мэдээлэл харах.
3. Төлөлт хийгдсэн шимтгэлийг тэмдэглэх.
