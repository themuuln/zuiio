# Санхүүгийн бүртгэл

Давхар бүртгэлийн (double-entry) систем дээр суурилсан санхүүгийн бүртгэл.

```mermaid
flowchart LR
    A[Санхүүгийн бүртгэл] --> B[Дансны төлөвлөгөө]
    A --> C[Журналын бичилт]
    B --> D[Хөрөнгө]
    B --> E[Өр төлбөр]
    B --> F[Өмч]
    B --> G[Орлого]
    B --> H[Зарлага]
```

## Дансны төлөвлөгөө (Chart of Accounts)

Дансны төлөвлөгөөнд дараах төрлийн дансуудыг үүсгэх боломжтой:

- **Хөрөнгө** (Active) — бэлэн мөнгө, банк, бараа материал гэх мэт
- **Өр төлбөр** (Passive) — зээл, өглөг
- **Өмч** (Capital) — дүрмийн сан, ашгийн хуримтлал
- **Орлого** (Income) — борлуулалтын орлого
- **Зарлага** (Expense) — үйл ажиллагааны зарлага

## Журналын бичилт (Journal Entries)

Санхүүгийн гүйлгээг журналын бичилтээр бүртгэнэ. Бичилт бүр дебет, кредит мөрүүдээс бүрдэнэ.

### Автомат бичилтүүд

Дараах үйлдлүүд автоматаар журналын бичилт үүсгэдэг:

- Борлуулалтын баримт
- Худалдан авалт
- Зарлага
- Буцаалт
