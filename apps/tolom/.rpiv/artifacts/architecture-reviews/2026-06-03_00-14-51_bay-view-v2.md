# Architecture review — Bay View v2

Bay View v2 is TOLOM's visual garage floor — a tablet-first, drag-and-drop interface for managing service bays, mechanics, and work orders in real time. It replaces the legacy v1 (flat list) with a spatial Kanban/grid view using `@dnd-kit`, live timers, and a rich work-order detail drawer. The review was triggered as a post-major-refactor audit: the module has grown to 38 files (including 2 test files) across page, component, and service directories.

## Conventions

### Finding shape

Each finding is a level-3 heading `### L<layer>-<seq> — <title>` followed by the fields below.

| Field | Meaning |
|---|---|
| **Evidence** | `file.ext:lineA-lineB` (+ short quote when useful) |
| **Current state** | what the code does today |
| **Desired state** | what we want it to look like |
| **Proposed improvement** | concrete action (rename, extract, merge, split, delete) |
| **Severity** | Low / Med / High — how wrong this is today |
| **Effort** | S / M / L — bounded changes ship cheaply |
| **Blast radius** | `internal` / `public-API` / `on-disk` / `cross-module` |
| **Class** | `polish` (rename / refactor / DRY) vs `redesign` (structural shift) |
| **Status** | `open` / `accepted` / `rejected` / `deferred` / `withdrawn` |
| **Depends on** | other finding IDs that must land first |
| **Cross-cut tag** | optional — see "Cross-cutting themes" |

### Status legend

- `open` — flagged, not yet triaged
- `accepted` — will land; includes the chosen option summary
- `rejected` — declined with reason inline
- `deferred` — accepted in principle but punted post-release
- `withdrawn` — initial diagnosis turned out incorrect; kept for audit

## Layer 0 — Entry Point

**Files:** `page.tsx`

### L0-01 — Dual entry points

**Evidence**

`bay-view/page.tsx:8-10` and `bay-view-v2/page.tsx:8-10` (both dynamically import `BayViewV2Client` with different wrapper margins).

```ts
// bay-view/page.tsx:8
const BayViewV2Client = dynamic(() => import("@/components/bay-view-v2/bay-view-v2-client")...) const BayViewV2Client

// bay-view-v2/page.tsx:8  
const BayViewV2Client = dynamic(() => import("@/components/bay-view-v2/bay-view-v2-client")...)
```

**Current state**

Two route directories (`/bay-view` and `/bay-view-v2`) import the same `BayViewV2Client` component. Navigation only links to `/bay-view`. The v2 route page (`bay-view-v2/page.tsx`) exists but has no navigation or external references pointing to it.

**Desired state**

Single canonical route — remove the vestigial v2 entry point.

**Proposed improvement**

Delete `bay-view-v2/page.tsx` and the empty `bay-view-v2/` directory.

- **Severity:** Low
- **Effort:** S
- **Blast radius:** `internal`
- **Class:** `polish`
- **Status:** **accepted** — deleted `bay-view-v2/page.tsx` + directory; cleaned up nav item, locale keys, and breadcrumb mapping from `use-navigation.ts`, `use-breadcrumbs.ts`, `mn.json`, and `en.json`.
- **Depends on:** none
- **Cross-cut tag:** —

### L0-02 — Missing error.tsx in v2 route

**Evidence**

`bay-view/error.tsx` exists (33 lines, Mongolian error UI + reset button), `bay-view-v2/` has none.

**Current state**

v1 route has a dedicated error boundary; v2 route doesn't — errors bubble to dashboard-level `error.tsx`.

**Desired state**

Consistent error handling.

**Proposed improvement**

Copy `error.tsx` from v1 to v2.

- **Severity:** Low
- **Effort:** S
- **Blast radius:** `internal`
- **Class:** `polish`
- **Status:** **withdrawn** — rendered moot by L0-01 deletion of the v2 route entirely.
- **Depends on:** L0-01
- **Cross-cut tag:** —

### L0-03 — Loading skeleton mismatch

**Evidence**

`bay-view/page.tsx:14-28` uses `mx-3 tablet:mx-4 lg:mx-6` skeleton outer wrapper; `bay-view-v2/page.tsx:14-26` uses `p-4`.

**Current state**

Two routes' loading skeletons look different despite rendering the same `BayViewV2Client` component.

**Desired state**

Consistent loading appearance.

**Proposed improvement**

Sync skeleton padding/margin classes between both routes.

- **Severity:** Low
- **Effort:** S
- **Blast radius:** `internal`
- **Class:** `polish`
- **Status:** **withdrawn** — rendered moot by L0-01 deletion of the v2 route entirely. The surviving v1 skeleton is the sole loading state.
- **Depends on:** L0-01
- **Cross-cut tag:** —
