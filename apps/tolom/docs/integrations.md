# Интеграцууд

TOLOM систем нь та аль хэдийн ашиглахдаа түгээмэл хэрэгслүүдтэй холбогдох боломжийг олгоно. Төлбөрийн системээс эхлээд нягтлан бодох программ хангамж хүртэл — бид танд хэрэгтэй бүхийг хангана.

## Хаяг

Интеграцын хуудас нь `/integrations` хаягаар нээгдэнэ.

## Дэлгэрэнгүй тодорхойлолт

### 1. Төлбөрийн боловсруулалт (Live)

Банкны шилжүүлэг, кредит карт, бэлэн мөнгө зэрэг бүх төлбөрийн төрлийг нэг дороос хянах боломжтой.

### 2. Имэйл мэдэгдэл (Live)

Нэхэмжлэх, сануулга, тайланг автоматаар харилцагч болон ажилтнуудад имэйлээр илгээнэ.

### 3. Excel/CSV экспорт (Live)

Санхүүгийн өгөгдөл, зарлага, үйлчилгээний каталогийг Excel болон CSV форматаар экспортлох боломжтой.

### 4. Telegram & Чатбот (Planned)

Telegram, WhatsApp, Messenger-ээр үйлчилгээний автоматаар сануулга илгээх. Дэлгэрэнгүйг [Telegram Bot](/telegram-bot) хэсгээс үзнэ үү.

### 5. REST API (Ready)

Бүрэн REST API интерфейс. Өөрийн апп, вэбсайт, системүүдийг TOLOM-тэй холбох боломжтой. Business төлөвлөгөөнд багтсан.

### 6. Нягтлан бодох (Planned)

Санхүүгийн өгөгдлийг нягтлан бодох программ хангамж руу автоматаар экспортлох.

### 7. Messenger / WhatsApp (Planned)

Харилцагчидтай Messenger болон WhatsApp-аар сануулга болон харилцаа хийх.

### 8. Сэлбэгийн зах зээл (Planned)

Ханган нийлүүлэгчдийн каталогтой холбогдож, сэлбэгийн үнэ болон нөөцийг бодит цагт харах.

## Захиалга

::: tip Захиалга
Хэрэв танд хэрэгтэй интеграц байхгүй бол эсвэл захиалгатай интеграц хэрэгтэй бол бидэнтэй холбогдоно уу. Бид таны бизнесийн хэрэгцээнд тохирсон шийдлийг санал болгоно.
:::
