# Тайлан

![Тайлан](/images/reports.png)

Тайлангийн хэсэг нь орлого, ашигт ажиллагаа, механикчийн гүйцэтгэл, үйлчилгээний бүтэц, retention зэрэг бизнесийн үзүүлэлтүүдийг нэг дор харуулна.

## Тайлангийн төрлүүд

| Төрөл | Дүрс | Огнооны сонголт | Тайлбар |
| --- | --- | --- | --- |
| **Daily** | 📅 | DatePicker (нэг өдөр) | Өдрийн гүйцэтгэл |
| **Weekly** | 📊 | DatePicker (7 хоногийн эхлэх өдөр) | 7 хоногийн тайлан |
| **Monthly** | 📈 | MonthPicker (сар + жил) | Сарын тайлан |
| **Custom** | 📅 | DateRangePicker (эхлэх/дуусах) | Өөрийн сонгосон огнооны хүрээ |
| **EOD** | 📋 | DatePicker (нэг өдөр) | End-of-day механикчийн хаалтын тайлан |

## Шүүлтүүрүүд

Тайлангийн хуудаснаас дараах шүүлтүүрүүдийг ашиглавал зүгээр:

### Салбар ба механикчийн уялдаа

- **Салбар** шүүлтүүр дээр **Бүх салбар** эсвэл тодорхой нэг салбарыг сонгож болно (олон салбартай бол)
- Нэг л салбартай байгууллага бол салбарын шүүлтүүр харагдахгүй
- Салбар солих үед механикчийн жагсаалт тухайн салбарын ажилтнуудаар шинэчлэгдэнэ
- Өмнө сонгосон механикч шинэ салбарт байхгүй бол механикчийн шүүлтүүр автоматаар цэвэрлэгдэнэ

### Refresh товч

Refresh товч нь үндсэн тайлангаас гадна insights, forecast, target, retention, PnL, service breakdown зэрэг бүх дагалдах картуудыг хамт шинэчилнэ.

### Tab navigation ба accessibility

- Тайлангийн төрлүүдийн товчнууд нь keyboard-оор удирдагдах tablist болсон
- Идэвхтэй tab нь screen reader-д `selected` төлөвтэй уншигдана
- Tab солиход тухайн panel нь холбогдсон `tabpanel` байдлаар харагдана
- Refresh дүрс болон туслах дүрснүүд нь decorative тул screen reader-д давхар уншигдахгүй

## Үндсэн KPI үзүүлэлтүүд (Daily / Weekly / Monthly / Custom)

Тайлангийн дээд хэсэгт дараах картууд ээлжлэн харагдана. Бүр **өмнөх хугацаатай харьцуулалт (delta)** харуулна:

### 1-р эгнээ

| Карт | Тайлбар |
| --- | --- |
| **Work Orders** | Дуусгасан ажлын захиалгын тоо + өмнөхтэй харьцуулалт (%) + дундаж захиалгын дүн |
| **Services Sold** | Борлуулсан үйлчилгээний тоо + харьцуулалт (%) + захиалга бүрт дундаж |
| **Revenue** | Нийт орлого + харьцуулалт (%) + өмнөх хугацааны орлого |
| **Expenses** | Зарлага (холбосон бол) — одоогоор "Connect expense data" зөвлөмжтэй |

### 2-р эгнээ (Profitability)

| Карт | Тайлбар |
| --- | --- |
| **Gross Profit** | Цэвэр ашиг (хоёрдугаар өнгөтэй: ногоон/улаан) |
| **Margin** | Ашгийн хувь |
| **Effective Labor Rate** | Дундаж цалингийн хүү (WO бүрт) |
| **Parts to Labor Ratio** | Сэлбэг / Цалин харьцаа (%) |

## Гол анализууд

Тайлан дотор дараах анализууд байна:

### Insight Alerts

Системийн анхаарах ажиглалтууд — тухайн хугацааны онцлог үзүүлэлтүүдийг жижиг картуудаар харуулна.

### Forecast Card

Ойрын төсөөлөл — ирээдүйн орлогын таамаглал.

- Projected орлого, өдөр тутмын хурд, одоогийн гүйцэтгэл харуулна
- Өмнөх хугацаатай харьцуулж хуваарийн дагуу явж байгаа эсэхийг харуулна
- Мэдээлэлгүй үед хоосон үлдэхгүй, тайлбартай empty state үзүүлнэ

### Target Card

Зорилтот гүйцэтгэл — тодорхойлсон зорилтод хүрсэн эсэхийг харуулна.

- Зорилт байхгүй үед `Орлогын зорилт тохируулаагүй байна` төлөв гарна
- Зорилт байгаа үед actual vs target, биелэлтийн хувь, progress bar харуулна

### Revenue Split (Pie Chart)

Үйлчилгээ ба сэлбэгийн орлогын бүтцийг **donut pie chart**-аар харуулна:
- Цэнхэр — Services (хувь болон мөнгөн дүн)
- Ногоон — Parts (хувь болон мөнгөн дүн)
- Tooltip-д дэлгэрэнгүй мэдээлэл харагдана

### Profit Breakdown

Орлого, өртөг, ашгийн дэлгэрэнгүй задаргаа:

| Мөр | Тайлбар |
|-----|---------|
| Service Revenue | Үйлчилгээний орлого |
| Service Cost | Үйлчилгээний өртөг (улаан өнгөөр) |
| Parts Revenue | Сэлбэгийн орлого |
| Parts Cost | Сэлбэгийн өртөг (улаан өнгөөр) |
| **Gross Profit** | **Цэвэр ашиг (нийт)** (ногоон/улаан) |

### Daily Revenue Chart

- **Weekly тайлан**: 7 хоногийн өдөр бүрийн орлогыг харуулна (Даваа → Ням)
- **Monthly тайлан**: Сарын 7 хоног бүрийн орлогыг харуулна
- Хэрэв тухайн хугацаанд мэдээлэл байхгүй бол график алга болохын оронд `Энэ хугацаанд мэдээлэл алга` төлөв харагдана

### Mechanic Bar Chart

Механикчдын гүйцэтгэлийг баганаар харуулна (захиалга сонгосон бол харуулахгүй).

- Мэдээлэлгүй үед chart нуухгүй, empty state харуулна

### Service Breakdown Chart

Үйлчилгээний бүтцийн дэлгэрэнгүй тайлан — аль үйлчилгээ хамгийн их эрэлттэй байгааг харуулна.

- Мэдээлэлгүй үед chart нуухгүй, empty state харуулна

### Retention Card

Давтан үйлчлүүлэгчийн үзүүлэлт — харилцагчдын эргэн ирэлтийг хянах.

- Retention, returning, new customer, average visit, lifetime value харуулна
- Top customers жагсаалт нь орлогын дүнтэй хамт харагдана
- Мэдээлэлгүй үед empty state харуулна

### PnL Card

Profit and Loss тойм — орлого, зарлага, ашгийн ерөнхий байдлыг харуулна.

- Revenue, COGS, gross margin, expenses, net profit мөрөөр задалж харуулна
- Мэдээлэлгүй үед empty state харуулна

## MechanicTable

Механикчдын дэлгэрэнгүй хүснэгт:

| Багана | Тайлбар |
| --- | --- |
| **Mechanic** | Механикчийн нэр |
| **Jobs** | Дуусгасан ажлын тоо |
| **Services** | Хийсэн үйлчилгээний тоо |
| **Parts** | Ашигласан сэлбэгийн тоо |
| **Revenue** | Нийт орлого |
| **Avg per WO** | Захиалга бүрийн дундаж орлого |
| **Δ** | Өмнөх хугацаатай харьцуулалт |

- Хүснэгтийг **Excel** файл болгон экспортлох боломжтой
- Харьцуулалтын багана нь өмнөх хугацааны өсөлт/бууралтыг харуулна

## EOD тайлан

EOD харагдац нь тухайн өдрийн хаалтын тайлан бөгөөд тусдаа KPI картууд болон хүснэгттэй:

### EOD KPI картууд

| Карт | Тайлбар |
| --- | --- |
| **Total Revenue** | Нийт орлого + механикчдын тоо |
| **Total Work Orders** | Нийт дуусгасан захиалга + захиалга бүрийн дундаж орлого |
| **Commission** | Нийт комисс + захиалга бүрийн дундаж комисс |
| **Шилдэг механикч** | Хамгийн их орлого авсан механикчийн нэр + орлого + ажлын тоо |

### EOD механикчийн хүснэгт

| Багана | Тайлбар |
| --- | --- |
| **Mechanic** | Механикчийн нэр (шилдэг бол 🏆 дүрс) |
| **Jobs** | Дуусгасан ажлын тоо |
| **Services** | Хийсэн үйлчилгээний тоо |
| **Parts** | Ашигласан сэлбэгийн тоо |
| **Revenue** | Нийт орлого |
| **Commission** | Нийт комисс (ногоон өнгөөр) |

- Хүснэгтийн **нийт мөр** — бүх механикчдын нийлбэр
- Шилдэг механикчийн мөр **амбер өнгийн фон**-той
- Хүснэгтийг **Excel** файл болгон экспортлох боломжтой

## Экспорт

Reports хэсгээс механикчийн хүснэгт болон EOD breakdown зэрэг гол хүснэгтүүдийг Excel файл болгон татаж авч болно.

## Баруун sidebar

Тайлангийн хуудас дээр баруун талын sidebar дээр:
- **Help**: Тайлангийн төрлүүдийн (daily, weekly, monthly, EOD) товч тайлбар
- **Recent**: Сүүлийг үзсэн тайлангууд

## Хугацааны гарчиг

Тайлангийн гарчиг нь төрлөөс хамаарч автоматаар тохируулагдана:

| Төрөл | Жишээ гарчиг |
| --- | --- |
| **Daily** | Пүрэв гараг, Зургаадугаар сарын 5, 2026 |
| **Weekly** | 6-р сарын 2, 2026 |
| **Monthly** | Зургаадугаар сар 2026 |
| **Custom** | 6-р сарын 2 – 6-р сарын 8, 2026 |

::: tip Зөвлөмж
Тайлангийн өгөгдлийг шинэчлэхийн тулд **Refresh** товчийг дарна уу. Энэ нь бүх картуудыг (insights, forecast, target, retention, PnL, service breakdown) хамт шинэчилнэ. Механикчийн шүүлтүүр нь зөвхөн нэг механикчийн гүйцэтгэлийг харахад тохиромжтой — бүх механикчдыг харахын тулд шүүлтүүрийг цэвэрлээрэй.
:::

::: info Харьцуулалт (Delta)
Тайлангийн KPI картууд нь өмнөх хугацаатай (жишээ нь: өчигдрийн өнөөдөртөй, өмнөх сарын энэ сартай) харьцуулалтыг харуулдаг. Энэ нь бизнесийн чиг хандлагыг хурдан үнэлэхэд тусална. Харьцуулалтыг өсөлт (ногоон) эсвэл бууралт (улаан) гэж харуулна.
:::

## НӨАТ Тайлан (Tax Report)

НӨАТ тайлан нь Татварын ерөнхий газарт илгээх Нэмэгдсэн Өртөгт Татварын тайланг гаргахад зориулагдсан.

### Хүрээ

| Төлөв | Тайлбар |
|-------|--------|
| **НӨАТ-тэй борлуулалт** | Нийт нэхэмжлэхийн дүн + НӨАТ цуглурсан дүн |
| **НӨАТ-тэй худалдан авалт** | Нийт зардлын дүн + НӨАТ төлсөн дүн |
| **НӨАТ-н цэвэр төлбөр** | Цуглурсан - Төлсөн = Татварын ерөнхий газарт төлөх дүн |

### Хэрхэн ашиглах

1. **Reports → Tax Report** хэсэгт орох
2. **Эхлэх огноо**, **Дуусах огноо**-гоо сонгох
3. **Тайлан гаргах** товчийг дарах
4. НӨАТ-тэй борлуулалт, худалдан авалтын жагсаалт харах
5. **CSV** татаж авч болно

### Тайлангийн агуулга

| Багана | Тайлбар |
|--------|--------|
| **Төрөл** | Борлуулалт (Sale) эсвэл Худалдан авалт (Purchase) |
| **Огноо** | Нэхэмжлэхийн огноо |
| **Нэр дугаар** | Нэхэмжлэлийн дугаар |
| **Тайлбар** | Нэхэмжлэлийн нэр/тайлбар |
| **Дүн** | НӨАТ-тэй нийт дүн |
| **НӨАТ** | НӨАТ-н дүн |

::: tip Зөвлөмж
НӨАТ-ийн тайлангийг сар бүр гаргаж, Татварын ерөнхий газарт илгээх нь зүйтэй. CSV файлаар экспортлоод нягтлан бодогчдоо өгнө.
:::
