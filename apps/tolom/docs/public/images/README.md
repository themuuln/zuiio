## Regenerating

```bash
# Make sure the dev server is running on port 3000
pnpm dev

# In another terminal:
pnpm docs:screenshots           # Mongolian (default)
pnpm docs:screenshots:en        # English

# Capture specific pages only:
node scripts/screenshots/capture.mjs --only dashboard,work-orders

# Custom viewport:
node scripts/screenshots/capture.mjs --width 1280 --height 800
```
