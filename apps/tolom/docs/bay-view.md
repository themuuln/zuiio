# Засварын булан (Bay View)

![Засварын булан](/images/bay-view.png)

Засварын булан (Bay View) нь таны цехийн булангуудын бодит харагдацыг харуулна. Эндээс аль буланд ямар захиалга хийгдэж байгааг нэг дороос харж болно.

## Ерөнхий зохион байгуулалт

Bay View нь дараах үндсэн хэсгүүдээс бүрдэнэ:

```
┌─────────────────────────────────────────────────┐
│  Toolbar (хяналтын самбар)                       │
│  ├─ View mode  │ Branch │ Search │ Bay count    │
│  ├─ My Jobs    │ Refresh│ Register buttons      │
├─────────────────────────────────────────────────┤
│  KPI Cards (үзүүлэлтийн картууд)                 │
│  ├─ Bay Utilization │ Active Jobs               │
│  ├─ Completed Today │ Revenue Today             │
├─────────────────────────────────────────────────┤
│  View Content (Grid / Kanban / List)             │
│  ├─ Bay cards / columns / table rows            │
│  └─ Work order details                          │
├─────────────────────────────────────────────────┤
│  Sidebar: Queue Panel + Mechanic Panel           │
└─────────────────────────────────────────────────┘
```

## Булангийн 3 харагдац

| Харагдац | Дүрс | Тайлбар |
| --- | --- | --- |
| **Grid** (анхдагч) | GridIcon | Булангуудыг grid байдлаар харуулна |
| **Kanban** | KanbanIcon | Төлөвөөр нь багана болгон харуулна. Queue-г зүүн талд харуулна |
| **List** | ListIcon | Хүснэгт хэлбэрээр харуулна |

## Хяналтын самбар (Toolbar)

Дээд хэсэгт байрлах хяналтын самбар:

| Элемент | Тайлбар |
| --- | --- |
| **View mode** | Grid / Kanban / List сонголт |
| **Branch filter** | Салбар сонгох дропдаун (All эсвэл тодорхой салбар) |
| **Search** | Булангууд дотор хайх (дугаар, марк, загвар, харилцагч, механикч, төлөв) |
| **Bay count** | Засварын булангийн тоо (тоо оруулж өөрчлөх боломжтой) |
| **My Jobs** | Зөвхөн өөрийн ажлуудыг харуулах (механикчид) |
| **Refresh** | Өгөгдлийг шинэчлэх |
| **Register Vehicle** | Шинэ тээврийн хэрэгсэл бүртгэх |
| **Register Mechanic** | Шинэ механикч бүртгэх |
| **Shift Report** | Шифтийн тайлан харах |
| **PIN Settings** | PIN тохиргоо |

## KPI картууд

Хяналтын самбарын доор дараах үзүүлэлтийн картууд харагдана:

| Карт | Тайлбар |
| --- | --- |
| **Bay Utilization** | Ашиглагдаж буй булангийн хувь |
| **Active Jobs** | Идэвхтэй ажлын тоо |
| **Completed Today** | Өнөөдөр дууссан захиалгын тоо |
| **Revenue Today** | Өнөөдрийн орлого (₮) |

- Картууд **trend delta** (өмнөх шинэчлэлттэй харьцуулсан өөрчлөлт) харуулна

## Булангийн төлөв, өнгө

| Төлөв | Тайлбар |
| --- | --- |
| **Чөлөөтэй** | Буланд захиалга байхгүй, шинэ захиалга авахад бэлэн |
| **Захиалгатай** | Буланд гүйцэтгэгдэж буй захиалга байна |
| **Хүлээгдэж буй** | Дараалалд хүлээгдэж буй захиалгууд |

## Drag-and-Drop

Bay View нь **drag-and-drop** дэмждэг:

- **Машин/захиалгыг** нэг буланаас нөгөө рүү чирэх боломжтой
- **Механикчийг** захиалгад томилох боломжтой
- Хүрэх цэгтэй утга утгаар идэвхжүүлэх (8px хязгаар)
- Mobile дээр **300ms** хүлээлттэй touch sensor ажиллана
- Газардах үед зургийн preview гарна

## Булангуудын хяналт

### Булангийн тоо өөрчлөх

- **Bay count** талбарт шинэ тоог оруулж болно
- Өөрчлөлт шууд хэрэгжиж, булангуудын тоо шинэчлэгдэнэ
- Spinner гарч ирэх үед өөрчлөлт боловсруулж байна

### Булангуудыг хайх

- **Search** талбарт дугаар, марк, загвар, харилцагч, механикчийн нэрээр хайж болно
- Fuzzy search ашиглана (0.4 threshold)

## Захиалгын төлөвийн шилжилт

Булангийн карт дээрх төлөвийн dropdown-оос шинэ төлөв сонгох боломжтой:

| Төлөв | Дараагийн төлөв |
| --- | --- |
| **New** | Diagnosing |
| **Diagnosing** | In Progress |
| **In Progress** | Ready for Pickup |
| **Ready for Pickup** | Completed |
| Бүх идэвхтэй төлөв | Cancelled |

::: tip Completed төлөвийн онцлог
"Completed" төлөвт шилжүүлэхэд **PickupCompleteDialog** нээгдэж, харилцагчийн сэтгэл ханамж, санал, дараагийн цагийг бүртгэнэ. Дараа нь статус шинэчлэгдэнэ.
:::

## Булангуудын бүтэц

Нэг булангийн картад дараах мэдээлэл байна:

- Булangiйн дугаар
- Захиалгын төлөв (badge)
- Машины дугаар
- Механикийн нэр
- Захиалгын дүн
- Төлөвийн dropdown
- Зүүн талын өнгөн бар (төлөвийн өнгө)
- Дүрс (status icon, аниматай)

## Хүлээгдэж буй захиалгууд (Queue)

Хэрэв бүх булан завгүй байвал шинэ захиалгуудыг **Queue Panel**-д харуулна.

Queue-д:

- Зашиалгын жагсаалт
- **Quick Assign** товч — хоосон буланд шууд томилох
- Булан сонгох dropdown — аль буланд томилох
- Механикч сонгох — механикчийг томилох
- Дэлгэрэнгүй харах — WorkOrderDetailDrawer нээгдэнэ

## Механикчдын самбар (Mechanic Panel)

Sidebar-ын **Mechanic** табт:

- Механикч бүрийн нэр
- Томилогдсон захиалгын тоо
- Төлөв (идэвхтэй/чөлөөтэй)

## Ажлын захиалгын дэлгэрэнгүй (WorkOrderDetailDrawer)

Булангийн карт дээр дарахад баруун талаас Drawer нээгдэнэ:

- Захиалгийн дэлгэрэнгүй мэдээлэл
- **Add Service** — үйлчилгээ нэмэх
- **Add Part** — сэлбэг нэмэх
- Тэмдэглэл нэмэх
- URL-д `?woId=...` параметр нэмэгдэнэ

## Шифтийн тайлан (Shift Report)

**Shift Report** товчоор нээх цонх:

- Өнөөдрийн хураангуй үзүүлэлтүүд
- Булангийн ашиглалт
- Гүйцэтгэсэн захиалга
- Орлого

## Төхөөрөмж болон механикч бүртгэх

### Төхөөрөмж бүртгэх

- **Register Vehicle** товчоор шинэ тээврийн хэрэгсэл бүртгэнэ
- Бүртгэсний дараа Queue-д нэмэгдэнэ

### Механикч бүртгэх

- **Register Mechanic** товчоор шинэ механикч бүртгэнэ
- Имэйл, нэр, утасны дугаар оруулна
- Бүртгэсний дараа жагсаалтад нэмэгдэнэ

## Batch Complete

Бүх "Ready for Pickup" төлөвтэй захиалгуудыг нэгэн зэрэг дуусгах боломжтой:

1. **Batch Complete** товч дарна
2. Баталгаажуулалтын цонх гарна (хэдэн захиалга дуусгахыг харуулна)
3. **Confirm** дарна
4. Бүх захиалгыг "Completed" төлөвт шилжүүлнэ

## Post-Service мэдээлэл

Захиалгыг "Ready for Pickup" болгох үед **PostServiceDialog** нээгдэнэ:

| Талбар | Тайлбар |
| --- | --- |
| **Одометр (км)** | Машины одометрийн заалт |
| **Зөвлөмжүүд** | Механикийн зөвлөмжүүд |
| **Тэмдэглэл** | Механикийн нэмэлт тэмдэглэл |

## Хүлээлгэхэд бэлэн (Pickup Complete)

Захиалгыг "Completed" болгох үед **PickupCompleteDialog** нээгдэнэ:

| Талбар | Тайлбар |
| --- | --- |
| **Сэтгэл ханамж** | 1-5 одны үнэлгээ |
| **Санал хүсэлт** | Харилцагчийн нэмэлт санал |
| **Дараагийн цаг** | Дараагийн үзлэгийн огноо (заавал биш) |

## PIN хамгаалалт

Засварын буланг PIN кодоор хамгаалах боломжтой. Энэ нь зөвшөөрөлгүй хандалтаас сэргийлнэ.

1. **PIN Settings** товч дээр дарна
2. 4-6 оронтой PIN оруулна
3. Хадгална

## Автомат шинэчлэлт

Bay View нь **30 секунд тутамд** автоматаар шинэчлэгдэнэ. ДIALOG нээлттэй үед автоматаар зогсоно.

## Sidebar (Баруун талын хэсэг)

| Таб | Дүрс | Агуулга |
| --- | --- | --- |
| **Queue** | List | Хүлээгдэж буй захиалгуудын жагсаалт |
| **Mechanics** | Users | Механикчдын жагсаалт, тэдгээрийн ажлын төлөв |

## Зөвлөмж

::: tip PIN кодоо хамгаалах
PIN кодоо хэнд ч бүү хэлээрэй. PIN кодыг тогтмол сольж байхыг зөвлөж байна.
:::

::: tip Хугацааг шинэчлэх
Төлөвийг тогтмол шинэчилж байх нь багийн бусад гишүүдэд мэдээлэлтэй байхад тусалдаг. Ялангуяа "In Progress" болон "Ready for Pickup" төлөвүүдийг цаг тухайд нь шинэчлэх нь чухал.
:::

::: tip Бүх булан завгүй бол
Хэрэв бүх булан ажилтай байвал Queue Panel-д хүлээгдэж буй захиалгуудыг харж, булан сулрах үед шилжүүлнэ үү.
:::
