# Тамга бүртгэл (Horse Stamp Registration)

> Малын тамга нь Монгол хуулиар заавал байх ёстой малын таних тэмдэг. Tamga нь энэ процессийг дижиталжуулж, тамганы зургийг цахим паспортад хадгална.

---

## Юу вэ? (What)

**Тамга** гэдэг нь адуундаа тавьдаг таних тэмдэг — эзэмшлийн баталгаа, удмын шугам, нэр төрийн илэрхийлэл. Монгол Улсын **Малын тухай хууль**-иар мал бүр тамгатай байх ёстой.

| Зүйл | Тайлбар |
|---|---|
| **Хуулийн шаардлага** | Мал бүр тамгатай байх (Малын тухай хууль) |
| **Бүртгэлийн газар** | Харьяа аймаг, сумын Засаг даргын Тамгын газар / Мал эмнэлгийн хэлтэс |
| **Бүртгэлийн зардал** | Харьяа нутгаас хамаарч өөр — ихэвчлэн үнэгүй эсвэл бага төлбөртэй |
| **Тамганы хэлбэр** | Төрөл бүрийн хэлбэртэй (дугай, буга, мод, зүйлийн хэлбэр г.м) |
| **Нэмэлт** | Тамганы зургийг дижитал болгож Tamga-д хадгална |

---

## Яагаад чухал вэ? (Why It Matters)

| Шалтгаан | Тайлбар |
|---|---|
| **Хуулийн шаардлага** | Тамгагүй малыг хуулиар хүлээн зөвшөөрдөггүй |
| **Хулгайгаас сэргийлэх** | Тамга нь малын өвөрмөц тэмдэг — хулгайчийг барихад тусална |
| **Зах зээлийн итгэлцэл** | Тамгатай мал нь худалдан авагчид итгэл төрүүлнэ |
| **Удам судрын баталгаа** | Тамга нь удмын шугамын нэг хэсэг |
| **Даатгалын нөхцөл** | Зарим даатгалын компани тамганы бүртгэл шаарддаг |

---

## Албан ёсны бүртгэлийн дараалал (Government Registration Steps)

### 1. Тамгаа сонгох

| Хүчин зүйл | Зөвлөмж |
|---|---|
| **Энгийн байх** | Хэт нарийн хэлбэр нь тамглахад хэцүү |
| **Өвөрмөц байх** | Бусад малчдын тамгатай төстэй байх ёсгүй |
| **Хуулийн хязгаар** | Зарим хэлбэр нутгийн засаг даргын зөвшөөрөл шаарддаг |
| **Ойлгомжтой** | Тамганы зураг тодорхой байх |

### 2. Харьяа нутгийн Засаг даргын тамгын газарт хандих

| Алхам | Юу хийх вэ |
|---|---|
| **1** | Харьяа сум/аймгийн Засаг даргын Тамгын газар (эсвэл Мал эмнэлгийн хэлтэс) рүү явах |
| **2** | Тамганы хэлбэрээ үзүүлэх (зураг эсвэл загвар) |
| **3** | Малын тоо, төрөл, байршлыг мэдүүлэх |
| **4** | Бүртгүүлэх хүсэлт бичих |
| **5** | Бүртгэлийн гэрчилгээ авах |

### 3. Тамглах

| Арга | Тайлбар |
|---|---|
| **Галдан тамглах** | Уламжлалт арга — модон дээр тамгаа хийж адуундаа тамглах |
| **Тэмдэглэх** | Зарим нутгийн засаг даргын тамгаар тэмдэглэдэг |

### 4. Бүртгэлийн баримт хадгалах

| Баримт | Хаана хадгалах вэ |
|---|---|
| Бүртгэлийн гэрчилгээ | Бие махбод + Tamga-д сканнерлэх |
| Тамганы зураг | Tamga-н дижитал паспортад |
| Бүртгэлийн дугаар | Tamga-н морины мэдээлэлд |

---

## Tamga-н дижитал тамга бүртгэл (Digital Stamp in Tamga)

Tamga апп нь тамганы албан ёсны бүртгэлийг **дижиталжуулж**, дараах боломжуудыг олгоно:

### Бүртгэх үйлдэл

| Алхам | Хэрэглэгчийн үйлдэл |
|---|---|
| **1** | Морины профайл нээх → "Тамга" хэсэг рүү орох |
| **2** | Тамганы зургийг камераар авах (тод, ойроос) |
| **3** | Бүртгэлийн дугаар оруулах (хэрэв байвал) |
| **4** | Бүртгэлийн огноо, бүртгэсэн газрыг сонгох |
| **5** | Хадгалах |

### Хадгалагдах мэдээлэл

| Талбар | Тайлбар |
|---|---|
| **Тамганы зураг** | JPEG/PNG — камераар авсан эсвэл галерейгаас |
| **Бүртгэлийн дугаар** | Харьяа нутгийн бүртгэлийн дугаар |
| **Бүртгэсэн газар** | Аймаг, сум |
| **Бүртгэсэн огноо** | Хэзээ бүртгүүлсэн |
| **Баталгаат эсэх** | Админаар шалгагдсан эсэх |

### Давуу тал

| Давуу тал | Тайлбар |
|---|---|
| **Оффлайн хадгалалт** | Тамганы зураг утсан дээрээ хадгална — интернэтгүй үед ч харна |
| **Хурдан хайх** | Тамганы хэлбэрээр морь хайх боломжтой |
| **Худалдааны итгэлцэл** | Зах зээл дээр зар тавихдаа тамганы зураг харуулах |
| **Хулгайгаас сэргийлэх** | Алга болсон морийг тамгаар нь хайх боломж |
| **Дижитал архив** | Бүх тамганы зураг нэг дор — бие махбодын баримт алдсан ч дижитал хувь байна |

---

## Зах зээлтэй холбох (Marketplace Connection)

Тамганы бүртгэл нь зах зээлийн итгэлцлийн нэг хэсэг:

| Холбоо | Тайлбар |
|---|---|
| **Зарын итгэлцэл** | Тамганы зурагтай зар нь тамгагүй зарыг бодвол илүү итгэлтэй |
| **Эзэмшлийн баталгаа** | Тамга + дижитал гэрчилгээ = эзэмшлийн баталгаа |
| **Худалдааны шимтгэл** | Тамга бүртгэлтэй морийг Tamga-аар шилжүүлэхэд баталгаатай |
| **Хайлтын шүүлтүүр** | Тамганы хэлбэрээр шүүж хайх боломж |

---

## Хэрэглэгчийн аялал (User Journey)

```
Албан ёсны тамга бүртгүүлэх
        ↓
Тамганы зураг авах (камераар)
        ↓
Tamga-д тамгаа бүртгүүлэх
        ↓
Морины дижитал паспортад тамга нэмэгдэнэ
        ↓
Зах зээлд зар тавихдаа тамгаа харуулах
        ↓
Худалдан авагч тамгыг харж итгэлтэй худалдан авна
```

---

## Алдааны мэдээлэл (Error Handling)

| Асуудал | Шийдэл |
|---|---|
| Тамганы зураг тод биш | "Зураг тод биш — дахин авна уу" сануулга |
| Бүртгэлийн дугаар оруулаагүй | Зөвлөмж: "Бүртгэлийн дугаар оруулвал илүү итгэлтэй" |
| Тамга давхардсан | Бусад морины тамгатай төстэй эсэхийг шалгах (ирээдүй) |
| Бүртгэлийн баримт алдсан | Tamga-д хадгалсан тамганы зураг нь нэмэлт нотолгоо болно |

---

## Дэмжигдэх үе шатууд (Phased Rollout)

| Үе шат | Функц | Төлөв |
|---|---|---|
| **Phase 1** | Тамганы зураг камераар авах, хадгалах | ✅ Бүртгэх UI байна |
| **Phase 2** | Тамганы хэлбэрээр хайх | ⏳ Төлөвлөгдсөн |
| **Phase 3** | Тамгыг зах зээлийн итгэлцлийн нэг хэсэг болгох | ⏳ Төлөвлөгдсөн |
| **Phase 4** | Хуурамч тамга илрүүлэх (зургийн анализ) | ⏳ Ирээдүй |
