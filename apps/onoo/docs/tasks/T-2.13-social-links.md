## Goal

Add social media link fields (Instagram, Facebook, Twitter/X, YouTube, TikTok, Website) to player, team, competition, and organization profiles — both admin editing and public display.

## Why

Leagues and teams want to showcase their social media presence on their profiles. This is a common request for athlete and team pages, improving discoverability and engagement.

## Design Decisions

- **JSONB storage**: `{}` with keys like `instagram`, `facebook`, `twitter`, `youtube`, `tiktok`, `website` — flexible without schema changes
- **Admin form pattern**: Teams/competitions use `useEntityCrud`; org uses custom `useForm`/`useMutation` + RPC
- **Public display**: Pill badges with platform icons — same pattern reused in HeroCard and TeamHeader
- **RPC update**: Dropped old 8-param overload, created 9-param version with `p_social_links` to avoid ambiguous GRANT/REVOKE

## Risks & Gotchas

- Remote Supabase `season_player_stats` has no `ftp` column → view migration needed manual fix on remote
- `DROP VIEW ... CASCADE` fails when called in same transaction on remote — needed sequential drops
