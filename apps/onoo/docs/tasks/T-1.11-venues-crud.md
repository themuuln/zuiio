## Goal

Admin CRUD for basketball venues (name, address, city, hours).

## Why

Games need venues assigned. This is a supporting admin page for game management.

## Implementation Steps

1. Add venues table to Supabase schema (included in foundational migrations)
2. Create admin page at `/admin/venues` with `useEntityCrud` pattern
3. API routes for create/update/delete via `createEntityApi`
4. Form fields: name, address, city, hours, is_active
