## Goal

League/team sites can iframe a game or player widget.

## Why

Team sites, league partner pages, and basketball news outlets can embed live game cards and player profiles — extending Onoo's reach beyond its own domain without requiring those sites to build their own widgets.

## Implementation Steps

1. **Audit CSP headers:** Check `next.config.ts` and `vercel.json` for any `X-Frame-Options: DENY` or global `frame-ancestors` CSP that would block embedding. Report if found — don't change without understanding the impact.

2. **Embed layout:** Create `src/app/embed/layout.tsx`:
   - No site navigation, no footer
   - Transparent-friendly background (use `bg-transparent` not `bg-background`)
   - Minimal padding
   - No SEO metadata (noindex by default)

3. **Game embed** (`embed/game/[id]/page.tsx`):
   - Reuses `GameCard` component from Task 3.1
   - Fully server-rendered, zero client JS
   - Footer link: "onoo.mn ↗" (`target="_blank"`)
   - Generate minimal metadata with `noindex`

4. **Player embed** (`embed/player/[id]/page.tsx`):
   - Mini hero: `PlayerAvatar`, name, 3 stat averages (PPG / RPG / APG)
   - Fully server-rendered, zero client JS
   - Footer link: "onoo.mn ↗"
   - Generate minimal metadata with `noindex`

5. **CSP hole:** In `next.config.ts`, add a `headers()` entry setting `Content-Security-Policy: frame-ancestors *` specifically for `/embed/:path*`. Confirm no global framing header exists.

6. **Documentation:** Create `docs/embeds.md` with:
   - iframe code snippet (width/height recommendations: 400×300 for game, 300×400 for player)
   - Supported parameters
   - Example usage

## Design Decisions

- Embed layout is completely minimal — no navigation, no footer except a small attribution link.
- Server-rendered only — zero client JS means instant render and minimal bandwidth for the embedding site.
- Transparent-friendly background lets the embed blend into the host site's design.
- CSP header is scoped to `/embed/*` only — doesn't weaken security for the main app.

## Risks & Gotchas

- CSP `frame-ancestors *` allows any site to embed. This is intentional for embeds but must NOT apply to non-embed routes. Use Next.js `headers()` with a path matcher: `source: '/embed/:path*'`.
- If `vercel.json` has a global `headers` entry for `X-Frame-Options: DENY`, it takes precedence over `next.config.ts`. Check and remove the global header or add an exception.
- Embedded pages must be discoverable for embed users but not indexed by search engines — add `noindex` to metadata.
