## Goal

Players download a game-line or award image to post themselves.

## Why

Players are the league's best promoters. Giving them a polished stat card they can download and post to their own social feeds creates organic reach — every shared game line or award is a branded endorsement.

## Implementation Steps

1. **OG route** `src/app/api/og/player-card/route.tsx`:
   - Accept query params: `playerId`, `gameId?`, `awardId?`
   - Return `ImageResponse` at 1080×1350 (feed portrait aspect ratio)
   - **Game mode** (playerId + gameId): player photo, one-liner from `describePlayerGame`, full stat line (PTS/REB/AST/STL/BLK/TOV/FG%/FT%), opponent + date
   - **Award mode** (playerId + awardId): award badge layout from `v_public_awards`
   - **Sponsor strip**: if T-4.5 has landed, render sponsor logo from `v_public_sponsor_slots` where slot = 'award_card' or 'recap' at the bottom strip. Otherwise, leave a `<!-- SPONSOR SLOT — filled by Task 4.5 -->` placeholder region.
   - Reuse `src/lib/og/theme.ts` from T-4.1 for fonts, colors, styling

2. **`ShareCardButton` component:** Create `share-card-button.tsx`:
   - Fetches the OG route as a blob
   - Triggers download via `a[download]` element
   - On Web Share API support (`navigator.canShare` with files), offer native share instead
   - Label: "Зураг татах" (Download image)
   - Loading state while the image generates
   - Error state with retry if generation fails

3. **Mount points:**
   - Player page hero area (downloads current season's stat card)
   - Player page awards shelf (per-award download)
   - Game page box-score rows (per-player game stat card)

## Design Decisions

- 1080×1350 portrait (3:4) is the standard Instagram/Facebook feed aspect ratio — optimized for social posting.
- Game mode vs award mode uses separate rendering paths in the same route, selected by which optional params are present.
- Web Share API with files is checked via `navigator.canShare` for native sharing; fallback to download for desktop browsers.
- Sponsor strip is a clearly marked placeholder if T-4.5 hasn't landed — easy to fill later without changing the card layout.

## Risks & Gotchas

- `ImageResponse` runs server-side. The fetch from the client is a regular HTTP request to an API route — ensure CORS isn't blocked (in dev, Next.js doesn't block same-origin).
- The font files (Noto Sans) must be available for OG generation — reuse the `load-fonts.ts` from T-4.1.
- Some browsers don't support `navigator.canShare` with files. The `a[download]` fallback works everywhere.
- Large image generation may be slow (~500ms). Show a loading spinner to avoid user confusion.
- Web Share API on iOS Safari requires HTTPS (except localhost). Local dev testing should work on localhost.
