## Goal

Generate Instagram-ready stat graphics for any player performance — best game, season averages, career highs. One-click download or share via native web share API. Uses Satori + @vercel/og for server-side rendering.

## Why

Athletes sharing their stats on Instagram/Facebook = free marketing for Onoo. Every share reaches teammates, rivals, scouts, and families. "Look at my 28-point game" card is the most viral thing we can produce.

## Implementation Steps

1. Install `@vercel/og` (or `satori` + `@resvg/resvg-js`)
2. Create OG API route at `/api/og/player/[playerId]`:
   - Fetch player stats + game data
   - Render a beautiful card: player name, photo/placeholder, stat line, team logo, "Оноо" branding
   - Support two modes: "season averages" and "single game"
3. Create `ShareCard` client component:
   - Button: "Хуваалцах" or "Татах"
   - On click: fetch OG image URL, then use `navigator.share()` or download link
   - Show preview of the card in a small modal/dialog
4. Wire into player page hero area and game recap top performers
5. Handle empty/missing photos gracefully (use existing placeholder)

## Design Decisions

- Use `@vercel/og` (satori-based) for server-side rendering — same pattern as existing OG images
- Card layout: top = player name + team + photo, middle = big stat numbers, bottom = "Оноо — Монголын сагсан бөмбөг"
- Two share modes: "best game this season" and "season averages" and "career highs"

## Risks & Gotchas

- `@vercel/og` uses Satori which has limited CSS support — no flexbox gap, limited text wrapping
- Font loading: need to bundle or fetch Mongolian font
- Image generation timeout on Edge Functions (max 10s for OG)
