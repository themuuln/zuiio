## Goal

Generate a downloadable season report PDF with champion, runners-up, statistical leaders, all-team final standings, and key season facts. One-click export from the league admin dashboard or standings page.

## Why

League operators currently compile season reports in Word/Excel for federation reporting and press releases. An auto-generated PDF saves hours and makes the league look professional.

## Implementation Steps

1. Create API route `/api/reports/season/[competitionId]`:
   - Fetch standings, leaders, game results for the competition
   - Render as a server-side page (using existing OG/Satori approach or a dedicated route)
   - Or use a simpler approach: create a print-optimized HTML page and let browser print-to-PDF handle it
2. Two approaches (pick simplest):
   - **Approach A**: Satori-based image-to-PDF (if @vercel/og already used)
   - **Approach B**: Create a `/reports/season/[id]` HTML page with `@media print` CSS, users right-click → Print → Save as PDF → simpler but manual
   - **Approach C**: Use `puppeteer` or a PDF library on server — complex
3. Start with Approach B (HTML + print CSS), which is simplest:
   - Create a printable season report page
   - Content: competition header, standings table, top 5 leaders per category, champion callout, season summary stats
4. Add "Улирлын тайлан" button on standings page that opens the printable report
