## Goal

Redesign the app color palette to use a near-black background (`oklch(0.02 0.002 60)`) with orange (`oklch(0.72 0.22 40)`) and purple accent colors, replacing the previous light default theme.

## Why

The dark background creates a more powerful, immersive feel suitable for a sports stats platform. Orange/purple accents provide strong brand identity and visual contrast.

## Implementation Steps

1. Set `--background` to near-black in `globals.css`
2. Set `--primary` to orange (`oklch(0.72 0.22 40)`)
3. Set `--accent` to orange at various opacities
4. Add sidebar theming with dark purple-tinted background
5. Ensure `.dark` class overrides cascade properly with CSS variable indirection
6. Verify contrast and readability across components
