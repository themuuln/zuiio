## Goal

Admin CRUD for basketball seasons (name, start/end date, league).

## Why

Competitions are organized by season. This is a supporting admin page for competition management.

## Implementation Steps

1. Add seasons table to Supabase schema (included in foundational migrations)
2. Create admin page at `/admin/seasons` with `useEntityCrud` pattern
3. API routes for create/update/delete via `createEntityApi`
4. Form fields: name, league_id, starts_on, ends_on
