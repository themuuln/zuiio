## Goal

Enhance the existing tournament page into a full FIBA-style hub with group stage standings tables, knockout bracket, classification bracket (9-12th, 13-16th places), per-phase leaders, and game cards grouped by round.

## Why

Tournament hub makes any Mongolian league look world-class. League owners show this to federation and sponsors. The scaffold exists (tournament route + basic bracket) but lacks group stage, classification, and the FIBA-level polish that impresses.

## Implementation Steps

1. Add data helpers:
   - `getTournamentPhases(id)` → phases with round info
   - `getTournamentGroups(id)` → groups with teams and standings
   - `getGamesByPhase(tournamentId, phaseId)` → games for a phase
2. Rework tournament page layout:
   - **Header**: Tournament name, logo, dates, status badge
   - **Group Phase** (if applicable): Group A, Group B tables with W/L/PTS, team names
   - **Knockout Bracket**: Enhanced bracket with team logos, scores, advancement lines
   - **Classification**: 9-12th, 13-16th bracket if applicable
   - **Phase Leaders**: Top scorers, rebounders for this tournament
   - **Game List**: All games grouped by round/phase
3. Reuse existing `GameCard` component for game listing
4. Group standings table: similar to standings page but per-group
5. Classification bracket: smaller bracket below main bracket
