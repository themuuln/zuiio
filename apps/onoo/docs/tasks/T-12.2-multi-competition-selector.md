## Goal

Add a dropdown selector to switch between competitions/seasons on the home page, standings page, and leaders page. Enables browsing different leagues (U18, Open, Women's) and historical seasons.

## Why

Leagues running multiple competitions (U18 + Open + Women's) need to navigate between them. Currently all pages show only the current/default competition. A selector makes Onoo feel like a real multi-league platform.

## Data Dependencies

| Entity | Access | Purpose |
|--------|--------|---------|
| `competitions` or `seasons` table | Read only | List of available competitions |
| `v_public_standings` | Read only | Filtered by competition_id |
| `v_public_leaders` | Read only | Filtered by competition_id |

## Implementation Steps

1. Add `getCompetitions()` to data.ts that returns all competitions with id, name, season, is_current flag
2. Create `CompetitionSelector` client component using shadcn Select
   - Props: `competitions`, `currentId`, `onChange`, `label`
3. On home page: convert data fetching to accept optional competition_id, pass to selector
4. On standings page: wrap in client component with competition state, re-fetch on change
5. On leaders page: same pattern as standings
6. Persist selection in URL search params (?competition_id=xxx) for shareable URLs
