## Goal

Embed YouTube/Facebook Live stream on game detail pages alongside live stats. League operators provide a stream URL; the page auto-detects live status and shows "Шууд үзэх" button + embedded player.

## Why

Watching a game AND seeing live stats on the same page is a game-changer for fan experience. Makes Mongolian leagues look professional.

## Files to Touch

```
- src/app/games/[id]/components/live-stream.tsx    — NEW: YouTube/Facebook embed component
- src/app/games/[id]/page.tsx                      — Wire live stream into game layout
- src/app/games/[id]/components/recap-header.tsx   — Add "Шууд үзэх" button area
- src/app/admin/api/games/route.ts                 — Add stream_url field to game admin
- src/app/admin/games/[id]/page.tsx                — Add stream URL input to game edit form
```

## Data Dependencies

| Entity | Access | Purpose |
|--------|--------|---------|
| `games` table | Read only | Add `stream_url` column (nullable text) |
| `games` table | Write (admin) | League admin sets stream URL |

## Implementation Steps

1. Add migration: `ALTER TABLE games ADD COLUMN stream_url text`
2. Create `LiveStream` component:
   - If `stream_url` is set, detect YouTube vs Facebook vs generic embed
   - YouTube: use `<iframe>` with youtube.com/embed/{id}
   - Facebook: use facebook.com/plugins/video.php
   - Generic: use `<video>` with src or generic iframe
   - Show "🔴 Шууд үзэх" badge when game status is "live_provisional"
   - Responsive: 16:9 aspect ratio container, full width on mobile
3. Add stream URL field to admin game edit form
4. Add stream URL to `v_public_games` view or include in game data query
5. On game page, render LiveStream alongside live stats when stream_url is set

## Risks & Gotchas

- Facebook and YouTube have different embed URL formats. Handle both with URL parsing.
- Stream URL is provided by league — no validation beyond URL format.
- Need to handle case where stream is not live yet (show placeholder/scheduled state).
