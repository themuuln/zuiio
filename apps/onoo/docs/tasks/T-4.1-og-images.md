## Goal

Links pasted into Messenger/Facebook render branded stat cards.

## Why

Every share of a player, game, or team page on social media should deliver a visual stat card — not a generic URL preview. Branded OG images drive click-through and make the league look professional in Messenger and Facebook feeds where Mongolian basketball fans gather.

## Implementation Steps

1. **Font setup:** Create `src/lib/og/load-fonts.ts`:
   - Read NotoSans-Bold.ttf and NotoSans-Regular.ttf using `fs.readFile` (`import fs from 'node:fs'`)
   - Files come from `src/assets/fonts/` — if they don't exist, stop with clear instructions
   - Export `{ bold: ..., regular: ... }` for `ImageResponse` `fonts` option

2. **Theme config:** Create `src/lib/og/theme.ts` with shared colors, spacing, and font configs for OG images.

3. **Player OG card** (`players/[id]/opengraph-image.tsx`):
   - 1200×630px, dark background
   - Team-color accent bar (vertical stripe on left)
   - Player photo on left (fetched via `photo_url`), placeholder initials block if null
   - Name, team label
   - Three big stat numbers with Mongolian captions: PPG / RPG / APG
   - "onoo.mn" wordmark bottom-right
   - Appropriate `alt` text, `contentType: 'image/png'`

4. **Game OG card** (`games/[id]/opengraph-image.tsx`):
   - Both team logos + short_codes
   - Final score (large, centered)
   - Status chip: "Баталгаажсан" for `league_verified|official`
   - Date
   - "onoo.mn" wordmark

5. **Team OG card** (`teams/[slug]/opengraph-image.tsx`):
   - Team logo, name
   - W–L record
   - Top scorer line (name + PPG)

6. **Metadata audit:** For each page (player, game, team), verify `generateMetadata` doesn't set `openGraph.images`. If it does, remove the hardcoded image entries (file-convention wins only if metadata doesn't set images explicitly). Add a comment noting the OG image convention.

## Design Decisions

- `ImageResponse` from `next/og` is built into Next.js 16 — no new dependencies.
- Cyrillic rendering requires bundled Noto Sans fonts. Font files go in `src/assets/fonts/` and are loaded via `fs.readFile` at build/request time (Next.js OG handles this).
- Team-color accent bar uses the team's `primary_color` from the database — same as the standings accent (T-3.2).
- Dark background makes stat numbers pop visually on Messenger/Facebook feeds.
- Three stats per player card: PPG, RPG, APG — the most universally understood basketball stats.

## Risks & Gotchas

- Font files must be present. If `src/assets/fonts/` doesn't exist or fonts are missing, the OG image generation will error or use a fallback font that doesn't render Cyrillic. The task should check for font presence early.
- `photo_url` may be null or broken. Always have a fallback (initials on dark circle) that looks intentional.
- `opengraph-image.tsx` files run in a server-side Node.js environment — no client APIs, no `window`, no `document`.
- `generateMetadata` on existing pages may already set `openGraph.images`. If so, the file-convention is ignored and must be removed from metadata.
- OG images are cached aggressively by Vercel's Edge and Facebook's crawler. Changes may not appear immediately after deploy.
