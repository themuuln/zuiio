## Goal

Create a head-to-head matchup page showing historical results between two teams: who leads the series, per-game scores as a trend chart, recent meetings, and stat comparison.

## Why

Rivalries drive engagement. Team owners want to show "we beat them 5-3 all time." Fans share matchup pages before big games. This is a missing classic sports site feature.

## Files to Touch

## Data Dependencies

| Entity | Access | Purpose |
|--------|--------|---------|
| `games` + team IDs | Read only | All games between two teams |
| `v_public_games` | Read only | Game results with scores |
| `v_public_team_roster` | Read only | Current rosters |

## Implementation Steps

1. Add `getHeadToHead(teamAId, teamBId)` to data.ts:
   - Query `v_public_games` where (home_team_id, away_team_id) in either order
   - Return: games list with scores, total meetings, each team's wins
2. Create team matchup page at `/teams/vs/[teamA]/[teamB]`:
   - Series record: "Багахангай 5–3 Хангарид"
   - Score trend line chart (scores over time, two lines)
   - Recent meetings list with result cards
   - Season-by-season breakdown
   - Link to current standings comparison
3. Add "Өрсөлдөгчид" section to team page showing last 5 results vs each opponent
4. Add head-to-head quick link on game detail page
