## Goal

Add two interactive enhancements to the player season arc chart:
1. **Recharts Brush** — drag-select a date range to recalculate stats for selected games
2. **Play Animation** — "Тоглуулах" button that animates the chart drawing point by point

## Why

The season arc chart exists but is static. Athletes want to explore their own data ("how did I do in February?") and watch their season unfold as a story. The Brush is a 100-line change using built-in recharts; the animation is a small state machine loop.

## Files to Touch

```
- src/app/players/[id]/components/season-arc.tsx  — Add Brush + animation + summary badges
- src/app/components/ui/chart.tsx                  — May need to expose recharts Brush if not already
```

## Implementation Steps

1. Add `<Brush>` from recharts below the x-axis (built-in, zero deps)
   - `dataKey="game_date"`, `height={30}`, `stroke`: theme color
2. On brush change, filter the data array to selected range
3. Recalculate averages for selected range → show as badges above chart
4. Add "Тоглуулах" button
   - On click, start a `setInterval`/`requestAnimationFrame` that increments a `visibleCount` state from 1 to data.length
   - Chart renders only up to `visibleCount` points
   - Button label toggles to "Түр зогсоох" (Pause)
   - On animation end, button shows "Дахин тоглуулах" (Replay)
5. Clean up interval on unmount

## Design Decisions

- Use `useState` + `useEffect` for animation, not framer-motion (convention: no animation library)
- Brush is recharts built-in `<Brush>` component
- Speed: ~500ms per point (adjustable), total animation < 30s for typical season
