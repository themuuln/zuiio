## Goal

Last-5 games as horizontally scrollable capsules showing opponent (team logo + name), W/L result, standout stat, and date. Each card links to the game page.

## Why

The recent games strip answers "how has this player been playing lately?" without opening multiple game pages. The horizontal scroll pattern is mobile-friendly and widely familiar from sports apps.

## Implementation Steps

1. **Data**: `getPlayerGameLog` returns all game lines sorted by date. The `RecentGames` component calls `.slice(-5).reverse()` to get the newest-first last 5.
2. **`getStandoutStat` heuristic**: picks the best stat from each game using a weighted heuristic — raw `pts` vs `reb × 1.2` vs `ast × 1.5`. The weights surface all-around performances (a 15-point, 12-rebound game shows "12 самбар" instead of "15 оноо"). Documented in a code comment.
3. **Game summary**: `generatePlayerGameSummary()` (wraps `describePlayerGame` from core) produces one-liner for each card subtitle — e.g., "Карьерийн дээд амжилт: 35 оноо" or "15 оноо, 8 самбар, 6 дамжуулалт".
4. **`RecentGames` Server Component**: horizontal `flex` row with `snap-x snap-mandatory overflow-x-auto`. Each capsule: opponent `TeamLogo` + `short_code`, W/L chip (green bg for W, red for L), standout stat line, date formatted in `Asia/Ulaanbaatar` timezone, summary as subtitle, `Link` to `games/[id]`.
5. **Empty state**: if `gameLines` is empty, show a centered message "Тоглолтын мэдээлэл байхгүй" with dashed border.
6. **Desktop layout**: on `lg` breakpoint, switch from horizontal scroll to CSS grid (5 columns, no scroll).

## Design Decisions

- **Server Component**: `RecentGames` doesn't need client interactivity (scroll is native HTML + CSS). Avoiding `"use client"` saves bundle size.
- **Weighted standout stat heuristic**: `reb × 1.2` and `ast × 1.5` — the weights are arbitrary but calibrated: they ensure a 10-rebound game beats a 12-point game, and a 10-assist game beats both. This surfaces playmaking and rebounding performances, not just scoring.
- **Snap scroll**: `snap-x snap-mandatory` with `scroll-snap-align: start` on each card — standard mobile card-rail pattern.
- **CSS Grid on desktop**: at `lg`, the strip converts to a 5-column grid — this avoids the awkward "partially visible cards" look on wide screens.
- **`TeamLogo` reuse**: opponent identity reuses the existing component from T-2.1, ensuring consistency.

## Risks & Gotchas

- **Overflow scroll on desktop**: the default horizontal scroll shows scrollbar on desktop even when using grid. The `lg:overflow-visible lg:grid` class overrides correctly.
- **Date formatting**: game dates must be formatted in `Asia/Ulaanbaatar` timezone using `date-fns-tz` `formatInTimeZone`. Using local timezone would show wrong dates for users in other timezones.
- **Capsule width**: each capsule needs a `min-w-[160px]` or `w-48` on mobile to be readable — too narrow and the content wraps. Too wide and you see <2 cards at a time.
- **W/L chip contrast**: green (#22c55e) and red (#ef4444) must have sufficient contrast against card background. Use filled variant with white text.
