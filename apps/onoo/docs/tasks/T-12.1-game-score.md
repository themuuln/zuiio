## Goal

Add NBA-style Game Score (efficiency rating) to every player's game performance. Display it as a single-number metric in recent games lists, game detail pages, and player profiles.

## Why

Athletes love a single number that summarizes their performance. "My career high Game Score is 24.3" is shareable, understandable, and ego-boosting. It costs almost nothing to compute since all inputs exist in `game_player_stats`.

## Implementation Steps

1. Create `packages/core/src/stats/game-score.ts` with `computeGameScore(stats)` function
   - Formula: PTS + 0.4×FGM − 0.7×FGA − 0.4×(FTA−FTM) + 0.7×OREB + 0.3×DREB + STL + 0.7×AST + 0.7×BLK − 0.4×PF − TOV
   - Also compute `efficiency = (PTS+REB+AST+STL+BLK) - (FGA-FGM) - (FTA-FTM) - TOV` (traditional EFF)
2. Export from `packages/core/src/index.ts`
3. Add Mongolian label "Тоглолтын үнэлгээ" (Game Score) and "Үр дүн" (EFF) to i18n
4. Display Game Score badge 🔥 in recent games table rows on player page
5. Show Game Score in top performers section on game detail page
6. Apply career-high Game Score highlighting with gold badge
