## Goal

Enhance the existing opponent scout card (`/teams/[slug]/scout`) with a print-optimized view that coaches can take to the locker room. One-page format with opponent strengths/weaknesses, key players, stat duels, and recent form.

## Why

The scout page exists (T-7.4 done ✅) but isn't printable. Coaches currently copy-paste or screenshot. A print CSS layout with a "Хэвлэх" button makes it genuinely useful in real game prep.

## Files to Touch

```
- src/app/teams/[slug]/scout/page.tsx        — Add print button + @media print CSS
- src/app/teams/[slug]/scout/components/     — Add PrintLayout wrapper
- src/app/teams/vs/[teamA]/[teamB]/page.tsx  — Also add print view
```

## Implementation Steps

1. Add `"use client"` to scout page (if not already) or create a PrintButton component
2. Create print-optimized layout:
   - Remove nav, footer, sidebar in print
   - Compact stat duel section side by side
   - Opponent top 3 players with key stats
   - Recent form as compact W/L badges
   - Key matchup comparison (team ORtg vs opponent DRtg, etc.)
3. Add `window.print()` button labeled "🖨️ Хэвлэх"
4. Add `@media print` CSS:
   - Page break rules
   - Black/white friendly (avoid dark backgrounds)
   - Font size optimization for A4
   - Hide non-essential decorative elements
