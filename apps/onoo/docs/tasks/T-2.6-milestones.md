## Goal

Auto-detected career bests shown as badge chips — career-high per stat, double-double / triple-double counts, 20+ point games, and current double-digit scoring streak.

## Why

Milestones turn raw game logs into stories. A badge showing "Career High: 35 pts (2026-06-15)" communicates achievement immediately. Streaks ("5 games with 10+ pts") show momentum.

## Implementation Steps

1. **Core types**: define `GameLine` (game_id, game_date, pts, reb, ast, stl, blk) and `Milestone` (type, value, game_date?, count?, streak?) in `packages/core/src/stats/milestones.ts`.
2. **`detectMilestones` pure function**: accepts `GameLine[]`, returns `Milestone[]`. Detection logic:
   - Career highs per stat (pts/reb/ast/stl/blk) — first time each record is set across the sorted game array
   - Double-double count (any two categories ≥10)
   - Triple-double count (any three categories ≥10)
   - 20+ point games count
   - Current double-digit scoring streak (counting backward from last game)
3. **Unit tests**: fixtures covering empty array, single game, multi-game career highs, double-double/triple-double detection, 20+ game counting, streak tracking. Two-player fixture to verify isolation.
4. **`MILESTONE_LABELS` dictionary**: added to `packages/core/src/i18n/stats.ts` — Mongolian + English labels for each milestone type.
5. **`Milestones` UI component**: badge grid using shadcn `Badge`. Each badge shows an icon (Award/Trophy/Flame/Sparkles), label, and value/date. Career-high badges show the value + date. Variants: `default` (accent) for career highs, `secondary` for counts, `outline` for streak.
6. **Integration**: player page calls `detectMilestones(gameLines)` with the full game log, renders `<Milestones milestones={...}/>` above the season arc.

## Design Decisions

- **Pure function in core package**: `detectMilestones` has zero React/DB/DOM dependencies — it's a domain function in `packages/core`. Testable without any framework, usable from server or client.
- **Sorted internally**: `detectMilestones` sorts input by `game_date` ascending regardless of input order — callers don't need to pre-sort.
- **First occurrence, not all-time max**: career highs track the *first* time a record is set, which is more dramatic (the breakout game), not the highest value overall.
- **Streak is current only**: the streak is always the streak ending at the last game in the array. Historical streaks are not tracked.
- **Badge icons**: different icons signal milestone importance — Trophy for career highs, Award for 20+ games, Flame for streak. Variants mapped by `milestoneVariant()`.

## Risks & Gotchas

- **Large game arrays**: `detectMilestones` is O(n) and runs on the server. Even with 200+ games (multiple seasons), this is negligible.
- **Milestone type for career career mode**: when viewing "Карьер" mode, milestones computed across all games make sense.
- **Badge overflow**: 7+ badges could wrap poorly on mobile. The component uses a flex-wrap layout with tight gap.
- **Concurrent milestones**: a triple-double game also counts as a double-double. Both badges render — this is intentional (the triple-double is more notable).
