# Нөөц хуулах, экспортлох

TOLOM систем нь таны өгөгдлийг хамгаалах хэд хэдэн түвшний нөөц хуулах, экспортлох боломжийг санал болгодог.

## 1. Өгөгдлийн экспорт (UI-ээр)

Системийн **Тохиргоо** хэсгээс байгууллагын бүх өгөгдлийг JSON файл хэлбэрээр экспортлох боломжтой.

Экспортод дараах өгөгдлүүд багтана:

- Байгууллагын тохиргоо
- Салбарууд
- Хэрэглэгчид, үүргүүд
- Харилцагчид
- Тээврийн хэрэгсэл, эзэмшигчид
- Ажлын захиалга (үйлчилгээ, сэлбэг, төлөвийн түүх)
- Үйлчилгээний каталог
- Сэлбэгийн каталог
- Нийлүүлэгчид
- Худалдан авалтын захиалга
- Бараа материалын хөдөлгөөн
- Санхүүгийн гүйлгээ
- Нэхэмжлэх, төлбөр

Экспорт хийх:
1. **Тохиргоо** хэсэгт очно уу
2. **Data Export & Backup** хэсэгт **Export Data** товч дарна уу
3. JSON файл татагдаж эхэлнэ

## 2. Мэдээллийн сангийн нөөц хуулах (Command Line)

Мэдээллийн санг бүрэн нөөцлөхөд дараах скриптүүдийг ашиглана.

### Шаардлагууд

- `supabase` CLI (локал нөөцөд)
- `pg_dump` (алсын нөөцөд, PostgreSQL-тэй хамт суудаг)
- `DATABASE_URL` орчны хувьсагч (алсын нөөцөд)

### Локал нөөц (хөгжүүлэлтийн орчин)

```bash
./scripts/backup.sh
```

Мэдээллийн сангийн схем, өгөгдлийг бүрэн нөөцлөж `.backups/` хавтсанд хадгална.

### Алсын нөөц (амьд сервер)

```bash
# Эхлээд DATABASE_URL-ээ тохируулна
export DATABASE_URL="postgresql://..."

# Дараа нь нөөцлөнө
./scripts/backup.sh --remote
```

### Бусад сонголтууд

| Сонголт | Тайлбар |
|---------|---------|
| `--schema-only` | Зөвхөн схемийг нөөцлөх (хүснэгт, индекс, RLS) |
| `--data-only` | Зөвхөн өгөгдлийг нөөцлөх |
| `--prune` | 30 хоногоос дээш настай нөөц хуулбаруудыг устгах |
| `--remote` | Алсын мэдээллийн санг нөөцлөх |
| `BACKUP_DIR` | Нөөц хадгалах хавтас (анхдагч: `.backups/`) |
| `RETENTION_DAYS` | Хадгалах хоног (анхдагч: 30) |

### Жишээнүүд

```bash
# Локал схемийн нөөц
./scripts/backup.sh --schema-only

# Алсын өгөгдлийн нөөц
./scripts/backup.sh --remote --data-only

# Хуучин нөөц хуулбаруудыг цэвэрлэх
./scripts/backup.sh --prune
```

## 3. Нөөц хуулбараас сэргээх

Сэргээхдээ `scripts/restore.sh` скриптийг ашиглана.

```bash
# Локал мэдээллийн санг сэргээх
./scripts/restore.sh ./.backups/tolom-backup-20260513-full.sql.gz

# Алсын мэдээллийн санг сэргээх
./scripts/restore.sh backup.sql --remote
```

::: warning Анхаар
Сэргээх үйлдэл нь мэдээллийн санг **бүрэн дарж бичнэ**. Сэргээхээс өмнө одоогийн мэдээллийн санг нөөцлөхөө мартуузай.
:::

## 4. Автомат нөөц (Supabase)

Supabase платформ нь дараах автомат нөөцийг хангадаг:

- **Өдөр тутмын нөөц** — мэдээллийн санг өдөр бүр автоматаар нөөцлөнө
- **Point-in-time recovery (PITR)** — Pro төлөвлөгөөнд 7 хоног хүртэлх хугацаанд сэргээх боломжтой
- **Хувилбар хяналт** — migration файлууд нь схем өөрчлөлтийн бүрэн түүхийг хадгална

Supabase Dashboard-оос Backup тохиргоог харна уу.

## 5. Excel экспорт

Сүүлийн жагсаалт бүрээс Excel формат руу экспортлох боломжтой.
Харилцагчид, тээврийн хэрэгсэл, ажлын захиалга, бараа материал гэх мэт бүх жагсаалтын хуудаснаас **Export Excel** товч дарж экспортолно.
