# Тээврийн хэрэгсэл

![Тээврийн хэрэгсэл](/images/vehicles.png)

Тээврийн хэрэгслийн бүртгэл нь харилцагч бүрийн машин, техникийн мэдээлэл, үйлчилгээний түүхийг хадгална.

## Жагсаалтын хуудас

Vehicles хуудаснаас:

- улсын дугаар эсвэл VIN-аар хайх
- Excel экспорт хийх (улсын дугаар, он, үйлдвэрлэгч, загвар, VIN, эзэмшигч)
- шинэ машин нэмэх
- мөр дээр дарж дэлгэрэнгүй нээх (зурагтын хэлбэрээр нээгдэнэ)
- засах (зурган дээрх баруун талын зүүний товч)
- устгах (зурган дээрх хогийн савны товч, баталгаажуулалтын цонхтой)

### Баганууд

| Багана | Тайлбар |
|--------|---------|
| **Улсын дугаар** | Машины улсын дугаар + он, үйлдвэрлэгч, загвар нэмэлт мэдээлэлтэй |
| **VIN** | Тээврийн хэрэгслийн дугаар (хэрэв байвал) |
| **Эзэмшигч** | Харилцагчийн нэр (хэрэв холбогдсон бол) |
| **Үйлдлүүд** | Засах болон устгах товчууд |

### Баруун талын sidebar

- **Stats** — нийт машин тоо, үйлдвэрлэгчийн тоо
- **Recent** — хамгийн сүүлд нэмэгдсэн 5 машин (улсын дугаар, марк, нэмсэн огноо)

### Мобайл харилцааны хэлбэр

Утасны дэлгэц дээр машин бүр картоор харагдана:

- улсын дугаар (моноширон)
- он, үйлдвэрлэгч, загвар
- VIN болон эзэмшигч мэдээлэл

## Бүртгэх мэдээлэл

Шинэ машин бүртгэхдээ дараах талбаруудыг бөглөнө:

### Захиалагч (Owner) хэсэг

| Талбар | Тайлбар |
|--------|---------|
| **Харилцагч сонгох** | Хайлтын талбараар харилцагчаа хайж сонгоно. Нэр, утас, имэйлээр хайж болно |
| **URL-аас урьдчилан сонгох** | `?customerId=...` параметрээр харилцагчийг автоматаар сонгоно |
| **Солих** | Сонгосон харилцагчаа солих боломжтой |

### Тээврийн хэрэгслийн мэдээлэл (Vehicle Information)

#### Заавал бөглөх талбарууд

| Талбар | Тайлбар | Жишээ |
|--------|---------|-------|
| **Улсын дугаар** ⭐ | Монгол улсын дугаарын формат (4 цифр + 3 үсэг) — автомат хяналттай | `1234 UBA` |
| **Үйлэрлэгч** ⭐ | Машины марк / үйлдвэрлэгч | `Toyota` |
| **Загвар** ⭐ | Машины загвар | `Prius` |

#### Нэмэлт талбарууд

| Талбар | Тайлбар | Жишээ |
|--------|---------|-------|
| **VIN** | Тээврийн хэрэгслийн нийтлэг дугаар | `JTDKN3DU...` |
| **Он** | Үйлдвэрлэсэн он | `2020` |
| **Одометр** | Гүйлтийн км | `120000` |
| **Хувилбар (Trim)** | Загварын хувилбар | `Hybrid SE` |
| **Өнгө** | Өнгөний сонголт | Цагаан, Хар, Улаан... |
| **Хөдөлгүүр** | Хөдөлгүүрийн мэдээлэл | `2.5L`, `3.5L V6` |
| **Дугуйн дугаар (Chassis)** | Дугуйн дугаар | |
| **Түлшний төрөл** | Сонголтоос сонгох: Gasoline, Diesel, Electric, Hybrid, LPG | `Gasoline` |
| **Хурдны хайрцаг** | Сонголтоос сонгох: Automatic, Manual, CVT, DCT | `Automatic` |
| **Жолооны хөтөлбөр** | Сонголтоос сонгох: AWD, 4WD, FWD, RWD | `AWD` |
| **Их биеийн төрөл** | Сонголтоос сонгох: SUV, Sedan, Hatchback, Coupe, Convertible, Wagon, Van, Truck, Bus | `Sedan` |
| **Лавлахын хугацаа** | Лавлахын хугацааны огноо | `2026-12-31` |
| **Дараагийн үйлчилгээ** | Дараагийн үйлчилгээний огноо | `2026-08-15` |
| **Тэмдэглэл** | Нэмэлт тэмдэглэл | |

::: tip Улсын дугаарын хяналт
Улсын дугаарыг **4 цифр + 3 үсэг** форматаар бичнэ (жишээ: `1234 UBA`). Буруу формат оруулсан тохиолдолд алдааны мессеж гарна.
:::

## Дэлгэрэнгүй харагдац

Машиг дээр дарахад **зурагтын хэлбэртэй дэлгэрэнгүй хaight** нээгдэнэ. Тэнд:

- захиалагчийн мэдээлэл
- засах, устгах боломжтой

## Холбоосууд

- Машинаас шууд ажлын захиалга руу шилжиж болно
- Үйлчилгээний хуваарь нь [Үйлчилгээний сануулга](/service-reminders) хэсэгтэй холбогдоно

## Ашиглах зөвлөмж

- Машиныг бүртгэхдээ **харилцагчийг заавал сонгоно** — харилцагчгүй машин бүртгэх боломжгүй
- **Түлшний төрөл, хурдны хайрцаг, жолооны хөтөлбөр** зэргийг зөв сонгох нь дараа нь тайлан, шүүлтүүрт хэрэг болно
- **Лавлахын хугацаа, дараагийн үйлчилгээ** огноог оруулбал үйлчилгээний сануулга автоматаар ажиллана
- **VIN**-ийг заавал биш ч оруулбал машиг илүү нарийн таних боломжтой
