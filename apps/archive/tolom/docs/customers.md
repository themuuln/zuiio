# Харилцагчид

![Харилцагчид](/images/customers.png)

Харилцагчийн хэсэг нь CRM, тээврийн хэрэгсэл, ажлын захиалгын түүхийг нэгтгэсэн хэрэглэгчийн сан юм. Харилцагч бүрт хувь хүн эсвэл байгууллага бүртгэж болох бөгөөд нэг бүртэлд тээврийн хэрэгсэл, нийлбэр үзлэг, нэхэмжлэх зэрэг холбогдсон өгөгдөл байна.

## Хоёр үндсэн харагдац

| Харагдац | Тайлбар |
| --- | --- |
| **My Customers** | Танай байгууллагын өөрийн харилцагчид. Бүрэн удирдах боломжтой (нэмэх, засах, устгах) |
| **Shared** | Бусад байгууллагуудаас хуваалцсан харилцагчид (зөвхөн унших). Байгууллагын нэрний тэмдэглэгээр харна |

Харагдацыг дээрх ToggleGroup товчлуураар солино. "My Customers" — Users icon, "Shared" — Globe icon.

## Хайх ба шүүлтүүр

- **Хайлт** — нэр, утас, имэйл, байгууллагын нэр, холбогдох хүн, бүрэн нэрээр хайна (илүү тодорхойлох)
- **Not visited in 3+ months** шүүлтүүр — сүүлийн 3 сар ирээгүй харилцагчдыг шүүнэ
- Шүүлтүүрийн тоо (count badge) нь идэвхгүй харилцагчдын тоог харуулна

## Жагсаалтын багана

### My Customers

| Багана | Мэдээлэл |
| --- | --- |
| **Name** | Харилцагчийн нэр (хувь хүн: нэр, овог нийлүүлсэн; байгууллага: компани нэр). Төрөл (individual/company) багана дээр гарч ирнэ. Хувь хүнд User icon, байгууллагад Building2 icon |
| **Contact** | Утас эсвэл имэйл. Утас байвал утас, үгүй бол имэйл, хоёулаа үгүй бол "--" |
| **Vehicles** | Бүртгэлтэй тээврийн хэрэгслийн тоо (Badge дотор Car icon-той) |
| **Visits** | Нийт айлчлалын тоо |
| **Last Visit** | Сүүлийн ирсэн огноо. "Today", "Yesterday", "X days ago", "X weeks ago" эсвэл огноогоор. Ирээгүй бол "Never" |
| **→** | Харилцагчийн дэлгэрэнгүй нээх товч |

### Shared

My Customers ижил баганатай + тухайн харилцагчийн эзэмшигч байгууллагын нэр Badge-ээр харуулна (Globe iconтай).

## Шинэ харилцагч бүртгэх

"Харилцагч нэмэх" товч дээр дарахад шинэ харилцагчийн форм нээгдэнэ (мөрний түвшинд диалог).

### Нийтийн талбарууд

| Талбар | Тайлбар |
| --- | --- |
| **Төрөл** | Хувь хүн (individual) эсвэл байгууллага (company) — dropdown сонголт |
| **Утас** | Монгол утасны формат автоматаар тохируулна (`formatMongolianPhone`) |
| **Имэйл** | Имэйл хаяг |
| **Хаяг** | Байршил |
| **Тэмдэглэл** | Нэмэлт мэдээлэл (4 мөрний textarea) |

### Хувь хүн (individual) нэмэлт талбарууд

| Талбар | Тайлбар |
| --- | --- |
| **Овог (First Name)** | Хувь хүний нэрний эхний хэсэг |
| **Нэр (Last Name)** | Хувь хүний нэрний сүүлийн хэсэг |

### Байгууллага (company) нэмэлт талбарууд

| Талбар | Тайлбар |
| --- | --- |
| **Компаний нэр** | Байгууллагын албан ёсны нэр |
| **Холбогдох хүн** | Байгууллагын харилцах хүн |

### Бүртгэх нөхцөл

- Утас, имэйл, нэр, компаний нэр, холбогдох хүн — эдгээрээс **доод нэг** нь байх шаардлагатай
- Утас эсвэл имэйл давхардсан бол зөвлөх шинжтэй (сэрэх мэдээлэл) гаргана, гэхдээ бүртгэлийг зогсоохгүй
- Шинэ харилцагчийг шинээр үүсгэхэд **audit log** бичигдэнэ

## Харилцагчийн дэлгэрэнгүй хуудас (Detail Sheet)

Жагсаалтын мөр дээр дарахад баруун талаас **detail sheet** нээгдэнэ.

### Унших горим (Read-only)

Дэлгэрэнгүй мэдээлэл:

| Хэсэг | Мэдээлэл |
| --- | --- |
| **Холбоо барих** | Утас (Phone icon), Имэйл (Mail icon), Хаяг (MapPin icon) |
| **Компани** | Байгууллагын нэр (компани төрөлд) — Building2 icon |
| **Холбогдох хүн** | Компаний харилцах хүн (компани төрөлд) |
| **Тэмдэглэл** | Нэмэлт мэдээлэл (хэрэв байвал) |
| **Машинууд** | Бүртгэлтэй тээврийн хэрэгслүүд (дугаар, жил, марк, загвар) |
| **Ажлын захиалгууд** | Холбогдсон ажлын захиалгууд (төлөв badge, огноо, нийт дүн MNT-ээр) |

Машин дээр дарахад тухайн машины detail хуудас руу шилжинэ.

### Засах горим (Edit)

Засах товч (Pencil icon) дээр дарахад форм нээгдэнэ. Дараах талбаруудыг засах боломжтой:

| Талбар | Тайлбар |
| --- | --- |
| **Төрөл** | Хувь хүн/Байгууллага солих |
| **Нэр** | First Name / Last Name (хувь хүн) эсвэл Компаний нэр / Холбогдох хүн (байгууллага) |
| **Утас** | Монгол утасны формат |
| **Имэйл** | Имэйл хаяг |
| **Хаяг** | Байршил |
| **Тэмдэглэл** | Нэмэлт мэдээлэл |

Засах үед **тэмдэглэл** textarea-д бүрэн нэрлэсэн талбаруудыг харуулна.

### Устгах

Толгой хэсэгт ногоон хогийн сав (Trash2 icon) товч байна. Дарахад **баталгаажуулах диалог** гарч ирнэ. Харилцагчийг **soft delete** хийнэ — `deleted_at` талбар бичигдэнэ, жинхэнэ устгахгүй.

## Харилцагчийн импорт (CSV)

`/dashboard/customers/import` хуудсанд олон харилцагчийг нэгэн зэрэг CSV файлаар импортлох боломжтой.

### Импортын урсгал

1. **CSV файл сонгох** — drag & drop эсвэл файл сонгогч ашиглах
2. **Урьдчилан харах** — эхний 5 мөрийг хүснэгтээр харуулна
3. **Импортлох** — "Import X Customers" товч дээр дарж импортлох
4. **Дүн** — амжилттай импортлогдсон тоо + алдаануудын жагсаалт

### CSV талбарууд

| CSV Багана | DB Талбар | Тайлбар |
| --- | --- | --- |
| `firstName` / `first_name` | `first_name` | Овог/нэрний эхний хэсэг |
| `lastName` / `last_name` | `last_name` | Овог/нэрний сүүлийн хэсэг |
| `phone` | `phone` | Утасны дугаар |
| `email` | `email` | Имэйл хаяг |
| `address` | `address` | Хаяг |
| `notes` | `notes` | Тэмдэглэл |
| `type` | `type` | Төрөл: `individual` (default) эсвэл `company` |
| `source` | `source` | Эх үүсвэр (жишээ: `referral`, `website`) |

### Импортын дүрэм

- Зөвхөн `.csv` файлыг хүлээн авна
- Хамгийн багадаа нэг **таних талбар** (firstName, lastName, phone, эсвэл email) бүх мөрд байх ёстой
- Утасны дугаар **давхардал** шалгана — ижил утасны дугаартай харилцагч байвал тухайн мөрийг алдаагаар татна
- Алдаануудыг мөрийн дугаартай (CSV-ийн 2-оос эхэлсэн) хамт харуулна
- Баталгаажсан мөрүүдийг **50 мөрийн багцаар** нэгтгэж нэмнэ
- Амжилттай импортлогдсон тоог `success` toast-оор мэдээлнэ
- Импортлохдоо **audit log** бичигдэнэ

### Алдааны төрлүүд

| Алдаа | Тайлбар |
| --- | --- |
| Файл хоосон | CSV файл хоосон эсвэл толгой мөр үгүй |
| Таних талбар байхгүй | Нэг ч таних талбар (firstName, lastName, phone, email) байхгүй |
| Утасны дугаар давхардал | Ижил утасны дугаар аль хэдийн бүртгэлтэй байна |
| DB алдаа | Бусад нөхцөлд алдаа (хүчний хязгаар, format алдаа гэх мэт) |

### Шаблон татаж авах

"Download Template" товч дээр дарж жишээ CSV файл татаж болно. Баганууд: `firstName, lastName, phone, email, address, notes, type, source`

## Практик зөвлөмжүүд

- **Харилцагчийг импортлохдоо** туршиж 5-10 мөртэй эхэл — алдаагаа ойлгоод дараа нь бүрэн файл оруулна
- **Shared харагдац** нь тухайн байгууллагын `sharing_enabled` тохиргоогоор идэвхждэг. Бусдын харилцагчийг засах боломжгүй
- **"Not visited in 3+ months"** шүүлтүүрийг харилцагчийн retention мэдээлэл цуглуулахад ашиглах
- **Тэмдэглэл** нь харилцагчийн дараагийн уулзалт, үйлчилгээний түүх, ажилтнуудын дотоод тэмдэглэлд хэрэгтэй
- **Утасны дугаар** Mongolian format автоматаар тохируулдаг — `+976 XXXX XXXX` формат руу хөрвүүлнэ
- **Харилцагчийн нэрийг харуулахдаа** дараах эрэмбээр: хувь хүн бол first+last name → байгууллага бол company name → contact person → phone
