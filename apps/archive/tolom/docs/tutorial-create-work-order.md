# Заавар: Ажлын захиалга үүсгэх

Энэ зааварт та **шинэ ажлын захиалгыг алхам алхмаар** хэрхэн үүсгэхийг сурах болно. Бүх процессыг нэг хуудаснаас бүрэн гүйцэтгэж болно.

---

## Алхам 1: Шинэ захиалга руу орох

Дээрх цэсээс **"+ Үүсгэх"** товч дээр дарж, дараа нь **"Ажлын захиалга"** сонгоно уу.

Эсвэл шууд `/dashboard/work-orders/new` хаягаар орж болно.

<TutorialStep
  :step="1"
  title="Шинэ захиалга нээх"
  image="/images/tutorial-wo-step1.png"
  :markers="[
    { id: 1, x: 50, y: 17, label: '1', color: '#3b82f6' }
  ]"
>
  **Харилцагч** болон **Тээврийн хэрэгсэл** хоёр нь <b>заавал</b> бөглөх талбарууд юм. Эхлээд харилцагчаа сонгоно уу.
</TutorialStep>

---

## Алхам 2: Харилцагчаа сонгох

**"Нэр, утас эсвэл улсын дугаараар хайх..."** талбарт харилцагчийн нэр, утас эсвэл имэйлийг бичнэ уу. Хайлтын жагсаалт гарч ирэхэд зөв харилцагчаа сонгоно уу.

<TutorialStep
  :step="2"
  title="Харилцагчаа хайж сонгох"
  image="/images/tutorial-wo-step2.png"
  :markers="[
    { id: 1, x: 52, y: 40, label: '2', color: '#3b82f6' }
  ]"
>
  Хайлтын жагсаалтад <b>хувь хүн</b> болон <b>байгууллага</b> хоёулаа гарч болно. Зөв нэрийг дарна уу.
</TutorialStep>

---

## Алхам 3: Харилцагч сонгогдлоо

Харилцагч сонгогдсоны дараа түүний мэдээлэл ногоон хүрээтэй карт хэлбэрээр харагдана. **"Солих"** товчоор өөр харилцагч руу солих боломжтой.

<TutorialStep
  :step="3"
  title="Харилцагчийн мэдээлэл"
  image="/images/tutorial-wo-step3.png"
  :markers="[
    { id: 1, x: 50, y: 43, label: '3', color: '#22c55e' }
  ]"
>
  Харилцагчийн <b>нэр</b> ба <b>утасны дугаар</b> ногоон хүрээтэй картад харагдана.
</TutorialStep>

---

## Алхам 4: Тээврийн хэрэгсэл сонгох

Тээврийн хэрэгсэл хайх талбарт **улсын дугаар** эсвэл **машиний нэр**-ээр хайна уу. Жишээ нь: `1111` гэж бичихэд `1111УНА — 2021 Toyota Prius` гарч ирнэ.

<TutorialStep
  :step="4"
  title="Тээврийн хэрэгсэл хайх"
  image="/images/tutorial-wo-step4.png"
  :markers="[
    { id: 1, x: 50, y: 79, label: '4', color: '#3b82f6' }
  ]"
>
  Тухайн харилцагчийн бүртгэлтэй машинууд жагсаалтад гарна. Зөв машигаа сонгоно уу. Хэрэв бүртгэлгүй бол <b>"Машин хурдан үүсгэх"</b> товчоор шинээр бүртгэж болно.
</TutorialStep>

---

## Алхам 5: Гомдол / Оношилгоо болон Үйлчилгээ нэмэх

Тээврийн хэрэгсэл сонгогдсоны дараа дараах хэсгүүд гарч ирнэ:

- **Гомдол / Оношилгоо** — харилцагчийн гомдол болон оношилгооны шошго
- **Үйлчилгээ** — каталогиос үйлчилгээ хайж нэмэх

<TutorialStep
  :step="5"
  title="Гомдол ба Үйлчилгээ"
  image="/images/tutorial-wo-step5.png"
  :markers="[
    { id: 1, x: 50, y: 22, label: '5а', color: '#f59e0b' },
    { id: 2, x: 50, y: 65, label: '5б', color: '#3b82f6' }
  ]"
>
  <b>5а</b> — Гомдол хэсэгт харилцагчийн ямар гомдолтой ирснийг бичнэ. Оношилгооны шошго (жишээ нь: "Engine", "Brakes")-г сонгоно.<br/>
  <b>5б</b> — Үйлчилгээ хайх талбарт нэр бичиж каталогиос сонгоно. Нэг удаа дарвал үйлчилгээ нэмэгдэнэ.
</TutorialStep>

---

## Алхам 6: Сэлбэг, Механикч, Тэмдэглэл

Дараах хэсгүүдийг нэмэлтээр бөглөнө:

- **Сэлбэг** — ашигласан сэлбэг нэмэх (сонголтоор)
- **Механикч** — хариуцлагатай механикчаа сонгох
- **Тэмдэглэл** — нэмэлт тэмдэглэл

<TutorialStep
  :step="6"
  title="Сэлбэг ба Механикч"
  image="/images/tutorial-wo-step6.png"

>
  <b>6а</b> — Механикч сонгох дропдаунаас хариуцлагатай механикчаа сонгоно.<br/>
  <b>6б</b> — Тэмдэглэл хэсэгт нэмэлт мэдээлэл бичиж болно (заавал биш).
</TutorialStep>

---

## Алхам 7: Нийт дүн хянаж, захиалга үүсгэх

Формын доод хэсэгт **Үйлчилгээ**, **Сэлбэг**, **Нийт дүн** автоматаар тооцогдоно. Бүх мэдээллийг хянаж, **"Захиалга үүсгэх"** товчийг дарна уу.

<TutorialStep
  :step="7"
  title="Захиалга үүсгэх"
  image="/images/tutorial-wo-step7.png"
  :markers="[
    { id: 1, x: 78, y: 84, label: '✓', color: '#22c55e' }
  ]"
>
  Бүх мэдээллийг хянаад <b>"Захиалга үүсгэх"</b> товчийг дарна уу. Захиалга үүсгэгдэж, Bay View дээр автоматаар харагдана.
</TutorialStep>

---

## Дүгнэлт

恭喜! Та амжилттай шинэ ажлын захиалга үүсгэж сурлаа. Дараах зүйлсийг анхаарна уу:

- **Харилцагч** болон **Тээврийн хэрэгсэл** заавал сонгоно
- **Үйлчилгээ**, **Сэлбэг** нэмэх нь сонголтоор (хоосон ч үүсгэж болно)
- Захиалга үүсгэсний дараа **Bay View** дээр харагдана
- Төлөвийг дараа нь шууд өөрчлөх боломжтой

::: tip Дараагийн алхам
Захиалга үүсгэсний дараа **Bay View** (`/dashboard/bay-view`) рүү орж захиалгынхоо явцыг хянах боломжтой.
:::
