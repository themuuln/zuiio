# Үнийн санал (Estimates / Quotes)

Үнийн санал (Quote) нь харилцагчид засвар, үйлчилгээний үнийг урьдчилан мэдээлэх баримт бичиг юм. Зөвшөөрөгдсөн үнийн саналыг ажлын захиалга (Work Order) болгон хувиргах боломжтой.

## Төлвийн урсгал

```
Draft → Sent → Approved → Converted (ажлын захиалга болсон)
                  ↘ Declined
                  ↘ Expired
```

| Төлөв | Өнгө | Тайлбар |
| --- | --- | --- |
| **Draft** | Саарал | Ноорог — засварлах, нэмэх боломжтой |
| **Sent** | Хөх | Харилцагчид хүргүүлсэн |
| **Approved** | Ногоон | Харилцагч зөвшөөрсөн — ажлын захиалга болгоход бэлэн |
| **Declined** | Улаан | Харилцагч татгалзсан |
| **Expired** | Шар | Хүчинтэй хугацаа дууссан |
| **Converted** | Ягаан | Ажлын захиалга болж хувирсан |

### Төлөвийн товчууд (дэлгэрэнгүй хуудас)

| Төлөв | Боломжтой үйлдлүүд |
| --- | --- |
| **Draft** | `Send` → Sent, `Approve` → Approved |
| **Sent** | `Approve` → Approved, `Decline` → Declined |
| **Approved** | `Convert to Work Order` → Converted, `Decline` → Declined |
| **Declined** | — (төгсгөл) |
| **Expired** | — (төгсгөл) |
| **Converted** | — (төгсгөл) |

## Жагсаалтын хуудас

### Төлвийн шүүлтүүр

Жагсаалтын дээрх dropdown-оос төлвөөр шүүж болно:

- **Бүгд** — бүх үнийн санал
- **Идэвхтэй** — `draft`, `sent`, `approved` төлөвтэйг шүүнэ
- Нэг бүрээр сонгох: draft, sent, approved, declined, expired, converted

### Жагсаалтын элемент бүр

Жагсаалт нь card хэлбэрээр харуулагдана:

- **Үнийн саналын дугаар** (жишээ: `EST-00001`)
- **Төлөвийн badge** — өнгөт badge
- **Огноо** — үүссэн огноо
- **Харилцагчийн ID** — хэрэв харилцагч холбогдсон бол
- **Нийт дүн** — ₮-аар

Мөр дээр дарвал дэлгэрэнгүй хуудас руу шилжинэ.

## Шинэ үнийн санал үүсгэх

**Цэс:** Хажуугийн самбараас **Estimates** → **New Quote**

### 1. Харилцагч сонгох

- Хайлтын талбарт харилцагчийн нэр, утас, имэйлээр хайх
- Шинэ харилцагч үүсгэх боломжтой

### 2. Машин сонгох

- Сонгосон харилцагчийн машины жагсаалтаас сонгох
- Харилцагч сонгохоос өмнө машин сонгох боломжгүй

### 3. Мөрүүд нэмэх

Гурван төрлийн мөр нэмэх боломжтой:

| Төрөл | Тайлбар |
| --- | --- |
| **Үйлчилгээ (Service)** | Каталогоос хайж, сонгох. Sheet хэлбэрээр нээгдэнэ |
| **Сэлбэг (Part)** | Инвенторийн каталогоос хайж, сонгох. Sheet хэлбэрээр нээгдэнэ |
| **Гар мөр (Custom)** | Өөрийнхөө тайлбар, үнэ оруулах |

### Мөр бүрийн талбарууд

| Талбар | Тайлбар |
| --- | --- |
| **Дугаар** | Автомат (1, 2, 3...) |
| **Тайлбар** | Мөрийн нэр/тодорхойлолт |
| **Төрөл** | service / part / custom ( Badge-аар харуулна) |
| **Тоо хэмжээ** | Нэгжийн тоо (1+) |
| **Нэгжийн үнэ** | Нэгжийн үнэ ₮-аар |
| **Хөнгөлөлт %** | Хувийн хөнгөлөлт (0-100%) |
| **Хөнгөлөлт ₮** | Тогтмол дүнгийн хөнгөлөлт |
| **Нийт** | Автомат тооцоо: `(үнэ × тоо) - хөнгөлөлтүүд` |
| **Хасах** | Мөрийг устгах товч |

### Нийт дүн

- **Дэд нийт** — бүх мөрийн нийт
- **Хөнгөлөлт** (хэрэв байвал)
- **Татвар** (хэрэв байвал)
- **Нийт дүн (Grand Total)**

### Тэмдэглэл болон нөхцөл

- **Тэмдэглэл (Notes)** — нэмэлт тэмдэглэл
- **Нөхцөл (Terms & Conditions)** — үнийн саналын нөхцөл

### Хадгалах

- **Cancel** — буцах
- **Save as Draft** — ноорог хэлбэрээр хадгалах
- **Create Quote** — үүсгэх (ноорог хэлбэрээр)

## Үнийн саналыг ажлын захиалга болгох

Зөвхөн **Approved** төлөвтэй үнийн саналыг ажлын захиалга болгох боломжтой.

1. Үнийн саналын **дэлгэрэнгүй хуудас** руу орно
2. **Convert to Work Order** товч дарна
3. Баталгаажуулах цонх гарч ирдэг:
   - Харилцагчийн мэдээлэл
   - Машиний мэдээлэл
   - Мөрүүдийн тоо
   - Нийт дүн
4. **Create Work Order** товч дарна
5. Шинэ ажлын захиалгын хуудас руу шилжинэ

### Хувиргах үед юу болох вэ?

1. Шинэ `work_order` үүснэ (customer, vehicle, discount зэрэг мэдээллээр)
2. Үнийн саналын мөрүүд (`estimate_items`) дараах байдлаар хуулагдана:
   - **service** төрлийн мөрүүд → `work_order_services`
   - **part** төрлийн мөрүүд → `work_order_parts`
   - **custom** төрлийн мөрүүд → `work_order_services` (service_name болж орно)
3. Алхам бүрт `service_price_history` / `part_price_history` шинэчлэгдэнэ
4. **Status History** дээр "Created from estimate #EST-00001" гэж тэмдэглэгдэнэ
5. Үнийн саналын төлөв `converted` болж, `converted_work_order_id` хадгалагдана
6. Ажлын захиалгын `source_estimate_id` талбарт үнийн саналын ID хадгалагдана

## Дэлгэрэнгүй хуудас

### Толгой хэсэг

- Үнийн саналын дугаар (EST-00001)
- Үүссэн огноо
- Харилцагчийн нэр
- Төлөвийн badge

### Төлвийн үйлдлүүд

Дээрх жагсаалтын дагуу тухайн төлөвт тохирох товчууд харуулагдана.

### Харилцагч ба Машиний мэдээлэл

- Харилцагчийн нэр, утас
- Машиний улсын дугаар, жил, марк, загвар

### Мөрүүдийн хүснэгт

| Багана | Тайлбар |
| --- | --- |
| **#** | Дугаар |
| **Тайлбар** | Мөрийн нэр + төрлийн badge |
| **Тоо** | Тоо хэмжээ |
| **Нэгжийн үнэ** | ₮-аар |
| **Хөнгөлөлт** | ₮ болон/эсвэл % |
| **Нийт** | Мөрийн нийт үнэ |

### Нийт дүн

- Дэд нийт
- Хөнгөлөлт (хэрэв байвал)
- Татвар (хэрэв байвал)
- **Нийт дүн (Grand Total)**

### Тэмдэглэл болон нөхцөл

- Тэмдэглэл болон нөхцөл хэрэв оруулсан бол харуулна

### Холбогдох ажлын захиалга

Хувиргасан бол холбогдох ажлын захиалгыг харуулна:

- Ногоон карттай мэдээлэл
- **Ажлын захиалга харах** товч — шууд ажлын захиалгын хуудас руу шилжинэ

## API

```
GET    /api/organizations/:id/estimates                         — Жагсаалт (status, branch_id шүүлтүүр)
POST   /api/organizations/:id/estimates                         — Шинэ үнийн санал
GET    /api/organizations/:id/estimates/:estimateId              — Дэлгэрэнгүй
PATCH  /api/organizations/:id/estimates/:estimateId              — Засварлах (status, notes, terms)
DELETE /api/organizations/:id/estimates/:estimateId              — Устгах
POST   /api/organizations/:id/estimates/:estimateId/convert      — Ажлын захиалга болгох
```

## Хэрэглээний зөвлөмж

- Үнийн саналыг **ноорог** хэлбэрээр үүсгэж, засварладаг
- **Send** товчийг дарж харилцагчид илгээнэ — төлөв `sent` болно
- Харилцагч зөвшөөрөхөд **Approve** товчийг дарна — төлөв `approved` болно
- Зөвхөн **approved** төлөвтэй үнийн саналыг ажлын захиалга болгоно
- **Custom мөр** ашиглан каталогод байхгүй үйлчилгээ, сэлбэг оруулж болно
- **Хөнгөлөлт** мөр бүр дээр тус бүр тохируулах боломжтой (% болон ₮)
- Хувиргасны дараа үнийн саналыг засварлах боломжгүй — `converted` төлөвт орно
- Ажлын захиалгын дэлгэрэнгүй хуудаснаас нэхэмжлэх үүсгэх боломжтой
