# Системийн тохиргоо

![Системийн тохиргоо](/images/settings.png)

Тохиргооны хуудас (`/dashboard/settings`) нь байгууллагын үндсэн утгууд, салбар, харагдац, комисс, үнийн дүрэм, оношилгооны шошго, Telegram, тээврийн хэрэгсэл, өгөгдөл хуваалцах болон экспортын тохиргоог удирдана.

## Тохиргооны 10 хэсэг

| Дугаар | Хэсэг | Тайлбар |
|--------|-------|---------|
| 1 | **General** | Байгууллагын үндсэн мэдээлэл, анхдагч утгууд |
| 2 | **Branches** | Салбаруудын жагсаалт, санхүүгийн салангид байдал |
| 3 | **Appearance** | Theme, өнгө, density |
| 4 | **Commission Rules** | Механикчийн комиссын дүрэм |
| 5 | **Pricing Rules** | Тээврийн хэрэгслийн төрөл, ангилалаас хамааран үнийг автоматаар тохируулах |
| 6 | **Diagnosis Labels** | Оношилгооны шошгууд |
| 7 | **Telegram Bot** | Telegram холболт ба мэдэгдэл |
| 8 | **Vehicle Niche** | Аль марк, загварт төвлөрөхөө хязгаарлах |
| 9 | **Data Sharing** | Бусад байгууллагад харагдах өгөгдлийг удирдах |
| 10 | **Data & Export** | Өгөгдөл татах, backup хийх |

### Хуудсын бүтэц

Тохиргооны хуудас дээр:

- **Дээрх хайлтын мөр** — хэсгээр хайх боломжтой, одоогийн хэсгийн нэр Badge-ээр харагдана
- **Зүүн талын sidebar** — бүх хэсгийн icon бүхий жагсаалт, идэвхтэй хэсэг тод өнгөтэй, доод хэсэгт байгууллагын эхний үсэг, хэл/цагийн бүс/валютын мэдээлэл
- **Үндсэн агуулга** — сонгосон хэсгийн агуулга

## 1. General (Үндсэн)

General хэсэг хоёр хэсгээс бүрдэнэ: **Organization Card** болон **Business Defaults Form**.

### Organization Card

Зүүн талд байрлах карт:

| Талбар | Тайлбар |
|--------|---------|
| **Logo** | Логогийг upload хийх болон өөрчлөх (OrgLogoUpload) |
| **Name** | Байгууллагын нэр (засах боломжгүй — зөвхөн харах) |
| **Slug** | Байгууллагын slug (monospace үсэгтэй) |

### Business Defaults Form

Баруун талд байрлах карт:

| Талбар | Анхдагч утга | Тайлбар |
|--------|-------------|---------|
| **Invoice Prefix** | `INV` | Нэхэмжлэхийн тэмдэг (дээд тал нь 12 тэмдэгт, том үсгээр) |
| **Default Currency** | `MNT` | Валют сонгох: MNT, CNY, USD, EUR |
| **НӨАТ Татвар (VAT)** | `Идэвхгүй` | Нэмэгдсэн Өртөгт Татварыг идэвхижүүлэх/идэвхгүй болгох |
| **НӨАТ Хувь** | `10%` | НӨАТ идэвхижүүлсэн үед хувийг тохируулна |
| **НДШ Тооцоо** | `Идэвхгүй` | Нийгмийн даатгалын шимтгэлийг тооцох эсэх |
| **НДШ Ажил олгогч** | `11.5%` | Ажил олгогчийн НДШ хувь |
| **НДШ Ажилтан** | `10%` | Ажилтны НДШ хувь |
| **Э-Баримт (E-Invoice)** | `Идэвхгүй` | Цахим нэхэмжлэлийг идэвхижүүлэх |
| **E-Invoice Merchant ID** | — | Татварын ерөнхий газрын merchant ID |
| **E-Invoice API Key** | — | Татварын ерөнхий газрын API түлхүүр |
| **Timezone** | `Asia/Ulaanbaatar` | Цагийн бүс |
| **Date Format** | `YYYY-MM-DD` | Огнооны формат |
| **Default Language** | `mn` | Хэл сонгох: mn (Монгол), en (English) |

### НӨАТ (VAT) Татвар

НӨАТ (Нэмэгдсэн Өртөгт Татвар) нь Монгол Улсын 10%-ийн татвар юм. Энэхүү тохиргоогоор:

- **Идэвхжүүлсэн:** Бүх нэхэмжлэх, ажлын захиалга, тооцоонд НӨАТ автоматаар тооцно
- **Идэвхгүй:** НӨАТ тооцохгүй (жижиг бизнесүүдэд тохиромжтой)
- **Ажлын захиалга тус бүрд:** Засварын булан дээр НӨАТ-г асаах/унтраах боломжтой

### НДШ (Нийгмийн даатгал)

НДШ нь хөдөлмөрийн зардлын тооцооны хэрэгсэл юм:

- **Ажил олгогч:** Цалингийн 11.5%
- **Ажилтан:** Цалингийн 10%
- Зөвхөн цалин хөлсөнд хамаарна, бараа үйлчилгээнд хамаарахгүй

### Э-Баримт (E-Invoice)

Э-Баримт нь Монгол Улсын Татварын ерөнхий газрын цахим нэхэмжлэлийн систем юм:

- B2B гүйлгээнд заавал шаардлагатай
- Нэхэмжлэх бүрт бүртгүүлж, бүртгэлийн дугаар болон QR код авна
- `ebarimt.mn` сайтаар баталгаажуулж болно

Хэл солих үед систем locale cookie-г шинэчилж хуудсыг дахин ачаална. **Save** товч дээр дарж хадгална.

## 3. Appearance (Харагдац)

### Theme (Сэдэв)

| Сонголт | Тайлбар |
|---------|---------|
| **Light** | Гэрэл арьс — цагаан дэвсгэртэй |

### Brand Color (Брэндийн өнгө)

Брэндийн өнгийг 3 аргаар тохируулж болно:

1. **Color picker** — дугуй товч дээр дарж өнгө сонгох
2. **Hex код** — `#2563eb` мэт форматтай hex өгөх
3. **Пreset сонголтууд:**

| Нэр | Өнгө |
|-----|------|
| Default | Анхдагч өнгө |
| Slate | `#334155` |
| Blue | `#2563eb` |
| Green | `#16a34a` |
| Red | `#dc2626` |
| Orange | `#ea580c` |
| Purple | `#9333ea` |
| Teal | `#0d9488` |
| Pink | `#db2777` |

Өнгө сонгоход preview шууд харагдана. Хадгалсан өнгөөрөө буцаах боломжтой (**Reset to saved**).

## 4. Commission Rules (Комиссын дүрэм)

Механикч бүрийн ажлын гүйцэтгэлээс хамааран комисс тооцох дүрмүүдийг эндээс удирдана.

### Дүрмийн хүснэгт

| Багана | Тайлбар |
|--------|---------|
| **Name** | Дүрмийн нэр |
| **Mechanic** | Хамаарах механикч (хоосон бол бүх механикчид) |
| **Type** | Комиссын төрөл |
| **Value** | Утга (хувь эсвэл тогтмол дүн) |
| **Min / Max** | Хязгаар |
| **Status** | Active эсвэл Inactive |
| **Actions** | Засах (pencil) / Устгах (trash) |

### Дүрэм үүсгэх / Засах

Дүрмийн диалог дээр дараах талбарууд байна:

| Талбар | Тайлбар |
|--------|---------|
| **Rule Name** | Дүрмийн нэр (шаардлагатай) |
| **Mechanic** | Тухайн механикчийг сонгох (Combobox-оос хайж сонгоно — хоосон бол бүх механикчид хамаарна) |
| **Commission Type** | Комиссын төрөл сонгох |
| **Commission Value** | Утга оруулах (% эсвэл тогтмол дүн — төрлөөс хамаарч өөрчлөгдөнө) |
| **Min Commission** | Хамгийн бага комисс (заавал биш) |
| **Max Commission** | Хамгийн их комисс (заавал биш) |
| **Active** | Идэвхтэй эсэх toggle |

### Комиссын төрлүүд

| Төрөл | Формула | Жишээ |
|-------|---------|-------|
| **Percentage of labor** | Ажлын цалин × хувь | Ажлын цалин 100,000₮, 20% бол 20,000₮ |
| **Percentage of parts** | Сэлбэгийн үнэ × хувь | Сэлбэг 50,000₮, 15% бол 7,500₮ |
| **Percentage of revenue** | Орлого × хувь | Орлого 200,000₮, 10% бол 20,000₮ |
| **Fixed per work order** | Захиалга бүрт тогтмол | Захиалга бүрт 5,000₮ |

## 5. Pricing Rules (Үнийн дүрэм)

Тээврийн хэрэгслийн төрөл, ангилалаас хамааран сэлбэг, үйлчилгээний үнийг автоматаар тохируулах боломж.

Үнийн дүрмийн талаарх дэлгэрэнгүй мэдээллийг [Үнийн дүрмүүд](/pricing-rules) хуудаснаас уншина уу.

### Дүрмийн жагсаалт

Дүрмүүд **priority** (эрийн) дугаараар эрэмбэлэгдсэн — бага тоо нь түрүүнд тооцогдоно. Дүрэм бүрт:

- Нэр
- Тайлбар
- **Applies to** Badge (Parts / Services / Both)
- **Active/Inactive** Badge
- Priority дугаар
- Operator + утга
- Нөхцлийн тайлбар
- Toggle (идэвхтэй/идэвхгүй), засах, устгах товч

### Дүрэм үүсгэх / Засах

Дүрмийн диалогт дараах талбарууд байна:

| Талбар | Тайлбар |
|--------|---------|
| **Rule Name** | Дүрмийн нэр |
| **Description** | Тайлбар (заавал биш) |
| **Applies To** | Хэсэг сонгох: Both / Parts / Services |
| **Vehicle Condition** | Тээврийн хэрэгсэл хэрхэн тодорхойлох |
| **Condition-specific fields** | Сонгосон нөхцөлөөс хамаарч илэрч ирэх нэмэлт талбарууд |
| **Condition Display** | Нөхцлийн хүний уншиж болох тайлбар |
| **Operator** | Үнэнд хэрхэн нөлөөлөх |
| **Value** | Операторын утга |
| **Priority** | Эрэмбэ (бага = түрүүнд тооцогдоно) |
| **Part Category** | Зөвхөн тодорхой сэлбэгийн ангилалд хамаарах (заавал биш) |
| **Service Category** | Зөвхөн тодорхой үйлчилгээний ангилалд хамаарах (заавал биш) |

### Vehicle Condition (Нөхцөл)

Дүрэм ямар тээврийн хэрэгсэлд хамаарахыг дараах нөхцөлөөр тодорхойлно:

| Нөхцөл | Нэмэлт талбарууд | Жишээ |
|---------|-----------------|-------|
| **Vehicle class** | Classes (таслалаар) | `luxury`, `standard`, `economy`, `performance` |
| **Vehicle make** | Makes (таслалаар) | `Lexus`, `Toyota`, `BMW` |
| **Make + model** | Makes + Models (таслалаар) | Makes: `Lexus`, Models: `RX`, `NX` |
| **Fuel type** | Fuel types (таслалаар) | `hybrid`, `plug-in-hybrid`, `electric` |
| **Body type** | Body types (таслалаар) | `suv`, `sedan`, `crossover`, `truck` |
| **All vehicles** | Нэмэлт талбаргүй | Бүх тээврийн хэрэгсэлд хамаарна |

### Операторууд

| Оператор | Формула | Жишээ |
|----------|---------|-------|
| **Multiply** | Үнэ × value | value=1.25 бол 25% нэмэгдэл |
| **+ Fixed amount** | Үнэ + value | value=20000 бол +20,000₮ |
| **Fixed price** | Үнэ = value | value=120000 бол 120,000₮ тогтмол |
| **+ Percentage** | Үнэ × (1 + value%) | value=15 бол +15% |
| **- Percentage** | Үнэ × (1 - value%) | value=10 бол -10% |

## 7. Telegram Bot

Telegram-аар дамжуулан үйлчилгээний сануулга, орлогын нөлөөллийн тайлан, яаралтай мэдэгдэл хүлээн авах боломж.

### Холболтын алхмууд

1. **Generate Link** товч дээр дарж нэг удаагийн холболтын token үүсгэнэ (15 минут хүчинтэй)
2. Telegram-д нээж **@tolomerpbot** ботыг эхлүүлнэ
3. **/start \<your_token\>** гэж илгээнэ
4. Дууссан! Өдөр, 7 хоногийн тайлангуудыг хүлээн авч эхэлнэ

### Боломжууд

| Үйлдэл | Тайлбар |
|--------|---------|
| **Generate Link** | Нэг удаагийн холболтын link үүсгэх |
| **Copy Link** | Link-ийг clipboard-д хуулах |
| **Open in Telegram** | Telegram апп-д шууд нээх |
| **QR Code** | Утсаараа скан хийж холбогдох |

## 8. Vehicle Niche (Тээврийн хэрэгсэл)

- Тээврийн хэрэгсэл үүсгэхэд
- Ажлын захиалга дээр
- Сэлбэгийн каталогт

харагдана.

### Тохиргоо

| Талбар | Тайлбар |
|--------|---------|
| **Enable toggle** | Vehicle niche-ийг идэвхжүүлэх/хүчингүй болгох |
| **Brand selection** | Брэндүүдийн жагсаалт — checkbox-уудаар сонгох |
| **Model selection** | Брэндийг дэлгэж загваруудыг сонгох |
| **Select all** | Бүх брэндийг сонгох |
| **Invert** | Сонголтыг эсрэг болгох |
| **Clear all** | Бүх сонголтыг арилгах |
| **Save niche settings** | Тохиргоог хадгалах |

## 9. Data Sharing (Өгөгдөл хуваалцах)

Бусад байгууллагуудад танай өгөгдлийг харуулах эсэхийг удирдана.

### Хуваалцах өгөгдлүүд

| Өгөгдөл | Агуулга |
|---------|---------|
| **Customer profiles** | Нэр, утас, и-мэйл, хаяг |
| **Vehicle details** | Улсын дугаар, марк, загвар, VIN, одометр |
| **Service history** | Ажлын захиалга, үйлчилгээ, ашигласан сэлбэг |
| **Invoices & payments** | Нэхэмжлэх, төлбөрийн төлөв |

### Хандалтын дүрэм

- Бусад байгууллагууд зөвхөн **унших** боломжтой — засах, устгах боломжгүй
- Танай ажилтнууд хэвийн бүрэн хандалттай үлдэнэ
- Хуваалцахыг хүссэн үедээ идэвхгүй болгож болно — өөрчлөлт шууд хүчин төлөвт орно

## 10. Data & Export (Өгөгдөл ба Экспорт)

### Export All Data

Бүх байгууллагын өгөгдлийг JSON форматаар татаж болно:

- Харилцагчид
- Тээврийн хэрэгсэл
- Ажлын захиалга
- Бараа материал
- Нэхэмжлэх
- Тохиргоо

**Export Data** товч дээр дарахад файл автоматаар татагдана (`tolom-export-YYYY-MM-DD.json`).

### Database Backup

Команд мөрөөс backup хийх:

```bash
# Local backup
./scripts/backup.sh

# Remote backup
./scripts/backup.sh --remote
```

## Зөвлөмж

- **Хайлт ашиглах** — тохиргооны хайлтын мөрөөр тухайн хэсгийг хурдан олох
- **Хэл солихдоо анхаарах** — хэл солих үед хуудас дахин ачаалагдана, хадгалсан эсэхийг шалгана уу
- **Салбарын санхүүгийн салгаар байдал** — нэг салбартай бол идэвхгүй үлдээж болно; олон салбартай бол салбар бүрт тусдаа санхүү харахыг идэвхжүүлэх нь зүйтэй
- **Комиссын дүрэмд механикч сонгохгүй бол** дүрэм нь бүх механикчид хамаарна — ерөнхий дүрэм тогтоохдоо механикч сонгохгүй байх нь хялбар
- **Diagnostic labels-ийн өнгө** —preset өнгөнүүдийг ашиглах нь илүү тохь тухтай харагдана; хэрэв өөрийн өнгө хэрэгтэй бол hex код оруулж болно
