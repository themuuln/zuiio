# Зөвлөмж, шилдэг туршлагууд

## Хайлт ба бүртгэл

::: tip Утасны дугаараар хурдан хайх
Харилцагч хайх хамгийн хурдан арга — утасны дугаараар хайх. Хайлтын талбарт дугаарын хэдэн орон ч бичихэд тохирох үр дүн гарч ирнэ.
:::

::: tip Машины дугаарын автомат санал
Ажлын захиалга үүсгэхдээ машины улсын дугаарыг бичиж эхлэхэд систем өмнө бүртгэгдсэн машинуудыг санал болгоно. Энэ нь давхар бүртгэлээс сэргийлнэ.
:::

## Ажлын захиалга ба төлөв

::: tip Төлөвийг тогтмол шинэчлэх
Захиалгын төлөвийг тогтмол шинэчилж байх нь багийн бусад гишүүдэд мэдээлэлтэй байхад тусалдаг. Ялангуяа "In Progress" болон "Ready for Pickup" төлөвүүдийг цаг тухайд нь шинэчлэх нь чухал.
:::

::: tip "Ready for Pickup" болгох үед
Захиалгыг "Ready for Pickup" болгохдоо **PostServiceDialog**-д одометр, зөвлөмж, тэмдэглэлийг бүртгэнэ. Энэ нь дараагийн үйлчилгээний сануулгын хугацааг автоматаар тооцоход хэрэгтэй.
:::

## Булан ба механикч

::: tip Булангийн тоог өөрчлөх
Засварын булангийн тоог toolbar-ын **Bay count** талбараас өөрчилж болно. Булангуудыг нэмэх эсвэл хасахад хэрэгтэй.
:::

::: tip "My Jobs" горим
Механикчид **My Jobs** товчийг асаахад зөвхөн өөрийн томилогдсон захиалгууд харагдана. Энэ нь бусад механикчдын ажлыг нууж, анхаарлаа төвлөрүүлэхэд тусална.
:::

::: tip Хуучин захиалгуудыг дуусгах
"Ready for Pickup" төлөвтэй хуучин захиалгуудыг нэгэн зэрэг дуусгахын тулд **Batch Complete** товчийг ашиглаарай. Бүх Ready for Pickup захиалгуудыг нэгэн зэрэг "Completed" болгоно.
:::

## Бараа материалын хяналт

::: tip Бараа материалын дохиолол
Бараа материалын үлдэгдэл бага үед шараар тэмдэглэгдэж, нөөцлөх шаардлагатайг сануулна. Босго хэмжээ тохируулж, дохиолол авах боломжтой.
:::

## Тайлан ба санхүү

::: tip Өдөр бүр тайлангаа шалгах
Өдөр бүр өдрийн тайлангаа шалгаж, санхүүгийн үзүүлэлтээ хянаж байхыг зөвлөж байна. Өдрийн эцэст тайлан гаргаж, маргаашийн төлөвлөгөөгөө гаргахад тусална.
:::

## Аюулгүй байдал

::: danger PIN кодоо хамгаалах
PIN кодоо хэнд ч бүү хэлээрэй. Засварын булангийн PIN код нь таны байгууллагын мэдээллийг зөвшөөрөлгүй хандалтаас хамгаална. PIN кодыг тогтмол сольж байхыг зөвлөж байна.
:::

## Худалдан авалт

::: tip Худалдан авалтын төлөв шалгах
Худалдан авалтын захиалгын төлөвийг тогтмол шалгаж байгаарай. "Захиалсан" төлөвт байгаа захиалгуудыг бараа ирэхэд "Хүлээн авсан" болгож шинэчлэхээ мартуузай.
:::

## Тохиргоо

::: tip Хэл, валютаа тохируулах
Тохиргоо хэсгээс валют, хэлээ өөрчилж болно. Хэрэв та Монгол улсад үйл ажиллагаа явуулдаг бол MNT валют, MN хэлээр ажиллахыг зөвлөж байна.
:::

## Цаг товлолт

::: tip Товлолтоос захиалга руу
Цаг товлолт нь харилцагчийг урьдчилан бүртгэх арга юм. Харилцагч ирсний дараа товлолтын төлөвийг "Checked In" болгож, дараа нь ажлын захиалга үүсгэнэ.
:::

::: tip Өдөр бүр шалгах
Цаг товлолтуудыг өдөр бүр шалгаж, ирээгүй харилцагчдыг "No Show" төлөвт шилжүүлэхийг зөвлөж байна.
:::
