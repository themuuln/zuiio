# Үйлчилгээний сануулга

Үйлчилгээний сануулга нь тээврийн хэрэгсэл бүрийн дараагийн засвар үйлчилгээний хугацааг хянаж, харилцагчид цаг тухайд нь мэдэгдэл хүргэхэд зориулагдсан.

## Хоёр үндсэн таб

| Таб | Тайлбар |
| --- | --- |
| **Schedule List** | Идэвхтэй үйлчилгээний хуваарийн жагсаалт |
| **Reminder Logs** | Илгээсэн болон хүлээгдэж буй мэдэгдлийн түүх |

## Schedule List

Жагсаалтын хүснэгт дараах мэдээлэлтэй:

| Багана | Тайлбар |
| --- | --- |
| **Машин** | Машины марк, загвар, дугаар |
| **Үйлчилгээ** | Үйлчилгээний нэр |
| **Интервал** | Сарын интервал / км интервал |
| **Сүүлийн үйлчилгээ** | Сүүлийн үйлчилгээний огноо |
| **Дараагийн хугацаа** | Дараагийн үйлчилгээний огноо |
| **Reminder** | Идэвхтэй эсэх (🔔 / 🔕) |
| **Үйлдэл** | Засах (✏️) / Устгах (🗑️) |

### Хугацааны төлөв

- **Ойртоогүй** — хугацаа хол байна (анхдагч)
- **7 хоногийн дотор** — шар өнгөөр тэмдэглэгдэнэ
- **Хэтэрсэн** — улаан өнгөөр тэмдэглэгдэнэ, ⚠️ анхааруулга дүрс

## Шинэ schedule нэмэх

**Add schedule** цонхоор дараах мэдээллийг бүртгэнэ:

| Талбар | Тайлбар | Заавал эсэх |
| --- | --- | --- |
| **Машин** | Combobox-оос хайж сонгох (маркийн нэр + дугаар) | Тийм |
| **Үйлчилгээний нэр** | Үйлчилгээний нэр (жишээ: Oil Change) | Тийм |
| **Сарын интервал** | Хэдэн сар тутамд (жишээ: 6) | Үгүй |
| **Км интервал** | Хэдэн км тутамд (жишээ: 5000) | Үгүй |
| **Сүүлийн үйлчилгээ** | DatePicker-аар сонгох | Үгүй |
| **Дараагийн хугацаа** | DatePicker-аар сонгох | Үгүй |

::: tip Хос интервал
Сарын болон км интервалыг хамтад нь тохируулж болно. Жишээ нь: 6 сар эсвэл 10,000 км (аль нь эхэлж хүрвэл тэр үед).
:::

## Засах ба устгах

**Засах** (✏️) товч дээр дарахад Edit цонх нээгдэнэ:

| Талбар | Тайлбар |
| --- | --- |
| **Үйлчилгээний нэр** | Нэр өөрчлөх |
| **Сарын интервал** | Интервал өөрчлөх |
| **Км интервал** | Интервал өөрчлөх |
| **Тэмдэглэл** | Нэмэлт тэмдэглэл |
| **Reminder enabled** | Reminder идэвхтэй/идэвхгүй (Toggle) |

**Устгах** (🗑️) товч дээр дарж schedule-ыг бүрмөсөн устгана.

## Тохиргоо (Settings)

**Settings** товчоор нээх Settings Sheet дотор дараах ерөнхий тохиргоо бий:

| Тохиргоо | Тайлбар |
| --- | --- |
| **Default channel** | Анхдагч хүргэх суваг: in_app, email, эсвэл both |
| **Auto enable** | Шинээр үүсгэсэн schedule-ууд reminder-аа автоматаар асах эсэх (Toggle) |

## Үндсэн үйлдлүүд

Хуудасны дээд хэсгийн товчлууруудаар:

| Товч | Дүрс | Үйлдэл |
| --- | --- | --- |
| **Sync History** | History | Өмнөх ажлын захиалгуудаас schedule үүсгэх |
| **Send Pending** | Send | Хугацаа болсон reminder-уудыг гараар илгээх |
| **Settings** | Settings | Channel болон auto-enable тохиргоо нээх |
| **Add schedule** | Plus | Шинэ schedule нэмэх |

## Reminder Logs

Түүхийн таб дээр дараах багануудтай хүснэгт харагдана:

| Багана | Тайлбар |
| --- | --- |
| **Машин** | Машины марк, загвар, дугаар |
| **Үйлчилгээ** | Үйлчилгээний нэр |
| **Төрөл** | Reminder-ийн төрөл (Badge) |
| **Суваг** | Хүргэсэн суваг (Badge) |
| **Төлөв** | Илгээсэн төлөв (Badge) |
| **Товлосон** | Товлосон огноо |
| **Илгээсэн** | Илгээсэн огноо |

### Reminder-ийн төрлүүд

| Төрөл | Тайлбар |
| --- | --- |
| **service_due** | Үйлчилгээний хугацаа ойртсон |
| **service_overdue** | Үйлчилгээний хугацаа хэтэрсэн |
| **custom** | Тусгай сануулга |

### Reminder-ийн төлөвүүд

| Төлөв | Тайлбар |
| --- | --- |
| **pending** | Хүлээгдэж буй |
| **sent** | Илгээсэн |
| **failed** | Амжилтгүй |
| **cancelled** | Цуцлагдсан |

### Сувгууд

| Суваг | Тайлбар |
| --- | --- |
| **email** | Имэйлээр |
| **in_app** | Систем дотор |
| **both** | Хugo сувгаар зэрэг |

## Баруун талын самбар (Sidebar)

| Таб | Агуулга |
| --- | --- |

## Зөвлөмж

::: tip Өдөр бүр шалгах
Reminder logs-ыг өдөр бүр шалгаж, амжилтгүй (failed) reminder-уудыг шалгана уу.
:::

::: tip Синхрончлол
Ажлын захиалгуудаас автоматаар schedule үүсгэхийн тулд **Sync History** товчийг ашиглаарай.
:::

::: tip Сувгийн сонголт
Харилцагчид Телеграм холбогдсон бол **telegram** сувгийг сонгохыг зөвлөж байна. Телеграм нь имэйлээс илүү хурдан хүргэлттэй.
:::
