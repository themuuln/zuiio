# TOLOM системтэй танилцах

TOLOM — авто засварын газруудад зориулсан бүрэн удирдлагын систем (ERP). Энэ нь захиалга хүлээн авахаас эхлээд санхүүгийн тайлан гаргах хүртэлх бүх үйл ажиллагааг нэг дор зохицуулна.

:::: info Олон байгууллагад зориулсан
TOLOM нь multi-tenant SaaS платформ юм. Та өөрийн байгууллагаа бүртгүүлээд тусгаарлагдсан орчинд ажиллана. Өөр байгууллагын өгөгдөл танд харагдахгүй.
::::

## Системийн үндсэн модулиуд

| Модуль                           | Үүрэг                         | Гол боломжууд                                                                                                           |
| -------------------------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Хяналтын самбар**              | Өдрийн үйл ажиллагааны тойм   | Орлого, идэвхтэй захиалга, дундаж захиалга, харилцагч, график, өдрийн зорилтот орлого                                   |
| **Засварын булан (Bay View)**     | Ажлын байрны харагдац         | 3 харагдац (grid/kanban/list), drag-and-drop, PIN хамгаалалт, механикчдын бүртгэл, хүлээгдэж буй дараалал, shift report |
| **Механикийн самбар**            | Механикчийн ажлын самбар       | Цаг бүртгэл (Clock In/Out) + хугацааны тоолуур, 6 KPI карт (Completed, Revenue, Active Jobs, Hours, Avg Job Value, Jobs Per Day), trend график, захиалгын жагсаалт, төлөвийн dropdown, админ харагдац (механикч сонгох, удирдлагын самбар) |
| **Механикчийн гүйцэтгэл**        | Эзэмшигчийн харьцуулах самбар  | Механикчдын үзүүлэлтийн хүснэгт (орлого, захиалга, цаг, комисс, үнэлгээ), 5 KPI карт (Active Mechanics, Jobs, Hours, Revenue, Avg Satisfaction), баганан график, leaderboard, дэлгэрэнгүй sheet, салбарын шүүлтүүр |
| **Ажлын захиалга**               | Засвар үйлчилгээний баримт    | 6 төлөв, үйлчилгээ + сэлбэг, wizard үүсгэх, төлөвийн түүх, үнийн түүх                                                   |
| **Үнэлгээ**                      | Захиалгын үнийн санал         | Үнэлгээ үүсгэх, батлах, хэвлэх, захиалга болгон хувиргах, публик холбоос                                              |
| **Харилцагчид**                  | Үйлчлүүлэгчийн мэдээлэл       | Хувь хүн / байгууллага, CRM тэмдэглэл, хандсан эх үүсвэр, хурдан хайлт, CSV импорт                                      |
| **Тээврийн хэрэгсэл**            | Автомашины бүртгэл            | VIN, дугаар, түүх, олон эзэмшигчтэй холбох                                                                              |
| **Үйлчилгээний каталог**         | Үйлчилгээ, үнийн жагсаалт     | Үйлчилгээ нэмэх, засах, устгах, ангилал, үнийн түүх, загварт тохирсон үнэ, Excel экспорт                                |
| **Автомашины загвар**            | Марк, загварын мэдээллийн сан | Үйлдвэрлэгч → загвар → хувилбар, мод хэлбэрийн бүтэц, жинтэй хайлт, Excel экспорт                                       |
| **Бараа материал**               | Сэлбэгийн нөөцийн бүртгэл     | Сэлбэг, дансны дэвтэр (ledger), ханган нийлүүлэгчид, худалдан авалт (PO), босго хэмжээ, Машины сэлбэг (PartsCars), үнэлгээ, шилжүүлэг, дохиолол, импорт |
| **Санхүү**                       | Орлого, гүйлгээ, нэхэмжлэх    | 5 таб (тойм, гүйлгээ, нэхэмжлэх, зарлага, буцаалт), өдөр/7 хоног/сар, 4 валют, Excel экспорт, публик нэхэмжлэх           |
| **Зарлага**                      | Зарлагын бүртгэл              | Зарлагын ангилал (10 анхдагч), төлөв (төлсөн/төлөгдөөгүй), шүүлтүүр, Excel экспорт, ангилалын тохиргоо                   |
| **Кассын бүртгэл**               | Бэлэн мөнгөний бүртгэл        | Орлого/зарлагын бүртгэл, кассын үлдэгдэл, түүх                                                      |
| **Тайлан**                       | Үзүүлэлт, тайлан              | Өдөр/7 хоног/сар, EOD тайлан, техничний гүйцэтгэл, үйлчилгээний ангилал, зарлагын үзүүлэлт, татварын тайлан              |
| **Өдрийн хаалт**                 | Өдрийн санхүүгийн хаалт       | Бэлэн мөнгөний тохирц, орлогын баталгаажуулалт, зөрүү бүртгэл, өдрийн тайлан хэвлэх                                     |
| **Үйлчилгээний сануулга**        | Үйлчилгээний хуваарь          | Машины үйлчилгээний хуваарь, Телеграм / имэйл сануулга, синхрончлол, reminder logs, тохиргоо                            |
| **Цаг товлолт**                  | Харилцагчийн цаг товлолт      | 7 төлөв (Scheduled, Checked In, In Progress, Completed, Cancelled, No Show, Requested), шинэ товлолт, төлөв өөрчлөх, цуцлах |
| **Телеграм бот**                 | Харилцагчийн мэдээлэл         | Сануулга, мэдэгдэл, QR цаг бүртгэл, холбоо барих                                                         |
| **QR цаг бүртгэл**               | Механикчийн цагийн бүртгэл    | QR код уншуулан цаг бүртгэх, оролт/гаралтын түүх                                                                        |
| **Цалин**                        | Механикчийн цалин             | Комиссын тооцоо, цалингийн тайлан, төлбөрийн түүх                                                                      |
| **Үнийн дүрмүүд**                | Үнийн автомат тохируулга      | Тээврийн хэрэгслийн төрөл, марк, үйлчилгээгээр ялгаатай үнэ, 5 оператор, 6 нөхцөл                                     |
| **Тохиргоо**                     | Системийн тохиргоо            | 10+ таб (Ерөнхий, Салбар, Харагдац, Комисс, Үнийн дүрэм, Оношилгоо, Телеграм, Машины төрөл, Өгөгдөл хуваалцах, Экспорт/Backup) |
| **Админ самбар**                 | Супер админийн хяналт         | Байгууллагын жагсаалт, төлөвлөгөө өөрчлөх (Starter/Pro/Business/Enterprise), Trial сунгах, subscription удирдлага        |
| **Харилцагчийн портал**          | Үйлчлүүлэгчийн хуудас         | Захиалга, нэхэмжлэх, машин харах, цаг товлох — өөрийн имэйл/нууц үгээр нэвтрэх                                          |

:::: tip Хажуугийн цэс — статусын индикатор
Хажуугийн цэсэнд модуль бүрийн хажууд **ногоон (🟢) / шар (🟡) цэг** харагдана. **Ногоон** — тухайн модуль бүрэн хийгдсэн, баталгаажсан. **Шар** — хөгжиж буй, туршигдаагүй хэсэгтэй. Энэ нь аль боломжууд бэлэн, алийг нь болгоомжтой ашиглахыг шууд харуулна.
::::

TOLOM-ийн гол онцлог нь **таблет, ухаалаг утас, компьютер** гэх мэт бүх төхөөрөмжөөс ажиллах боломжтой, хэрэглэхэд хялбар интерфейс юм.

## Хэн ашиглах вэ?

- **Авто засварын газрын эзэд** — бизнесийн бүх үйл ажиллагааг нэг дороос хянах
- **Механикч нар** — захиалга хүлээн авах, гүйцэтгэх, төлөв шинэчлэх, булангийн харагдац
- **Админ ажилтнууд** — харилцагчдын мэдээлэл хөтлөх, тайлан гаргах
- **Нягтлан бодогчид** — санхүүгийн тайлан, орлого зарлагын хяналт
- **Үйлчлүүлэгчид** — өөрийн захиалга, нэхэмжлэхээ порталаас харах
