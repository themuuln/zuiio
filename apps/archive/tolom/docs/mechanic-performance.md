# Механикийн гүйцэтгэлийн үнэлгээ

Механикийн гүйцэтгэлийн хуудас нь механикчдын ажлын бүтээмж, орлого, цаг, комисс, сэтгэл ханамжийн үзүүлэлтүүдийг нэгтгэн харьцуулах боломж олгоно.

## Хугацааны сонголт

Дээд хэсэгт дараах гурван үеээр сонгож харах боломжтой:

| Сонголт | Хугацаа |
| --- | --- |
| **This Week** | Сүүлийн 7 хоног |
| **This Month** | Сүүлийн 30 хоног |
| **This Quarter** | Сүүлийн 3 сар |

- Сонгосон үеийн тухай тайлбар хуудасны дэд гарчигт харагдана
- **🔄 Refresh** товч — сүүлийн өөрчлөлтүүдийг шинэчлэх
- Салбарын шүүлтүүр — бүх салбар эсвэл тодорхой салбар сонгох боломжтой

## KPI картууд

| Карт | Дүрс | Тайлбар |
| --- | --- | --- |
| **Active Mechanics** | Users | Сонгосон үеийн идэвхтэй механикчдын тоо |
| **Jobs Completed** | Wrench | Сонгосон үед гүйцэтгэсэн нийт захиалга |
| **Total Hours** | Clock | Нийт ажилласан цаг (механикчдын цагийн бүртгэлээс) |
| **Total Revenue** | DollarSign | Нийт орлого (₮) |
| **Avg Satisfaction** | Star | Дундаж сэтгэл ханамжийн үнэлгээ (5-аас). "No reviews" хэрэв үнэлгээ байхгүй |

## Revenue by Mechanic (Баганан график)

Сонгосон үеийн шилдэг 8 механикчийн орлогыг баганан графикаар харуулна. Графикийн доор "Showing top N of M mechanics" гэсэн мэдээлэл харагдана.

## Mechanic Leaderboard (Механикчдын жагсаалт)

Механикчин бүрийн мөрөнд дараах үзүүлэлтүүд харагдана:

| Багана | Тайлбар |
| --- | --- |
| **#** | Чансаа. Тэргүүлэгч механикчид Crown дүрс + "Top" тэмдэг |
| **Mechanic** | Нэр. Тэргүүлэгчийн мөрөнд шар өнгийн дэвсгэр |
| **Jobs** | Гүйцэтгэсэн захиалгын тоо |
| **Hours** | Ажилласан цаг (нэг аравтын бутархай). Цаг бүртгэлгүй бол "—" |
| **Revenue** | Нийт орлого (₮) |
| **Rev/Hr** | Цаг тутамд авчирсан орлого (revenue / hours). Цаггүй бол "—" |
| **Commission** | Шийдвэрлэсэн захиалгын комиссын нийт дүн (ногоон өнгөөр). Комиссгүй бол "—" |
| **Rating** | Дундаж үнэлгээ (од + тоо). Нийт 5-аас бага үнэлгээ бол "Low" тэмдэг нэмэгдэнэ |

::: tip Эрэмбэлэх
Баганын гарчиг дээр дарахад өгөгдлийг өсөх/буурахаар эрэмбэлэх боломжтой. Анхдагчаар Revenue баганаар буурахаар эрэмбэлэгдэнэ.
:::

## Механикчийн дэлгэрэнгүй мэдээлэл (Sheet)

Жагсаалтад механикчийн мөрөнд дарахад баруун талаас **Sheet** нээгдэж дараах мэдээлэл харагдана:

### KPI хүснэгт

| Үзүүлэлт | Тайлбар |
| --- | --- |
| **Jobs Completed** | Гүйцэтгэсэн захиалгын тоо |
| **Hours Worked** | Ажилласан цаг |
| **Total Revenue** | Нийт орлого (₮) |
| **Revenue / Hour** | Цаг тутамд орлого |
| **Avg Revenue / Job** | Захиалга бүрийн дундаж орлого |
| **Customer Rating** | Одны үнэлгээ + нийт үнэлгээний тоо |
| **Commission** | Нийт комисс (ногоон өнгө) |

### Service vs Parts Breakdown

| Талбар | Тайлбар |
| --- | --- |
| **Services Performed** | Гүйцэтгэсэн үйлчилгээний тоо |
| **Parts Used** | Ашигласан сэлбэгийн тоо |

### Сүүлийн үеийн үнэлгээ (Recent Reviews)

Хэрэв механикчин үнэлгээ авсан бол дараах мэдээлэл харагдана:

- 5 одны үнэлгээ (одон дүрсээр)
- Харилцагчийн нэр (эсвэл "Anonymous")
- Огноо
- Санал хүсэлт (хэрэв байгаа бол)

### Period Context

Энэ механикчийн чансаа (жагсаалт дахь байр): "This mechanic is ranked #N of M mechanics by revenue"

## Тэмдэглэл

- Хэрэв цагийн бүртгэл идэвхгүй бол **Total Hours**, **Rev/Hr** утгууд "—" хэвээр харагдана
- Хэрэв комиссын тохиргоо идэвхгүй бол **Commission** "—" хэвээр харагдана
- Тэргүүлэгч механикчийн мөрөнд шар өнгийн дэвсгэр (`bg-amber-50`) харагдана
- Нийт 5-аас бага үнэлгээ авсан механикчинд "Low" тэмдэг нэмэгдэнэ
