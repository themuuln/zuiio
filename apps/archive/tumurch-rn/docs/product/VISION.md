# Tumurch — Product Vision

## What is Tumurch

Tumurch is an all-in-one gym platform that combines:

- **Hevy-level workout logging** — fast, polished, sticky
- **Coach workflows** — client management, program assignment, progress review
- **Gym operations** — reception check-in, memberships, billing, access control
- **Shop & ERP** — supplement sales, inventory, POS, branch management
- **Health ecosystem** — calorie tracking, Apple HealthKit, Google Health Connect
- **AI coaching** — adaptive plan generation, form analysis (future)

In short: **Hevy + gym operations + shop/ERP + CRM in one app.**

## Why this exists

Gym owners currently stitch together 3-5 tools: a workout app for members, a POS for the shop, spreadsheets for memberships, WhatsApp for coach communication, and a calendar for scheduling. None of them talk to each other. Members have one app, coaches have another, and reception uses a notebook.

Tumurch replaces all of that with one product that serves every role in the gym.

## Target users

| Role | What they need |
|---|---|
| **Member** | Log workouts, track progress, buy supplements, see membership status |
| **Coach** | Manage clients, assign programs, review progress, communicate |
| **Reception** | Look up members, validate check-in, handle guests, sell products |
| **Manager** | Oversee memberships, approve freezes, view dashboard, manage staff |
| **Owner** | Track revenue, retention, inventory, multi-branch performance |

## Design principles

1. **Fast above all** — workout logging must feel instant. No loading spinners between sets.
2. **One app, many roles** — same codebase, role-based navigation. No separate apps.
3. **Mongolian-first** — all UI text in Mongolian. Currency in ₮. Phone format +976.
4. **Offline-capable** — reception check-in and workout logging should work without internet.
5. **Hevy is the bar** — if Hevy does it well, we must match or beat it.

## What we won't do

- Build a generic fitness social network (that's Hevy's game)
- Support enterprise franchise management before single-branch works
- Ship hardware integrations (turnstiles, locks) before software is solid
- Add AI features that can't be explained to a gym owner
