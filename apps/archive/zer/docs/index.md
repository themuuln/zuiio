## Tech Stack

| Category        | Technology                                   |
| --------------- | -------------------------------------------- |
| Language        | TypeScript                                   |
| Framework       | Next.js 16                                   |
| Package Manager | pnpm                                         |
| UI Library      | shadcn/ui + @base-ui/react + Tailwind CSS v4 |
| Forms           | react-hook-form + zod                        |
| Data Fetching   | TanStack React Query v5                      |
| Table           | TanStack React Table v8                      |
| Database        | Supabase (PostgreSQL)                        |
| Auth            | Supabase Auth                                |
| Charts          | Recharts                                     |
| PDF             | pdf-lib + jsPDF                              |
| Spreadsheets    | exceljs                                      |
| Email           | Nodemailer                                   |
| Testing         | Playwright, CodeceptJS, Midscene             |
| Linting         | Biome                                        |
