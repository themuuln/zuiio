# Төсөв vs бодит дүн

Сар/улирлын төсөв гаргаж, бодит зарлага/борлуулалттай харьцуулах.

**Яагаад хэрэгтэй вэ:** Бизнесийн зарлагаа хянах, хэтэрсэн үед эрт мэдэх.

## Хэрэгжүүлэх тэмдэглэл

- `budgets` хүснэгт (category, month, planned_amount, actual_amount)
- Одоогийн зарлага/борлуулалт дээр агрегат query
- Recharts ашиглан харьцуулалт график
