# Үнэнч байдлын хөтөлбөр

Оноо хуримтлуулах, урамшуулал, эрэмбэ (tier) систем.

**Яагаад хэрэгтэй вэ:** Монголын дэлгүүрүүд үйлчлүүлэгчээ хадгалахад лояльти хөтөлбөр их ашигладаг.

## Хэрэгжүүлэх тэмдэглэл

- Онооны дүрэм (хэдэн төгрөг тутамд хэдэн оноо)
- Урамшууллын tier (bronze/silver/gold)
- Онооны үлдэгдэл, дуусах хугацаа
- POS дээр оноо ашиглах
