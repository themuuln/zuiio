# Баркод шошго хэвлэх

Бүтээгдэхүүний баркод шошгыг хэвлэх хуудас. `@media print` CSS ашигласан энгийн хэвлэх загвар.

**Яагаад хэрэгтэй вэ:** Дэлгүүрийн бараанд баркод нааж, касс дээр сканнердах хурдан болгоно.

## Хэрэгжүүлэх тэмдэглэл

- Бүтээгдэхүүн бүрт баркод талбар байгаа
- Хэвлэх preview хуудас + `window.print()` товч
- Термаль принтерт тохируулсан хэмжээ (58mm / 80mm)
