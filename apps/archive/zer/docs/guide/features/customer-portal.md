# Харилцагчийн портал

Үйлчлүүлэгч өөрийн өр/нэхэмжлэхээ харах, үлдэгдэл төлөх.

**Яагаад хэрэгтэй вэ:** Үйлчлүүлэгч өрийн үлдэгдлийг харахад дуудлага/мессеж багасна.

## Хэрэгжүүлэх тэмдэглэл

- Одоогийн public-share-link загварыг өргөжүүлэх
- Тусгай login (харилцагчийн утас/имэйлээр)
- Тэдний нэхэмжлэх, өрийн үлдэгдэл, төлбөрийн түүх
