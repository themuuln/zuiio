# Хямдрал

Бүтээгдэхүүн болон борлуулалтад хэрэглэх хямдралын тохиргоо.

## Хямдралын төрлүүд

- **Хувийн хямдрал** — үнийн тодорхой хувиар хямдруулах (жишээ: 10%)
- **Тогтмол дүнгийн хямдрал** — тодорхой дүнгээр хямдруулах (жишээ: 5000₮)

## Хэрэглэх хүрээ

- **Бүтээгдэхүүн дээр** — тодорхой бүтээгдэхүүнд хэрэглэх
- **Борлуулалт дээр** — борлуулалтын баримтын нийт дүнгээр

## Хямдрал тохируулах

1. `Хямдрал` цэснээс `Шинэ хямдрал` товч дарна.
2. Нэр, хямдралын төрөл, хэмжээг оруулна.
3. Хэрэглэх хүрээг сонгоно.
4. Идэвхжүүлэх/идэвхгүй болгох боломжтой.
