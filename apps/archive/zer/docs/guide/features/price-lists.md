# Үнийн жагсаалт

Бөөний болон жижиглэнгийн үнэ тусдаа хадгалах, үйлчлүүлэгчээр ялгаатай үнэ өгөх.

**Яагаад хэрэгтэй вэ:** Бөөний болон жижиглэнгийн худалдаалагчид өөр өөр үнэтэй.

## Хэрэгжүүлэх тэмдэглэл

- `customer_groups` хүснэгт (group нэр, хөнгөлөлтийн хувь)
- `product_group_prices` хүснэгт (product_id, customer_group_id, sale_price)
- Борлуулалтын форм дээр үйлчлүүлэгчийн groups-оос хамаарч үнэ автомат сонголт
