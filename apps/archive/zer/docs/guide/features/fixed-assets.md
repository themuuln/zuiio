# Үндсэн хөрөнгийн бүртгэл

Компьютер, тавилга, тоног төхөөрөмжийн элэгдэл тооцоо, үлдэгдэл үнэ.

**Яагаад хэрэгтэй вэ:** Татварын тайланд үндсэн хөрөнгийн элэгдэл заавал тусгах шаардлагатай.

## Хэрэгжүүлэх тэмдэглэл

- `fixed_assets` хүснэгт (name, purchase_date, purchase_cost, useful_life, depreciation_method, salvage_value)
- Шулуун шугамын / түргэвчилсэн элэгдлийн тооцоо
- Сар бүр элэгдлийг automation-оор бүртгэх
