# Батлуулах урсгал

Зарлага, худалдан авалтыг менжерээр батлуулах систем.

**Яагаад хэрэгтэй вэ:** Монгол бизнесүүдэд зарлага/худалдан авалтыг эхлээд батлуулдаг зуршилтай.

## Хэрэгжүүлэх тэмдэглэл

- Төлөвийн машин: `pending` → `approved` / `rejected`
- Батлах/татгалзах товч, pending-approvals жагсаалт
- Одоо байгаа server actions дээр permission check нэмэх
