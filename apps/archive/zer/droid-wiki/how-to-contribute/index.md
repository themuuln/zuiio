# How to contribute

Active contributors: themuuln

Zer is a Mongolia-first mini ERP for small businesses. We welcome contributions that improve the codebase, fix bugs, add features, or improve documentation.

## Ways to contribute

- **Report bugs** — Open an issue on GitHub with steps to reproduce.
- **Fix bugs** — Check open issues and submit a pull request.
- **Add features** — Discuss the feature in an issue first, then implement.
- **Improve documentation** — Fix typos, add missing docs, or write new guides.

## Getting started

1. Read the [development workflow](./development-workflow) guide for branch and commit conventions.
2. Read [patterns and conventions](./patterns-and-conventions) to understand the coding style.
3. Read [testing](./testing) for how tests are organized and run.
4. Read [tooling](./tooling) for the developer toolchain.
