# Gym Locker System

Offline-first Flutter apps for gym locker management. Member shows QR code → reception scans → locker assigned in < 1 second. No internet required.

- **reception_app** — Staff tablet app: QR scanning, locker grid, member management, check-in/out
- **client_app** — Member phone app: QR display, visit history
- **shared** — Core package: Drift models, repositories, QR codec

See [PLAN.md](./PLAN.md) for full architecture, data model, edge cases, and phased roadmap.
